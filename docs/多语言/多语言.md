# 多语言

语言包放在 `app/lang`，文件名即语言标识，例如 `zh-cn.json`、`en-us.json`、`ja-jp.json`。

## 配置

`config/lang.json`：

```json
{
    "default_lang": "zh-cn",
    "auto_detect_browser": true,
    "allow_lang_list": [],
    "detect_var": "lang",
    "use_cookie": true,
    "cookie_var": "think_lang",
    "header_var": "think-lang"
}
```

所有字段都会参与运行时检测。`allow_lang_list` 为空时允许所有已加载语言；非空时必须包含 `default_lang`。配置包含未知字段、错误类型、非法语言标签、Cookie/查询变量名或请求头名时，应用启动失败。

## 语言包

语言包必须是 UTF-8 编码的嵌套 JSON 对象：

```json
{
    "auth": {
        "login_success": "登录成功"
    },
    "validate": {
        "default": {
            "required": "{:field}不能为空"
        }
    }
}
```

加载后会扁平化为点路径：

```text
auth.login_success
validate.default.required
```

叶子值只能是字符串。重复键、扁平化后冲突、数组、数字、布尔值、空对象、尾随 JSON、超过 32 层嵌套、超过 100000 个条目或超过 4 MiB 的文件都会被拒绝。

## 读取语言

控制器中：

```go
message := c.Lang("auth.login_success")
```

应用中：

```go
message := app.Lang.Get("auth.login_success", nil, "zh-cn")
```

读取指定语言时会先检查允许列表；未允许、非法或缺少对应 key 时回退到 `default_lang` 语言包，默认语言也缺失时返回原 key。

变量替换：

```go
message := app.Lang.Get("validate.default.required", map[string]interface{}{
	"field": "email",
}, "zh-cn")
```

模板中：

```html
{{ lang "auth.login_success" }}
```

## 请求语言检测

语言中间件的检测顺序：

```text
查询参数 `detect_var` > Cookie `cookie_var` > 自定义请求头 `header_var` > `Accept-Language` > 默认语言
```

示例：

```text
/api/users?lang=en-us
Cookie: think_lang=zh-cn
think-lang: ja-jp
Accept-Language: en-US,en;q=0.9,zh-CN;q=0.8
```

每个候选都必须已加载且通过允许列表。`Accept-Language` 按 `q` 权重排序，忽略 `q=0`、非有限值和非法项；相同权重保持请求头顺序。完整标签优先，主语言码会按 `allow_lang_list` 顺序稳定匹配，例如 `en` 可以匹配 `en-us`。`auto_detect_browser=false` 时不读取 `Accept-Language`。

当前请求语言存入请求上下文：

```go
lang := c.GetLang()
```

该过程不会修改全局语言状态，适合并发请求。

## 手动加载

```go
err := app.Lang.Load("./app/lang/fr-fr.json", "fr-fr")
err = app.Lang.LoadAll("./app/lang")
```

`Load` 和 `LoadAll` 都在解析成功后原子提交。`LoadAll` 任一文件失败时不修改已有语言状态；全部成功时以目录当前内容替换旧语言包，因此已删除的文件不会继续生效。目录不存在时按“未配置语言包”处理，不阻断启动；越界符号链接会被拒绝。

初始化与切换语言均返回错误：

```go
if err := app.Lang.Init(config); err != nil {
	return err
}
if err := app.Lang.SetLang("en-us"); err != nil {
	return err
}
```

`HasLang` 可判断语言包是否存在：

```go
if app.Lang.HasLang("en-us") {
	// 语言包已加载。
}
```
