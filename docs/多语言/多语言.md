# 多语言概览

每个应用拥有独立 `framework/lang.Lang`。项目 `config/lang.json` 提供共享默认值，应用初始化时从自身 `app/<name>/lang` 加载语言包；不同应用的词条和当前请求语言不会互相污染。

## 应用装配

1. 从项目配置快照读取 `config/lang.json`。
2. 叠加目标应用配置；`default_lang` 缺失时兼容 `app.default_lang`，最终默认 `zh-cn`。
3. `Lang.Init` 严格校验配置。
4. `Lang.LoadAll(app.ApplicationLangPath())` 只加载当前应用真实目录。
5. 语言中间件写入当前 Request，不修改进程级“当前语言”。
6. 向该应用模板驱动注册 `lang` 函数。

配置或语言文件错误会成为该应用启动错误；由于宿主在监听前初始化全部应用，错误会阻断整个服务启动。

## 请求处理

```text
查询参数 -> Cookie -> 自定义请求头 -> Accept-Language -> 应用默认语言
```

候选必须已加载并通过允许列表。控制器 `Lang`/`GetLang` 从请求上下文读取，服务层应显式传递请求语言或翻译结果。
