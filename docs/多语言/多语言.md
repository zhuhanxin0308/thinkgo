# 多语言概览

ThinkGo 的多语言由 `framework/lang.Lang` 管理。每个应用初始化时读取项目级 `config/lang.json` 和自己的 `app/<应用名>/lang` 目录；HTTP 请求再通过当前应用的语言中间件选择请求语言并写入请求上下文。

## 应用装配

应用初始化顺序中的多语言步骤是：

1. 读取 `config/lang.json`。
2. 如果没有 `default_lang`，兼容读取 `app.default_lang`，默认值为 `zh-cn`。
3. 调用 `Lang.Init` 严格校验配置。
4. 调用 `Lang.LoadAll(app.ApplicationLangPath())` 加载当前应用语言包。
5. 把当前应用的语言处理能力放入该应用的全局中间件链。
6. 向默认 Go 模板驱动注册 `lang` 模板函数。

配置或语言文件错误会记录为启动错误，应用不应在半初始化状态下继续对外服务。

## 请求处理

请求语言检测只把选中的语言写入当前 `Request`：

```text
查询参数 -> Cookie -> 自定义请求头 -> Accept-Language -> 默认语言
```

候选必须是已加载且通过允许列表的语言；无效候选会继续尝试下一来源。控制器的 `c.Lang` 和 `c.GetLang` 从请求上下文读取，不修改共享当前语言。
