# 多语言

语言包放在 `app/lang`，文件名即语言标识，例如 `zh-cn.json`、`en-us.json`、`ja-jp.json`。

## 配置

`config/lang.json`：

```json
{
    "default_lang": "zh-cn"
}
```

当前实现使用 `default_lang` 初始化默认语言。其它字段保留在配置中，但语言检测逻辑以源码实现为准。

## 语言包

语言包支持嵌套 JSON：

```json
{
    "auth": {
        "login_success": "登录成功"
    },
    "validate": {
        "default": {
            "required": "{:field}不能为空"
        }
    }
}
```

加载后会扁平化为点路径：

```text
auth.login_success
validate.default.required
```

## 读取语言

控制器中：

```go
message := c.Lang("auth.login_success")
```

应用中：

```go
message := app.Lang.Get("auth.login_success", nil, "zh-cn")
```

读取指定语言时，如果该语言包缺少对应 key，会回退到 `default_lang` 语言包；默认语言也缺失时返回原 key。

变量替换：

```go
message := app.Lang.Get("validate.default.required", map[string]interface{}{
	"field": "email",
}, "zh-cn")
```

模板中：

```html
{{ lang "auth.login_success" }}
```

## 请求语言检测

语言中间件的检测顺序：

```text
GET 参数 lang > Cookie lang > Accept-Language > 默认语言
```

示例：

```text
/api/users?lang=en-us
Cookie: lang=zh-cn
Accept-Language: en-US,en;q=0.9,zh-CN;q=0.8
```

`Accept-Language` 会先尝试完整匹配，再尝试主语言码和同语言族语言包，例如 `en` 可以匹配 `en-us`。

当前请求语言存入请求上下文：

```go
lang := c.GetLang()
```

该过程不会修改全局语言状态，适合并发请求。

## 手动加载

```go
err := app.Lang.Load("./app/lang/fr-fr.json", "fr-fr")
err = app.Lang.LoadAll("./app/lang")
```

`LoadAll` 会返回目录遍历、文件读取或 JSON 解析错误；语言包目录不存在时按“未配置语言包”处理，不阻断启动。

`HasLang` 可判断语言包是否存在：

```go
if app.Lang.HasLang("en-us") {
	// 语言包已加载。
}
```
