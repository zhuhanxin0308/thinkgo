# 语言生命周期

`Lang` 服务提供独立解析、单文件加载、目录加载和显式当前语言切换 API。应用代码通过 `app.Lang()` 直接取得该服务。

## Parse

```go
import "path/filepath"

languageManager := app.Lang()
translations, err := languageManager.Parse(filepath.Join(app.ApplicationLangPath(), "zh-cn.json"))
```

`Parse` 只解析并扁平化文件，不修改管理器状态。适合在发布前检查语言包格式。

## Load

```go
import "path/filepath"

if err := languageManager.Load(filepath.Join(app.ApplicationLangPath(), "fr-fr.json"), "fr-fr"); err != nil {
	return err
}
```

`Load` 成功解析后原子合并到目标语言包；同一个语言中已有的同名键会被新文件值覆盖。语言参数为空时使用管理器当前语言。语言参数会先经过语言标识校验。

解析失败、文件不是普通文件、编码无效或语言标识非法时，不会提交本次内容。

## LoadAll

```go
if err := languageManager.LoadAll(app.ApplicationLangPath()); err != nil {
	return err
}
```

`LoadAll` 遍历目录中的 `.json` 文件（扩展名不区分大小写），以文件名解析语言标识。所有文件必须成功解析后才一次性替换语言表：

- 任一文件失败时，旧状态保持不变。
- 成功重载会移除目录中已删除语言文件对应的旧语言包。
- 目录不存在按“未配置语言包”处理，不返回错误。
- 传入路径必须是目录；嵌套逃逸根目录的符号链接会被拒绝。

显式传入的目录根符号链接会先解析为真实目录，目录内文件仍必须落在真实根目录内。

## 当前语言

```go
if err := languageManager.SetLang("en-US"); err != nil {
	return err
}
current := languageManager.GetLang()
```

`SetLang` 会先通过已加载语言和允许列表匹配，成功后修改管理器的共享 `currentLang`；未加载或未允许时返回 `ErrLanguageNotLoaded`。该 API 是兼容性全局状态，不应用于保存 HTTP 请求语言。请求级语言应由[请求语言检测](请求语言检测.md)写入 `Request`。

## 存在性 API

```go
loaded := languageManager.HasLang("en-us")
hasKey := languageManager.Has("auth.login_success", "en-us")
```

`HasLang` 判断语言表是否已加载；`Has` 判断键是否存在，并且目标语言必须通过允许列表。两者都不会因为缺失而自动回退。
