# 语言包格式

项目级公共语言文件放在 `app/lang`，应用专属语言文件放在 `app/<应用名>/lang`；同名键由应用专属语言覆盖。直接使用框架的 `lang` 包时也可以由调用方显式指定受信目录。文件名（不含 `.json`）是语言标识：

```text
app/lang/zh-cn.json
app/<应用名>/lang/zh-cn.json
app/<应用名>/lang/en-us.json
```

## JSON 结构

根节点必须是对象，叶子值必须是字符串；对象可以嵌套：

```json
{
    "auth": {
        "login_success": "登录成功"
    },
    "validate": {
        "default": {
            "required": "{:field}不能为空"
        }
    }
}
```

加载后扁平化为：

```text
auth.login_success
validate.default.required
```

键会去首尾空白并转小写；空键以及包含 NUL、回车或换行的键会被拒绝。同一对象中忽略大小写和空白后的重复键会返回 `ErrDuplicateLanguageKey`；扁平化后发生路径冲突也会拒绝。

## 不支持的值

数字、布尔值、数组和 `null` 不能作为叶子值。文件必须至少产生一个字符串叶子；只有空对象的文件会被拒绝。文件尾部不能包含第二个 JSON 文档或非空尾随内容。

## 文件限制

- 必须是有效 UTF-8。
- 单文件最多 4 MiB。
- 扁平化嵌套深度最多 32 层。
- 单文件最多 100000 个叶子条目。
- 完整扁平键最多 512 字节。

超过限制或 JSON 语法错误返回 `ErrInvalidLanguageFile` 或 `ErrLanguageFileTooLarge`。解析失败不会留下部分语言包。
