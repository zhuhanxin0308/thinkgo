# 多语言配置

配置文件为 `config/lang.json`。框架只接受已定义键，未知键、类型错误或不满足约束的值会使 `Lang.Init` 返回 `ErrInvalidLangConfig`。

## 配置示例

```json
{
    "default_lang": "zh-cn",
    "auto_detect_browser": true,
    "allow_lang_list": [],
    "detect_var": "lang",
    "use_cookie": true,
    "cookie_var": "think_lang",
    "header_var": "think-lang"
}
```

## 字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `default_lang` | string | `zh-cn` | 默认和回退语言 |
| `auto_detect_browser` | bool | `true` | 是否解析 `Accept-Language` |
| `allow_lang_list` | string array | 空数组 | 非空时限制可用语言；必须包含默认语言 |
| `detect_var` | string | `lang` | 查询参数名 |
| `use_cookie` | bool | `true` | 是否读取语言 Cookie |
| `cookie_var` | string | `think_lang` | Cookie 名 |
| `header_var` | string | `think-lang` | 自定义请求头名 |

空的 `allow_lang_list` 表示不使用显式白名单，但候选语言仍必须已经加载。非空白名单保持配置顺序，该顺序也用于主语言前缀匹配。

## 标识符约束

语言标识会去空白并转为小写，使用受支持的 BCP 47 子集：首段为 2 到 8 个 ASCII 字母，后续段为 1 到 8 个 ASCII 字母或数字，整体最多 35 字节，不允许下划线。`zh-CN` 会规范为 `zh-cn`，`zh_CN` 会被拒绝。

查询参数名和 Cookie 名最多 64 字节，首字符必须是字母或 `_`，后续允许字母、数字、`_`、`-`、`.`。请求头名必须是合法 HTTP token，提交后会规范为标准首字母大写形式。

## 原子初始化

`Init` 会先解析和校验所有字段，全部通过后才替换默认语言、当前语言、检测配置和允许集合。失败时不会提交半套配置。`DetectionConfig()` 返回的 `AllowedLanguages` 是副本，调用方修改它不会改变管理器。
