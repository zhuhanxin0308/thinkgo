# 翻译读取

通过 `app.Lang()` 得到的 `*lang.Lang` 调用 `Get`，读取扁平化键，并按照显式语言、当前语言、默认语言和原 key 的顺序回退。

## Get

```go
languageManager := app.Lang()
message := languageManager.Get("auth.login_success", nil, "en-us")
message = languageManager.Get("cart.total", map[string]interface{}{
	"count": 3,
}, "zh-cn")
```

语言参数为空时使用管理器的 `currentLang`；提供非空参数时，参数必须是合法且允许的语言标识，否则直接使用默认语言。指定语言缺少键且不是默认语言时，回退默认语言；所有语言都缺少键时返回传入的原始 `name`。

键查找会去首尾空白并转小写，但缺失时返回的原 key 保留调用方传入的形式。

## 变量替换

语言文本中的占位符格式是 `{:变量名}`：

```json
{
    "welcome": "你好，{:name}"
}
```

```go
languageManager.Get("welcome", map[string]interface{}{
	"name": "张三",
}, "zh-cn")
```

变量名最多 64 字节，首字符为字母或 `_`，后续允许字母、数字、`_`、`-`、`.`。只格式化以下安全标量：字符串、布尔值、所有有符号/无符号整数、有限浮点数和合法 `json.Number`。

数组、map、结构体、方法、NaN、Inf 和无效 JSON 数字不会被格式化，对应占位符会原样保留。变量处理不会调用不受信对象的 `String` 方法。

## 语言键存在性

```go
if languageManager.Has("auth.login_success", "en-us") {
	message := languageManager.Get("auth.login_success", nil, "en-us")
	_ = message
}
```

`Has` 不执行默认语言回退；如果当前语言缺少键，它返回 `false`，即使默认语言有相同键。
