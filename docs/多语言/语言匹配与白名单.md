# 语言匹配与白名单

`MatchLanguage` 把用户提供的完整语言标签或主语言前缀解析为一个已加载且允许使用的标准语言标识。

## 完整标签

```go
matched := languageManager.MatchLanguage("en-US")
```

语言标签先去首尾空白并转小写。只有对应语言包已加载且通过允许列表时，完整标签才直接命中；否则继续尝试主语言匹配。

## 主语言前缀

```go
matched := languageManager.MatchLanguage("en")
```

主语言 `en` 可以匹配 `en-us` 或 `en-gb`。选择顺序为：

- 配置了 `allow_lang_list` 时，按照白名单顺序选择第一个已加载的同主语言包。
- 没有白名单时，按已加载语言标识的排序选择，结果稳定。

`FindLangByPrefix` 是同一匹配逻辑的兼容名称。

## 白名单语义

白名单在候选匹配、显式读取和全局切换时都生效：

```go
if languageManager.MatchLanguage("ja-jp") == "" {
	// 未允许或未加载。
}
```

`Load` 仍可以把未列入白名单的语言读入管理器，但它不会被 `MatchLanguage` 或 `SetLang` 选中；`Get` 对未允许的显式语言会回退默认语言。`HasLang` 只表示已加载，不等同于可供请求使用。

## 回退链

语言候选无法匹配时，请求中间件继续尝试下一来源，全部失败后使用 `GetDefaultLang()`。翻译键缺失时，`Get` 再从当前语言回退到默认语言，仍缺失则返回原始 key。
