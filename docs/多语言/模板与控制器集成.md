# 模板与控制器集成

多语言管理器可以从模板和控制器读取。两种入口的语言来源不同，不能混用为同一请求语义。

## 模板 lang 函数

应用初始化成功安装默认 Go 模板驱动后，会注册：

```html
<h1>{{ lang "auth.login_success" }}</h1>
<p>{{ lang "cart.total" }}</p>
```

默认函数等价于调用：

```go
languageManager.Get(key, nil, "")
```

它使用管理器的共享 `currentLang`，不接收 `Request`，也不自动读取 `LangRequestKey`。如果同一进程需要为每个请求渲染不同语言，控制器应先翻译再传给模板：

```go
func (c *User) Page() string {
	c.Assign("title", c.Lang("page.title"))
	return c.Fetch("user/index")
}
```

视图模板根目录和函数注册规则见[模板章节](../模板/README.md)。

## 控制器入口

```go
message := c.Lang("auth.login_success")
locale := c.GetLang()
```

`c.Lang` 从当前请求读取语言，并将其传给 `c.App.Lang()`；`c.GetLang` 只读取语言标识。请求未经过语言中间件时，`GetLang` 返回空字符串，`c.Lang` 让管理器使用当前语言。

## 服务层传递

控制器可以把语言标识作为显式参数传给服务层：

```go
func (c *User) Create() *context.Response {
	locale := c.GetLang()
	languageManager := c.App.Lang()
	message := languageManager.Get("user.created", nil, locale)
	return c.Success(nil, message)
}
```

服务层不应依赖控制器实例；如果服务层需要返回消息，建议返回稳定消息键和变量，由请求边界按当前语言翻译。

## 验证器集成

验证器通过 `SetLang` 或本次调用的 `WithLang` 接收 `*lang.Lang`，自定义消息可以作为翻译键，默认规则消息来自 `validate.default.<rule>`。请求级语言通过 `WithLocale(c.GetLang())` 显式传入；控制器验证辅助会自动完成这一步。验证器核心不直接读取 HTTP 请求，详见[验证消息与多语言](../验证/验证消息与多语言.md)。
