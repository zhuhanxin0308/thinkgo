# 缓存

缓存入口是 `app.Cache`。公开操作均返回 `error`；`Get` 通过 `found` 区分“未命中”和“命中了 nil”。

## 配置

`config/cache.json`：

```json
{
    "default": "file",
    "stores": {
        "file": {
            "type": "file",
            "path": "./runtime/cache"
        },
        "memory": {
            "type": "memory"
        },
        "redis": {
            "type": "redis",
            "host": "127.0.0.1",
            "port": 6379,
            "password": "",
            "select": 0,
            "prefix": "thinkgo:",
            "timeout_ms": 3000,
            "allow_flush_db": false
        }
    }
}
```

`default` 必须引用已配置的 store。顶层、store 和 Redis 配置中的未知字段、错误类型、非法范围都会形成应用启动错误，不会回退到其他驱动。旧的 `expire` 字段已移除；过期时间只由每次 `Set`/`Remember` 调用的 TTL 决定。

文件缓存的相对 `path` 以应用根目录解析，不能通过 `..` 离开根目录；绝对路径表示显式使用外部目录。

## 基础用法

```go
if err := app.Cache.Set("user:1", user, time.Minute); err != nil {
	return err
}

value, found, err := app.Cache.Get("user:1")
if err != nil {
	return err
}
if found {
	// value 允许为 nil。
}

exists, err := app.Cache.Has("user:1")
if err != nil {
	return err
}

if err := app.Cache.Forget("user:1"); err != nil {
	return err
}
if err := app.Cache.Forever("site:name", "ThinkGo"); err != nil {
	return err
}
if err := app.Cache.Flush(); err != nil {
	return err
}
```

缓存键不能为空、不能包含控制字符、不能超过 1024 字节，也不能使用 `__thinkgo_tag__:`、`__thinkgo_tag_reverse__:`、`__thinkgo_lock__:` 内部前缀。TTL 为 `0` 表示永久，负数或超过 100 年会被拒绝。

未安装驱动时操作返回 `cache.ErrCacheDriverNotConfigured`；管理器关闭后返回 `cache.ErrCacheClosed`。后端文件、网络、SQL 和序列化错误均原样向上传播。

## Remember

```go
value, err := app.Cache.Remember("stats", time.Minute, func() (interface{}, error) {
	return loadStats()
})
```

同一进程内，同 store、同 key 的并发未命中只执行一次回调。回调错误或写入错误会返回且不伪造成功；命中的 nil 不会再次执行回调。进程间防击穿应配合缓存锁。

## 多 store

```go
redisStore, err := app.Cache.Store("redis")
if err != nil {
	return err
}
if err := redisStore.Set("key", "value", time.Minute); err != nil {
	return err
}
```

所有配置 store（包括默认 store）都可按名称访问。非法或不存在的名称返回错误，不会回退到当前 store。`RegisterStore` 对同一驱动幂等，但拒绝用另一个驱动静默替换同名 store。

## 计数

```go
n, err := app.Cache.Inc("counter", 1)
if err != nil {
	return err
}
n, err = app.Cache.Dec("counter", 1)
```

计数只接受可精确转换为 `int64` 的整数值和非负步长，小数、字符串、无穷值及溢出都会返回错误。过期或不存在的计数从 `0` 开始，已有 TTL 保持不变。

Redis 使用后端原子计数。Memory、File 和 DB 驱动保证同一驱动实例内的并发安全；跨进程计数优先使用 Redis。

## 标签缓存

```go
tagged, err := app.Cache.Tag("user", "profile")
if err != nil {
	return err
}
if err := tagged.Set("user:1", user, time.Minute); err != nil {
	return err
}
if err := tagged.Flush(); err != nil {
	return err
}
```

标签名必须是 1 至 128 字节的有效文本，单键最多 64 个标签，单标签最多 10000 个成员。标签写入维护正向和反向元数据；任一步骤失败会执行补偿回滚。普通 `Cache.Forget` 也会清理全部标签关系，`TaggedCache.Get/Has` 发现自然过期时会清理陈旧元数据。

同一缓存管理器内的标签变更会串行化；不同进程间不提供强事务标签更新，分布式强一致索引不应依赖标签成员列表。

## 缓存锁

```go
lock, err := app.Cache.Lock("sync:user:1", 10*time.Second)
if err != nil {
	return err
}
acquired, err := lock.Acquire()
if err != nil {
	return err
}
if acquired {
	defer func() {
		_, _ = lock.Release()
	}()
	// 执行互斥逻辑。
}
```

锁 TTL 为 `0` 时使用 10 秒默认值，最大 24 小时。owner 使用加密随机数生成。Memory 提供进程内锁，File 使用独占锁文件，Redis 使用 `SET NX` 和 owner 校验 Lua 脚本；DB 驱动不支持锁。

普通 `Flush` 不释放 Memory、File 和带前缀 Redis 中的活动锁。空前缀 Redis 在显式授权 `allow_flush_db=true` 后执行 `FLUSHDB`，会清除所选 DB 的全部数据和锁。

## 驱动行为

### Memory

- 保留写入值的 Go 动态类型，包括命中的 nil。
- 过期项按读取和周期扫描惰性回收。
- `Clear` 只清理缓存值，不清理锁。

### File

- `driver.NewFile(path)` 返回 `(*driver.File, error)`，目录不可用时立即失败。
- 使用 SHA-256 把业务键映射为固定文件名，单项读取上限为 16 MiB。
- 值使用 JSON 存储；读取后的 JSON 数值类型为 `float64`。
- 写入使用同目录临时文件、同步和原子替换；读取拒绝符号链接、目录和超大项。
- 过期删除按已读取文件身份执行，不会误删并发替换的新文件。
- `Clear` 仅删除 `.cache` 和超过一小时的缓存临时文件，保留 `.lock` 与非缓存文件。

### Redis

- `driver.NewRedis(config)` 返回 `(*driver.Redis, error)`，配置在创建阶段严格校验。
- 地址使用安全的 host/port 组合，支持 IPv4、IPv6 和合法主机名。
- 值统一 JSON 序列化；损坏数据和网络错误会返回，不按未命中处理。
- `timeout_ms` 范围为 0 至 60000；`0` 使用 3 秒默认值。
- 非空 `prefix` 的 `Clear` 使用字面量转义后的 `SCAN`，只删除该前缀业务数据并保留框架锁。
- 空 `prefix` 默认返回 `driver.ErrUnsafeRedisFlush`；仅独占 DB 可显式设置 `allow_flush_db=true`。

### DB

- `driver.NewDB(connection, table)` 返回 `(*driver.DB, error)`，空连接和不安全表名会被拒绝。
- `EnsureTable` 创建 `key`、`value`、`expiry` 字段，并使用当前 SQL 方言引用标识符。
- 值使用 JSON 存储，TTL 使用毫秒时间戳，并兼容读取旧的秒级过期值。
- 过期清理同时匹配读取到的旧 expiry，避免删除并发刷新值。
- 键最大 255 字节；DB 驱动不实现缓存锁。

## 关闭与调试

`app.Close()` 会在数据库和日志之前关闭所有唯一的可关闭缓存驱动，并等待活动缓存调用结束。直接创建缓存管理器时也应处理 `Cache.Close()` 的错误。

Trace 启用时，缓存操作会记录到请求级 Debug 数据中。Trace 面板只对本机回环请求开放。
