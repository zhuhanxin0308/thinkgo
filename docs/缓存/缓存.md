# 缓存

缓存入口是 `app.Cache`。框架支持多 store、标签缓存、原子计数和缓存锁。

## 配置

`config/cache.json`：

```json
{
    "default": "file",
    "stores": {
        "file": {
            "type": "file",
            "path": "./runtime/cache"
        },
        "redis": {
            "type": "redis",
            "host": "127.0.0.1",
            "port": 6379,
            "password": "",
            "select": 0,
            "prefix": "thinkgo:",
            "timeout_ms": 3000
        }
    }
}
```

默认 store 未配置或类型非法时回退到文件缓存。
直接构造缓存管理器且未提供驱动时，公开 API 会降级为空操作：`Get` 返回 `nil`，`Has` 返回 `false`，`Inc/Dec` 返回 `0`，`Remember` 返回回调结果但不写入存储。

## 基础用法

```go
app.Cache.Set("user:1", user, time.Minute)
value := app.Cache.Get("user:1")
exists := app.Cache.Has("user:1")
app.Cache.Forget("user:1")
app.Cache.Forever("site:name", "ThinkGo")
app.Cache.Flush()
```

`Remember`：

```go
value := app.Cache.Remember("stats", time.Minute, func() interface{} {
	return loadStats()
})
```

## 多 store

```go
app.Cache.Store("redis").Set("key", "value", time.Minute)
```

未找到指定 store 时返回当前缓存实例，不会 panic。

## 计数

```go
n := app.Cache.Inc("counter", 1)
n = app.Cache.Dec("counter", 1)
```

过期计数项再次 `Inc/Dec` 时按不存在处理，从 `0` 开始计算。

Redis 的 `Inc/Dec` 是原子操作；文件缓存和 DB 缓存通过进程内锁保证单进程原子，跨进程计数应使用 Redis 或分布式锁。

## 标签缓存

```go
app.Cache.Tag("user").Set("user:1", user, time.Minute)
app.Cache.Tag("user").Forget("user:1")
app.Cache.Tag("user").Flush()
```

标签关系使用元数据键维护。多进程场景下标签成员更新不是强事务语义，关键业务请谨慎使用。

## 缓存锁

```go
lock := app.Cache.Lock("sync:user:1", 10*time.Second)
if lock.Acquire() {
	defer lock.Release()
	// 执行需要互斥的逻辑。
}
```

文件驱动通过锁文件实现跨进程锁；Redis 驱动使用 `SET NX` 获取锁，并通过 Lua 脚本保证只有 owner 匹配时才能释放。

## 驱动行为

文件缓存：

- 使用 SHA-256 把缓存键映射为文件名。
- 写入时先写临时文件，再原子重命名。
- `Flush` 只删除本驱动生成的 `.cache`、`.lock` 和临时缓存文件。

Redis 缓存：

- 值统一 JSON 序列化，读取时反序列化。
- `timeout_ms` 控制单次 Redis 操作超时，默认 3 秒。
- 配置 `prefix` 时 `Flush` 只按前缀扫描删除。
- 未配置 `prefix` 时 `Flush` 会执行 `FLUSHDB`，只适合独占 DB。

DB 缓存：

- `EnsureTable` 会创建包含 `key`、`value`、`expiry` 的缓存表，并拒绝不安全表名；SQL 连接会按当前方言引用标识符，SQL Server 使用 `OBJECT_ID` 判表后建表。
- DB 驱动适合单进程或低并发场景；跨进程计数和锁语义优先使用 Redis。

## 调试

Trace 启用时，缓存操作会记录到请求级 Debug 数据中。Trace 面板只对本机回环请求开放。
