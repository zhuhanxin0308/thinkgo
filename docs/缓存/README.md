# 缓存

`framework/cache` 把缓存键、多个 store、标签、并发加载、计数、锁和驱动生命周期统一到 `cache.Cache`。应用通过 `framework.ServiceCache` 解析缓存服务，具体后端位于 `framework/cache/driver`。

本目录按能力拆分：

- [缓存基础](缓存基础.md)：命中语义、TTL、常用读写和计数 API。
- [缓存 Store 与配置](缓存Store与配置.md)：多 store、配置结构和应用初始化。
- [Remember 与计数](Remember与计数.md)：并发合并加载、整数精度和溢出边界。
- [标签缓存](标签缓存.md)：标签绑定、反向元数据、过期清理和回滚。
- [缓存锁](缓存锁.md)：进程级/分布式锁、owner 校验和 TTL。
- [缓存驱动](缓存驱动.md)：Memory、File、Redis 和 DB 驱动的差异。
- [缓存生命周期](缓存生命周期.md)：关闭、并发操作和调试追踪。
- [缓存错误与安全](缓存错误与安全.md)：命名空间、大小限制、清理边界和错误语义。

缓存调用返回后端错误，业务代码必须处理错误。`Get` 的 `found` 与值分离，因此可以区分“命中 nil”和“未命中”；不要只用返回值是否为 nil 判断命中。
