# 缓存驱动

驱动必须实现 `cache.Driver`：

```go
type Driver interface {
	Get(string) (interface{}, bool, error)
	Set(string, interface{}, time.Duration) error
	Has(string) (bool, error)
	Delete(string) error
	Clear() error
	Inc(string, int64) (int64, error)
	Dec(string, int64) (int64, error)
}
```

锁驱动可选实现：

```go
type DistributedLocker interface {
	AcquireLock(key, owner string, ttl time.Duration) (bool, error)
	ReleaseLock(key, owner string) (bool, error)
}

type LockRenewer interface {
	RenewLock(key, owner string, ttl time.Duration) (bool, error)
}
```

所有驱动都应返回明确错误；`Get` 必须通过 `found` 保留 nil 命中语义，`Clear` 不应在未显式授权时破坏驱动之外的数据或活动锁。

`TaggedCache` 的标签变更锁在驱动只实现 `DistributedLocker` 时仍可使用，但必须保证 TTL 覆盖临界区；`RememberWithLock` 为了在写回前确认 owner 仍有效，要求驱动同时实现 `DistributedLocker` 和 `LockRenewer`，支持续租的驱动会按租约自动续期。

## Memory

```go
memory := driver.NewMemory()
```

Memory 保留 Go 动态值类型，支持 nil、TTL、严格计数和进程内锁；写入和读取会复制常见可变值，避免 map、slice 或指针被调用方旁路修改。过期项在读取时删除，并按约一分钟的周期扫除长期残留。它不跨进程共享，适合测试、单进程临时数据和不要求跨实例一致性的场景。

## 有界 Memory 与标签缓存

使用 `NewMemoryWithMaxEntries` 或配置 `max_entries` 后，容量上限同时约束业务缓存项和框架标签元数据。标签元数据会被标记为受保护项：容量不足时不会被 FIFO 淘汰；如果没有可安全淘汰的普通业务项，写入会返回 `driver.ErrMemoryCapacityExhausted`，调用方应按缓存未命中或降级路径处理。

标签缓存需要为每个标签关系保留元数据项，因此生产环境设置上限时必须把标签开销计入预算。容量不足不会破坏已有标签关系，也不会改变未配置 `max_entries` 时的无限容量兼容行为。

## File

```go
file, err := driver.NewFile("./runtime/cache")
```

File 在构造时创建并解析根目录，目录使用最小权限。业务键通过 SHA-256 映射为 `.cache` 文件名，值以 JSON 保存；单项读取上限为 16 MiB。写入采用临时文件、同步和原子替换，读取/删除会复核普通文件身份，拒绝符号链接逃逸。

File 的 `Clear` 删除受管 `.cache` 文件和超过一小时的 `.tmp-cache-*` 临时文件，保留 `.lock`、非缓存文件和目录。计数操作使用分片进程锁；文件锁使用独占创建、同一句柄 OS 文件锁和原地载荷更新，校验 owner、过期时间和文件身份，并支持 owner 续租。损坏锁文件只有在满足恢复年龄后才允许被新 owner 原地接管，避免路径删除与新锁获取竞态。

## Redis

```go
redis, err := driver.NewRedis(map[string]interface{}{
	"host": "127.0.0.1",
	"port": 6379,
	"prefix": "thinkgo:",
	"timeout_ms": 1500,
})
```

支持的配置字段为 `host`、`port`、`password`、`select`、`timeout_ms`、`prefix`、`allow_flush_db`、`tls_enable`、`tls_server_name` 和 `tls_insecure_skip_verify`。默认主机为 `127.0.0.1`、端口为 6379、操作超时为 3 秒；超时配置最大 60000 毫秒，前缀最大 256 字节且不能包含控制字符。启用 TLS 时最低版本为 TLS 1.2，跳过证书校验必须显式配置。构造阶段严格校验但不主动发起业务连接。

值以 JSON 保存，计数使用 Redis 原子命令，锁使用 `SET NX`、owner 校验 Lua 和租约续期 Lua。带前缀的 `Clear` 使用转义后的 SCAN 模式，只删除当前前缀并跳过锁键；空前缀默认拒绝清理，只有 `allow_flush_db=true` 才允许整库范围清理，但仍保留 ThinkGo 活动锁。

## DB

```go
databaseCache, err := driver.NewDB(conn, "thinkgo_cache")
if err != nil {
	return err
}
if err := databaseCache.EnsureTable(); err != nil {
	return err
}
```

DB 驱动使用 `key`、`value`、`expiry` 三列，值以 JSON 保存，TTL 以毫秒时间戳保存，`EnsureTable` 会根据 SQL 方言生成建表语句。表名只允许字母、数字和下划线，键最长 255 字节；它依赖连接的原生执行能力来建表。

DB 的 upsert 会处理并发首次写入和“匹配但未变化返回 0”的数据库语义，过期删除会带旧 expiry 条件避免误删并发刷新后的新值。DB 驱动使用表内条件更新实现 owner/expiry 约束的分布式锁；`Set`、`Delete`、`Clear` 和 `Inc`/`Dec` 的修改临界区统一使用表级租约并自动续期，避免 `Clear` 与并发写入交错，`Clear` 保留活动锁记录。数据库连接与缓存表也会暴露资源标识，防止同一管理器注册重复 namespace。
