# 路由冻结与快照

路由器分为注册期和只读匹配期。`Freeze` 会解析所有路径、编译约束、建立静态索引和方法/域名/路径段动态 Trie，并按优先级排序：

```go
if err := router.Freeze(); err != nil {
	return err
}
```

`Match`、`URL` 和 `Routes` 会在需要时自动触发 `Freeze`；HTTP 内核在启动前也会冻结路由。

冻结后的动态索引是不可变快照，匹配只读取索引候选，再调用既有最终匹配器校验参数、正则、域名和扩展名。HEAD、OPTIONS、405、ANY、MISS、自动路由和命名 URL 的外部语义不由索引改变；注册期仍使用原有重复检查和错误返回。

冻结成功后，以下操作都会返回 `ErrRouterFrozen`：

- 注册新路由、分组路由、MISS 或资源路由；
- `WithName`、`WithPattern`、`WithDomain`、`WithExtension`；
- `WithoutMiddleware`、`Only`、`Except`；
- 开关自动路由或修改默认控制器/动作。

冻结失败也会被记住。后续再次调用 `Freeze`、`Match`、`URL` 或 `Routes` 会返回同一个失败原因，不会把失败状态误报为成功。

## 路由快照

```go
routes, err := router.Routes()
if err != nil {
	return err
}
```

返回值是 `[]RouteInfo` 快照，包含 `Method`、`Path`、`Handler`、`Name`、`Domain`、`Extension`、`Auto` 和 `MiddlewareCount`。快照切片不会暴露内部路由列表，适合 `route:list`、调试和权限目录读取。

路由对象的只读访问器使用路由器锁；`Middlewares` 返回副本。不要通过反射或保存内部引用绕过冻结语义。
