# 自动路由

自动路由默认关闭。`config/route.json` 中 `url_route_must` 默认按安全基线视为 `true`；只有显式设置为 `false`（或字符串 `false`、`0`）时，应用才会调用 `EnableAutoRoute(true)`。

也可以直接配置：

```go
if err := router.EnableAutoRoute(true); err != nil {
	return err
}
if err := router.SetDefaultController("Index"); err != nil {
	return err
}
if err := router.SetDefaultAction("index"); err != nil {
	return err
}
```

## 解析规则

```text
/                  -> Index@Index
/user              -> User@Index
/user/edit         -> User@Edit
/admin/user/edit   -> Admin.User@Edit
```

单段路径把段首字母大写后作为控制器；多段路径把最后一段作为动作，前面的段组成点分隔控制器层级。控制器和动作最终会生成 `Controller@Action` 处理器，动作首字母也会大写。

根路径使用 `SetDefaultController` 和 `SetDefaultAction` 的默认值，默认值分别为 `Index` 和 `index`。

## 方法与安全边界

自动路由只生成 GET 语义，并允许 HEAD 回落和自动 OPTIONS。对自动路由路径发送 POST、PUT 等写方法会返回 405，不会通过 URL 自动调用写操作。

路径段必须能映射为 Go 标识符：首字符是字母或下划线，后续只能是字母、数字或下划线。包含点号扩展名、连字符、空段、`..` 或非法解码内容的请求不会解析为自动路由。框架也会屏蔽基础控制器导出的内置方法，但业务控制器的导出只读动作仍可能被暴露，因此生产环境应保持显式路由。

## 配置边界

当前 `App.applyRouteConfig` 实际消费的字段只有 `url_route_must`、`default_controller` 和 `default_action`。配置文件中存在的 `url_case_sensitive`、`route_complete_match`、`controller_layer`、`url_html_suffix`、`remove_slash` 当前不会改变 `framework/route` 的行为，不应把它们当作已实现功能依赖。
