# 路由参数与约束

动态路径段使用 `:name`，可选段使用 `:name?`：

```go
detail, err := router.Get("/users/:id/posts/:slug?", "Post@Show")
if err != nil {
	return err
}
if err := detail.WithPattern("id", `[0-9]+`); err != nil {
	return err
}
```

参数名必须是字母或下划线开头、后续由字母、数字和下划线组成；同一路径不能重复参数名。可选参数最多 8 段，整条路径最多 64 段。

匹配成功后，`Router.Match` 返回参数 map。路径段会先做 URL 解码，因此 `%2F` 作为一个编码段可以成为参数值中的 `/`；原始请求路径中的真实空段、反斜线、点段、控制字符和非法转义会被拒绝。

## 正则约束

`WithPattern` 只能约束路径中已经声明的参数。框架会自动添加整值锚定，相当于只接受完整匹配：

```go
if err := detail.WithPattern("id", `[0-9]+`); err != nil {
	return err
}
```

正则不能为空、最长 512 字节，不能包含命名捕获组语法；编译失败返回 `ErrInvalidRoutePattern`。约束设置发生在注册期，冻结后不能再修改。

动态路由的优先级会考虑静态段、普通参数、正则参数和可选参数。静态段更多的路由优先于通配性更强的路由。

冻结后这些优先级被编码到方法/域名/路径段索引中，但索引只提供候选，不替代最终约束校验。正则不匹配、域名不匹配或扩展名不匹配时会继续尝试同级候选，不能因为索引命中就放宽参数边界。

## 扩展名约束

```go
if err := detail.WithExtension("json"); err != nil {
	return err
}
```

扩展名会参与匹配和命名 URL 生成。它会去掉一个前导点并转为小写，只允许字母、数字、短横线和下划线，最长 32 字符。上例只匹配 `/users/1.json`，不会匹配没有 `.json` 的路径。

扩展名不是普通参数的一部分；生成 URL 时框架会在最后一个路径段后追加扩展名，并对参数值执行路径转义。

## 请求路径边界

请求转为匹配段时，完整转义路径最长 2048 字节，最多 64 段，必须以 `/` 开始且不能包含反斜线或连续斜线。请求段解码后不能是空串、`.`、`..`，也不能包含反斜线、空字节、回车或换行。非法路径返回 `ErrInvalidRequestPath`，过于复杂返回 `ErrRouteTooComplex`。
