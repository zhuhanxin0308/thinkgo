# 路由参数与约束

动态路径段使用 `:name`，可选段使用 `:name?`：

```go
Route.Get("users/:id/posts/:slug?", "post/show").
	Pattern(map[string]string{
		"id": `[0-9]+`,
	})
```

参数名必须以字母或下划线开头，后续由字母、数字和下划线组成；同一路径不能重复参数名。可选参数最多 8 段，整条路径最多 64 段。

控制器动作可以直接声明同名参数：

```go
func (*Post) Show(id int, slug string) *framework.Response {
	return framework.NewResponse().Json(map[string]interface{}{
		"id": id,
		"slug": slug,
	})
}
```

## 正则约束

`Pattern` 接收参数名到正则表达式的映射，只能约束路径中已经声明的参数。框架自动执行整值匹配：

```go
Route.Get("users/:id", "user/read").
	Pattern(map[string]string{"id": `[0-9]+`})
```

正则不能为空，最长 512 字节，不能包含命名捕获组；非法约束会在路由加载阶段中止。

## 扩展名约束

```go
Route.Get("users/:id", "user/read").Ext("json")
```

上例只匹配 `/users/1.json`。扩展名会去掉一个前导点并转为小写，只允许字母、数字、短横线和下划线，最长 32 个字符。

## 请求路径边界

完整转义路径最长 2048 字节，最多 64 段，必须以 `/` 开始，不能包含反斜线或连续斜线。解码后的请求段不能是空串、`.`、`..`，也不能包含反斜线、空字节、回车或换行。

非法路径返回 400；过于复杂的路径不会进入控制器。
