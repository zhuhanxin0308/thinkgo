# 路由

每个业务应用在 `app/<应用名>/route/app.go` 注册自己的路由，控制器由同一应用目录静态发现。HTTP 宿主先选择应用，再使用该应用独立 Router 匹配；不同应用可以安全复用相同路径和控制器名称。

本目录按能力拆分：

- [路由定义](路由定义.md)：HTTP 方法、处理器、路径规范和多方法规则。
- [路由分组与域名](路由分组与域名.md)：应用内分组、域名约束和中间件继承。
- [路由参数与约束](路由参数与约束.md)：动态参数、可选参数、正则和扩展名。
- [路由匹配](路由匹配.md)：索引、优先级、MISS、默认调度和 OPTIONS。
- [命名路由与 URL](命名路由与URL.md)：应用上下文与参数化 URL。
- [资源、重定向与 MISS](资源、重定向与MISS.md)。
- [自动路由](自动路由.md)。
- [路由冻结与快照](路由冻结与快照.md)。
- [路由错误与安全](路由错误与安全.md)。

所有编译期应用的正式路由加载器会在网络监听前执行并冻结。注册、加载或冻结任一失败都会阻断宿主启动；`route:list --app <name>` 使用相同加载路径。
