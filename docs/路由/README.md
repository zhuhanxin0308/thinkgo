# 路由

`framework/route` 负责路由注册、冻结、匹配和命名地址生成。业务路由通常放在 `app/<应用名>/route` 包的加载器中，由所属应用初始化阶段执行；控制器字符串必须先完成当前应用的控制器注册。

本目录按能力拆分：

- [路由定义](路由定义.md)：HTTP 方法、处理器、路径规范和多方法规则。
- [路由分组与域名](路由分组与域名.md)：前缀、嵌套分组、域名约束和中间件继承。
- [路由参数与约束](路由参数与约束.md)：动态参数、可选参数、正则约束和扩展名。
- [路由匹配](路由匹配.md)：静态/动态索引、匹配优先级、HEAD、OPTIONS 和 405。
- [命名路由与 URL](命名路由与URL.md)：路由名称和参数化 URL 生成。
- [资源、重定向与 MISS](资源、重定向与MISS.md)：资源路由、重定向和未命中处理器。
- [自动路由](自动路由.md)：显式开关、控制器动作解析和安全限制。
- [路由冻结与快照](路由冻结与快照.md)：冻结时机、只读索引和路由元数据快照。
- [路由错误与安全](路由错误与安全.md)：注册错误、请求路径边界和安全校验。

所有注册和配置方法都返回 `error`；不要忽略加载器、路由配置或 `Freeze` 的错误。应用启动会冻结路由，冻结失败时 `App.Run()` 不会启动半初始化的 HTTP 服务。
