# 路由分组与域名

业务路由通过 `*framework.Route` 使用 ThinkPHP 风格链式 API，不需要解析底层 Router；`*framework.RuleGroup` 仅作为可选的 Go 强类型写法。

## 前缀分组

```go
Route.Group("api", func() {
	Route.Get("users", "user/index")
	Route.Get("users/:id", "user/read")
}, authMiddleware)
```

子路由最终路径为 `/api/users` 和 `/api/users/:id`。嵌套分组继续调用 `Route.Group`，回调结束后自动恢复父分组作用域。

## 域名分组

```go
Route.Domain("api.example.com", func() {
	Route.Get("users", "user/index")
})

Route.DomainGroup("admin.example.com", "v1", func() {
	Route.Get("users", "admin.user/index")
})
```

域名只表示精确主机约束，不接受协议、路径、端口、空白或通配符。请求匹配时忽略端口、域名大小写和末尾点；精确域名路由优先于同路径的无域名路由。

## 中间件继承

```go
Route.Group("account", func() {
	Route.Get("profile", "user/profile", auditMiddleware)
}, authMiddleware)
```

执行顺序为外层分组、中层分组、路由自身。单条路由也可以继续链式增删中间件：

```go
Route.Get("profile", "user/profile").
	Middleware(authMiddleware, auditMiddleware).
	WithoutMiddleware(auditMiddleware)
```

## 单路由域名

```go
Route.Get("users", "user/index").Domain("api.example.com")
```

所有分组和链式配置必须在 `route` 加载阶段完成；路由冻结后不会在请求处理中动态改变。
