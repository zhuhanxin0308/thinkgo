# 路由分组与域名

分组通过不可变的 `route.Group` 注册作用域组合前缀、域名和中间件。父作用域不会被子作用域修改，适合嵌套或并发构建。

以下示例中的 `router` 由 `framework.ResolveServiceAs[*route.Router](app, framework.ServiceRoute)` 获取。

## 前缀分组

```go
err := router.Group("/api", func(api *route.Group) error {
	_, err := api.Get("/users", "User@Index")
	return err
}, authMiddleware)
```

子路由最终路径为 `/api/users`。嵌套分组会继续拼接前缀；分组回调不能为 nil。分组前缀和子路径沿用路由路径的规范校验。

## 域名分组

```go
err := router.Domain("api.example.com", func(api *route.Group) error {
	_, err := api.Get("/users", "User@Index")
	return err
})

err = router.DomainGroup("admin.example.com", "/v1", func(admin *route.Group) error {
	_, err := admin.Get("/users", "Admin@Index")
	return err
})
```

域名分组可以继续嵌套。域名只表示精确主机约束，不接受协议、路径、端口、空白、通配符或控制字符。注册时会转为小写并移除末尾点；IPv4、IPv6 和普通 DNS 标签都支持。

请求主机匹配时会忽略端口、大小写和末尾点。精确域名路由优先于相同路径的无域名路由；如果精确域名没有匹配的路径/方法，不会错误回退到其它域名。

## 中间件继承

路由级中间件直接作为注册参数：

```go
_, err := router.Get("/profile", "User@Profile", authMiddleware, auditMiddleware)
```

分组中间件会先于子路由中间件，顺序为“外层到内层，再到路由自身”。空中间件会返回 `ErrInvalidRouteMiddleware`。

可以在冻结前移除路由级中间件：

```go
if err := registered.WithoutMiddleware(auditMiddleware); err != nil {
	return err
}
```

移除按函数指针识别。目标不存在、目标在当前路由中出现多次导致身份歧义、目标为 nil 或路由已冻结时都会失败关闭，不会静默移除其它函数。

单路由也可以使用 `WithDomain` 设置域名约束；它会再次检查重复路由。域名、前缀和中间件的所有修改都必须在冻结前完成。
