# 路由定义

应用路由通过 `framework.ServiceRoute` 解析为 `*route.Router`，不再作为 `App` 的公开字段。路由加载器可先解析：

```go
func Load(app *framework.App) error {
	router, err := framework.ResolveServiceAs[*route.Router](app, framework.ServiceRoute)
	if err != nil {
		return err
	}
	_, err = router.Get("/", func(req *context.Request) *context.Response {
		return context.NewResponse().Content("ThinkGo")
	})
	return err
}
```

应用通过所属 `application.go` 的 `app.RegisterRouteLoader(Load)` 注册加载器。加载器返回的错误或 panic 会进入当前 `App.StartupError()`，不会影响其它应用的路由注册表。

## HTTP 方法

快捷方法包括：

```text
Get Post Put Delete Patch Options Head Any
```

通用入口是 `Add(method, path, handler, middlewares...)`。方法会被转为大写；`Any` 使用内部通配方法，普通自定义方法只允许 HTTP token 字符。重复的“方法 + 路径 + 域名 + 扩展名”会返回 `ErrDuplicateRoute`。

`Rule` 用竖线一次注册多个方法：

```go
routes, err := router.Rule("/health", "Health@Check", "GET|HEAD")
```

`Rule` 会先准备全部定义，再一次性注册。包含空方法、重复方法或任一非法定义时，不会留下部分路由。

## 处理器

支持两种处理器：

```go
// 控制器动作。
"User@Index"

// 标准闭包。
func(req *context.Request) *context.Response {
	return context.NewResponse().Json(map[string]interface{}{"ok": true})
}
```

控制器字符串必须严格为 `Controller@Action`。控制器名称可以包含以点分隔的层级，每一段必须是合法 Go 风格标识符；动作必须是合法标识符。闭包签名必须是 `func(*context.Request) *context.Response`，类型化 nil 也会被拒绝。

## 路径规范化

路径为空时按 `/` 处理；缺少首斜线时会补齐，末尾一个斜线会被移除。注册路径不能包含空段、反斜线、`#`、点段、空字节、回车或换行；`/users//list` 和 `/users/../list` 都会失败。

路径规范化不会把不同路由合并成模糊匹配。注册成功后仍应处理返回的 `*route.Route`，再设置名称、参数正则、域名或扩展名。

## 路由对象

```go
registered, err := router.Get("/users/:id", "User@Show")
if err != nil {
	return err
}
if err := registered.WithName("users.show"); err != nil {
	return err
}
```

路由对象提供 `Method`、`Path`、`Handler`、`Name`、`ControllerAction`、`IsAuto` 和 `Middlewares` 只读访问器。`Middlewares` 返回防御性副本；冻结后所有配置方法都会返回 `ErrRouterFrozen`。
