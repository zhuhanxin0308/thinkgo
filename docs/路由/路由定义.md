# 路由定义

业务路由写在 `app/<应用名>/route`。每个应用的 `route/app.go` 接收独立 `*framework.Route`，调用方式与 ThinkPHP 的 Route facade 对齐：

```go
package route

import "github.com/zhuhanxin0308/thinkgo/framework"

func Load(Route *framework.Route) {
	Route.Get("users", "user/index")
	Route.Post("users", "user/save")
	Route.Get("users/:id", "user/read")
}
```

开发者不需要解析底层 Router、注册路由加载器或逐条处理装配错误。非法路由定义会在路由加载阶段中止，并进入统一启动/请求错误处理。

## HTTP 方法

```go
Route.Get("users", "user/index")
Route.Post("users", "user/save")
Route.Put("users/:id", "user/update")
Route.Delete("users/:id", "user/delete")
Route.Patch("users/:id", "user/patch")
Route.Head("health", "health/check")
Route.Options("users", "user/options")
Route.Any("probe", "probe/index")
```

`Rule` 未指定方法时匹配任意方法；多个方法使用竖线分隔：

```go
Route.Rule("health", "health/check")
Route.Rule("users", "user/index", "GET|POST")
```

## 处理器

控制器动作使用 ThinkPHP 的斜线写法：

```go
Route.Get("users", "user/index")
Route.Get("users/:id", "user/read")
```

也可以使用闭包：

```go
Route.Get("think", func() string {
	return "hello,ThinkPHP8!"
})

Route.Get("hello/:name", func(name string) string {
	return "hello," + name
})
```

闭包返回值与控制器动作一样会自动转换为响应，路由变量按声明顺序绑定；`App`、`Request` 和业务服务可按类型注入。底层扩展仍支持标准库 `http.Handler` 和 `func(http.ResponseWriter, *http.Request)`。

## 链式配置

```go
Route.Get("users/:id", "user/read").
	Name("users.read").
	Pattern(map[string]string{"id": `\d+`}).
	Domain("api.example.com").
	Ext("json")
```

常用链式 API：

- `Name`：设置命名路由。
- `Pattern`：设置一个或多个路由变量规则。
- `Domain`：设置精确域名约束。
- `Ext`：设置 URL 后缀约束。
- `Middleware`：追加路由中间件。
- `WithoutMiddleware`：移除继承的中间件。

## 分组

```go
Route.Group("api", func() {
	Route.Get("users", "user/index")
	Route.Get("users/:id", "user/read")
})
```

分组回调与 ThinkPHP 一样不需要参数，嵌套时继续调用 `Route.Group`。如需显式持有独立作用域，也兼容 `func(group *framework.RuleGroup)` 写法。

## 资源路由

```go
Route.Resource("users", "user")
Route.Resource("articles", "article").Only("index", "read")
Route.Resource("orders", "order").Except("delete")
```

资源动作名称和方法映射见[资源、重定向与 MISS](资源、重定向与MISS.md)。
