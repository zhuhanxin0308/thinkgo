# 路由

ThinkGo 路由集中定义在 `route` 包，通过 `framework.RegisterRouteLoader` 注册加载函数。

## 路由定义

```go
package route

import (
	"thinkgo/framework"
	"thinkgo/framework/context"
)

func init() {
	framework.RegisterRouteLoader(Load)
}

func Load(app *framework.App) {
	app.Route.Get("/", func(req *context.Request) *context.Response {
		return context.NewResponse().Content("ThinkGo")
	}).Name("home")

	app.Route.Get("/api/users", "User@Index").Name("users.index")
	app.Route.Post("/api/users", "User@Save")
	app.Route.Get("/api/users/:id", "User@Read").Pattern("id", `\d+`)
}
```

支持的方法：

```text
Get Post Put Delete Patch Options Head Any Rule
```

`Rule(path, handler, "GET|POST")` 可以一次注册多方法路由。

## 路由地址

路由处理器可以是闭包：

```go
app.Route.Get("/ping", func(req *context.Request) *context.Response {
	return context.NewResponse().Json(map[string]interface{}{"pong": true})
})
```

也可以是控制器字符串：

```go
app.Route.Get("/api/users", "User@Index")
```

控制器字符串格式必须是 `Controller@Action`。控制器需要先通过 `framework.RegisterController` 注册。

## 变量规则

动态参数使用 `:name`：

```go
app.Route.Get("/api/users/:id", "User@Read")
```

可用 `Pattern` 约束参数：

```go
app.Route.Get("/api/users/:id", "User@Read").Pattern("id", `\d+`)
```

`Pattern` 中的正则如果编译失败，该参数路由会失败关闭，不会退化为无约束匹配。

可选参数使用 `:name?`。

## 路由分组

```go
app.Route.Group("/api", func() {
	app.Route.Get("/users", "User@Index")
	app.Route.Post("/users", "User@Save")
})
```

分组可以传入中间件：

```go
app.Route.Group("/admin", func() {
	app.Route.Get("/users", "AdminUser@Index")
}, authMiddleware)
```

## 域名路由

```go
app.Route.Domain("api.example.com", func() {
	app.Route.Get("/users", "User@Index")
})

app.Route.DomainGroup("api.example.com", "/v1", func() {
	app.Route.Get("/users", "User@Index")
})
```

域名匹配会忽略端口、大小写和末尾点。

## 路由中间件

路由级中间件直接作为参数传入：

```go
app.Route.Get("/api/profile", "User@Profile", authMiddleware)
```

`WithoutMiddleware` 可以从当前路由移除指定中间件。

## 资源路由

```go
app.Route.Resource("/api/users", "User")
```

会生成：

| 动作 | 方法 | 路径 | 控制器 |
|---|---|---|---|
| `index` | GET | `/api/users` | `User@Index` |
| `create` | GET | `/api/users/create` | `User@Create` |
| `save` | POST | `/api/users` | `User@Save` |
| `read` | GET | `/api/users/:id` | `User@Read` |
| `edit` | GET | `/api/users/:id/edit` | `User@Edit` |
| `update` | PUT | `/api/users/:id` | `User@Update` |
| `delete` | DELETE | `/api/users/:id` | `User@Delete` |

裁剪动作：

```go
app.Route.Resource("/api/users", "User").Only("index", "read")
app.Route.Resource("/api/users", "User").Except("delete")
```

## MISS 路由

```go
app.Route.Miss(func(req *context.Request) *context.Response {
	return context.NewResponse().Code(404).Json(map[string]interface{}{
		"message": "not found",
	})
})
```

没有 MISS 路由时，`/api/` 前缀未命中返回 404；非 `/api/` 路径会尝试返回 `public/index.html` 作为 SPA fallback。

## 重定向路由

```go
app.Route.Redirect("/old", "/new", 301)
```

## 命名路由与 URL 生成

```go
app.Route.Get("/api/users/:id", "User@Read").Name("users.read")

url, err := app.Route.URL("users.read", map[string]interface{}{
	"id": 100,
})
```

必填参数会替换路径变量，未消费参数会进入查询字符串。

应用级 URL：

```go
app.Domain()       // SERVER_DOMAIN，默认 https://localhost
app.URL("/login")  // 拼接完整 URL
app.AssetURL("app.css")
```

## 自动路由

`config/route.json`：

```json
{
    "url_route_must": true,
    "default_controller": "Index",
    "default_action": "index"
}
```

`url_route_must=true` 是默认安全基线，只允许显式路由。设为 `false` 后，未命中显式路由时按 URL 自动解析：

```text
/              -> Index@Index
/user          -> User@Index
/user/edit     -> User@Edit
/admin/user/edit -> Admin.User@Edit
```

自动路由会屏蔽框架基础控制器内置方法，但仍会暴露业务控制器导出方法。生产环境建议保持显式路由。
自动路由片段必须能映射为 Go 标识符：首字符为字母或下划线，后续字符为字母、数字或下划线；包含 `..`、空片段、点号扩展名或连字符的 URL 不会生成自动路由。
