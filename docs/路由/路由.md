# 路由

ThinkGo 路由集中定义在 `route` 包，通过 `framework.MustRegisterRouteLoader` 注册可返回错误的加载函数。

## 路由定义

```go
package route

import (
	"thinkgo/framework"
	"thinkgo/framework/context"
)

func init() {
	framework.MustRegisterRouteLoader(Load)
}

func Load(app *framework.App) error {
	home, err := app.Route.Get("/", func(req *context.Request) *context.Response {
		return context.NewResponse().Content("ThinkGo")
	})
	if err != nil {
		return err
	}
	if err = home.WithName("home"); err != nil {
		return err
	}

	if _, err = app.Route.Post("/api/users", "User@Save"); err != nil {
		return err
	}
	detail, err := app.Route.Get("/api/users/:id", "User@Read")
	if err != nil {
		return err
	}
	return detail.WithPattern("id", `\d+`)
}
```

加载器返回的错误或 panic 会进入 `App.StartupError()`，`App.Run()` 将拒绝启动半初始化服务。应用读取的是持锁注册快照，运行中追加加载器只影响后续创建的应用实例。

所有注册方法都返回 `(*Route, error)`；`WithName`、`WithPattern`、`WithDomain`、`WithExtension`、`WithoutMiddleware` 返回 `error`。路由在 `App.Run()` 或首次匹配时冻结，冻结后的注册和修改返回 `ErrRouterFrozen`。

支持的方法：

```text
Get Post Put Delete Patch Options Head Any Rule
```

`Rule(path, handler, "GET|POST")` 可以一次注册多方法路由。

## 路由地址

路由处理器可以是闭包：

```go
_, err := app.Route.Get("/ping", func(req *context.Request) *context.Response {
	return context.NewResponse().Json(map[string]interface{}{"pong": true})
})
```

也可以是控制器字符串：

```go
_, err := app.Route.Get("/api/users", "User@Index")
```

控制器字符串格式必须是 `Controller@Action`。控制器需要先通过 `framework.MustRegisterController` 注册。

## 变量规则

动态参数使用 `:name`：

```go
_, err := app.Route.Get("/api/users/:id", "User@Read")
```

可用 `Pattern` 约束参数：

```go
detail, err := app.Route.Get("/api/users/:id", "User@Read")
if err != nil {
	return err
}
if err = detail.WithPattern("id", `\d+`); err != nil {
	return err
}
```

`Pattern` 中的正则如果编译失败，该参数路由会失败关闭，不会退化为无约束匹配。

可选参数使用 `:name?`。

## 路由分组

分组回调接收独立作用域，应用的 `route` 包需导入 `frameworkroute "thinkgo/framework/route"`。

```go
err := app.Route.Group("/api", func(group *frameworkroute.Group) error {
	if _, err := group.Get("/users", "User@Index"); err != nil {
		return err
	}
	_, err := group.Post("/users", "User@Save")
	return err
})
```

分组可以传入中间件：

```go
err := app.Route.Group("/admin", func(group *frameworkroute.Group) error {
	_, err := group.Get("/users", "AdminUser@Index")
	return err
}, authMiddleware)
```

## 域名路由

```go
err := app.Route.Domain("api.example.com", func(group *frameworkroute.Group) error {
	_, err := group.Get("/users", "User@Index")
	return err
})

err = app.Route.DomainGroup("api.example.com", "/v1", func(group *frameworkroute.Group) error {
	_, err := group.Get("/users", "User@Index")
	return err
})
```

域名匹配会忽略端口、大小写和末尾点。

## 路由中间件

路由级中间件直接作为参数传入：

```go
_, err := app.Route.Get("/api/profile", "User@Profile", authMiddleware)
```

`WithoutMiddleware` 可以从当前路由移除指定中间件。目标不存在或函数身份存在歧义时返回错误，不会静默移除错误的中间件。

## 资源路由

```go
resource, err := app.Route.Resource("/api/users", "User")
```

会生成：

| 动作 | 方法 | 路径 | 控制器 |
|---|---|---|---|
| `index` | GET | `/api/users` | `User@Index` |
| `create` | GET | `/api/users/create` | `User@Create` |
| `save` | POST | `/api/users` | `User@Save` |
| `read` | GET | `/api/users/:id` | `User@Read` |
| `edit` | GET | `/api/users/:id/edit` | `User@Edit` |
| `update` | PUT | `/api/users/:id` | `User@Update` |
| `delete` | DELETE | `/api/users/:id` | `User@Delete` |

裁剪动作：

```go
resource, err := app.Route.Resource("/api/users", "User")
if err != nil {
	return err
}
if err = resource.Only("index", "read"); err != nil {
	return err
}
```

## MISS 路由

```go
_, err := app.Route.Miss(func(req *context.Request) *context.Response {
	return context.NewResponse().Code(404).Json(map[string]interface{}{
		"message": "not found",
	})
})
```

没有 MISS 路由时，`/api/` 前缀未命中返回 404；非 `/api/` 路径会尝试返回 `public/index.html` 作为 SPA fallback。

## 重定向路由

```go
_, err := app.Route.Redirect("/old", "/new", 301)
```

状态码只允许 `301`、`302`、`303`、`307`、`308`；目标地址包含换行或空字节时注册会失败。

## 命名路由与 URL 生成

```go
detail, err := app.Route.Get("/api/users/:id", "User@Read")
if err != nil {
	return err
}
if err = detail.WithName("users.read"); err != nil {
	return err
}

url, err := app.Route.URL("users.read", map[string]interface{}{
	"id": 100,
})
```

必填参数会替换路径变量，未消费参数会进入查询字符串。

应用级 URL：

```go
app.Domain()       // SERVER_DOMAIN，默认 https://localhost
app.URL("/login")  // 拼接完整 URL
app.AssetURL("app.css")
```

`URL` 会消除域名与路径之间的重复斜杠；完整地址仅接受带 host 的 HTTP(S) URL，包含 CR/LF/TAB 或缺少 host 时返回空字符串。

## 自动路由

`config/route.json`：

```json
{
    "url_route_must": true,
    "default_controller": "Index",
    "default_action": "index"
}
```

`url_route_must=true` 是默认安全基线，只允许显式路由。设为 `false` 后，未命中显式路由时按 URL 自动解析：

```text
/              -> Index@Index
/user          -> User@Index
/user/edit     -> User@Edit
/admin/user/edit -> Admin.User@Edit
```

自动路由只接受 GET、HEAD 和自动 OPTIONS，写方法返回 405；同时会屏蔽框架基础控制器内置方法，但仍可能暴露业务控制器导出的只读动作。生产环境建议保持显式路由。
自动路由片段必须能映射为 Go 标识符：首字符为字母或下划线，后续字符为字母、数字或下划线；包含 `..`、空片段、点号扩展名或连字符的 URL 不会生成自动路由。

显式 GET 路由自动支持 HEAD 回落；路径存在但方法不匹配时返回 405 和 `Allow`，未显式注册 OPTIONS 时框架生成 204 OPTIONS 响应。静态和动态路由都同时按方法、路径、域名与扩展名匹配。
