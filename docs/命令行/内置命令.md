# 内置命令

`cmd/think` 注册以下内置命令：

| 命令 | 参数/选项 | 作用 |
|---|---|---|
| `list` | 无 | 按排序列出命令和参数契约 |
| `version` | 无 | 输出框架版本 |
| `run` | `-p`/`--port`、`-a`/`--app` | 启动统一 HTTP 服务，见[启动服务](启动服务.md) |
| `route:list` | `-a`/`--app` | 列出目标应用的方法、路径和处理器 |
| `config:dump` | 可选 `<name>`、`-a`/`--app` | 输出目标应用的配置 |
| `clear` | `-a`/`--app` | 清理目标应用缓存后端和文件缓存 |
| `make:controller` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成控制器 |
| `make:model` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成模型 |
| `make:command` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成命令 |
| `make:validate` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成验证器 |
| `make:middleware` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成中间件 |
| `make:event` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成事件 |
| `make:listener` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成监听器 |
| `make:subscribe` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成订阅者 |
| `make:service` | 必填 `<name>`、`-a`/`--app` | 在目标应用生成服务 Provider |

除 `run` 外，入口创建跳过数据库连接的 `ApplicationManager`，为全部应用建立独立 `App`；`run` 使用完整初始化并由一个 `MultiHttp` 宿主监听。

## version 与 list

```bash
go run cmd/think/main.go version
go run cmd/think/main.go list
```

`version` 输出框架版本；`list` 使用当前已注册命令的帮助输出。没有命令参数时 `cmd/think` 也会展示同一份帮助。

## route:list

```bash
go run cmd/think/main.go route:list --app admin
```

命令解析目标应用的 `framework.ServiceRoute` 并调用 `Routes()`，因此会触发路由冻结。表头包含 `Method`、`Path` 和 `Handler`；闭包处理器显示为 `Closure`，字符串处理器显示 `Controller@Action`。路由冻结错误会返回入口层。

## config:dump

```bash
go run cmd/think/main.go config:dump
go run cmd/think/main.go config:dump --app admin app.server
```

不提供参数时输出完整配置；提供点分隔键时只输出该路径值。输出前先按 JSON 语义归一化，再递归脱敏 `password`、`token`、`secret`、`authorization`、`credential`、`private_key`、`dsn`、`uri`、`url` 等敏感字段；直接查询敏感点路径也只能得到 `[REDACTED]`。不能 JSON 序列化时不会输出半成品。

## clear

```bash
go run cmd/think/main.go clear --app admin
```

命令先调用目标应用默认缓存 store 的 `Flush`。后端清理失败会立即返回，不会继续删除本地目录或输出成功；后端成功后才清理目标应用 `runtime/<name>/cache` 中受文件驱动管理的 `.cache` 和陈旧临时文件。活动 `.lock`、非缓存文件、日志、Session、证书和其它运行时数据库文件会保留。
