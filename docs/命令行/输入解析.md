# 输入解析

`console.NewInput` 只保存显式传入的 token，不读取或修改全局 `os.Args`：

```go
input := console.NewInput("Alice", "-o", "./dist", "--force")
if err := input.Parse(arguments, options); err != nil {
	return err
}
```

## 支持的写法

```text
--name value
--name=value
-n value
-n=value
--flag
-f
--
```

短选项按命令声明映射到规范长名。取值型选项可以接收负数，例如 `--offset -1`；布尔选项出现即为 `true`，不会消费后续位置参数，也可以写 `--flag=false`。

`--` 终止选项解析，之后所有 token 都作为位置参数，即使以 `-` 开头也不会再解析。

## 严格校验

解析器拒绝：

- 未声明的长选项或短选项；
- 取值型选项缺少值；
- 重复选项；
- 布尔选项的非法值；
- 缺少必填位置参数；
- 多余位置参数；
- 必填参数出现在可选参数之后；
- 命令声明中的重复或非法名称。

失败返回可用 `errors.Is` 判断的 `ErrInvalidInput`，并清空本次解析状态。重复调用 `Parse` 不会泄漏上一次的选项、参数或默认值。

## 读取结果

```go
name := input.GetArgument(0)
outputDir := input.GetOption("output")
```

成功解析后，`Arguments` 和 `Options` 保存规范名称；未解析时 getter 保留有限的原始 token 兼容扫描，正式命令应先调用 `Parse`。越界位置、未知选项和 nil 输入返回空字符串或明确错误，不会 panic。
