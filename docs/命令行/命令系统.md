# 命令系统

自定义命令实现 `console.ICommand`，通常嵌入 `console.Command`：

```go
type Demo struct {
    console.Command
}

func (command *Demo) Configure() {
    command.Signature = "app:demo"
    command.Description = "执行应用命令"
    command.AddArgument("name", "目标名称", true)
    command.AddOption("output", "o", "输出目录", "./dist")
    command.AddBoolOption("force", "f", "强制覆盖")
}

func (command *Demo) Execute(input *console.Input, output *console.Output) error {
    output.Writeln(input.GetArgument(0) + " -> " + input.GetOption("output"))
    return output.Err()
}
```

注册命令：

```go
if err := cli.Register(&Demo{}); err != nil {
    return err
}
```

## 注册校验

`Register` 调用 `Configure`，检查签名、描述、参数和选项声明，并拒绝重复命令。相同声明重复调用 `Configure` 幂等；未知、重复、缺值和参数数量不匹配都会在执行前失败。

实现 `SetApp(*framework.App)` 的命令会收到项目入口 App。需要处理具体应用时，应使用框架提供的编译期清单选择逻辑，而不是通过全局变量记录“当前应用”。内置路由、配置、迁移和部署命令使用 `--app`；生成器同时支持 `--app admin` 与 `admin@Type`，两者冲突时拒绝执行。

项目入口 App 负责持有和逆序关闭子应用。命令不得单独关闭从清单取得的子 App，也不得在并发任务之间共享请求级状态。

## 运行与帮助

```go
if err := cli.Run("app:demo", "Alice", "--force"); err != nil {
    return err
}
```

没有参数时 `Run()` 显示帮助。帮助按命令名排序，展示描述、位置参数、长短选项和默认值，适合脚本与快照。业务错误、解析错误和输出错误都由 `Console.Run` 返回，不会只打印文本后伪造成功。
