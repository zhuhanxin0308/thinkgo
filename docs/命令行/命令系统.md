# 命令系统

自定义命令实现 `console.ICommand`，通常嵌入 `console.Command`：

```go
type Demo struct {
	console.Command
}

func (c *Demo) Configure() {
	c.Signature = "app:demo"
	c.Description = "执行应用命令"
	c.AddArgument("name", "目标名称", true)
	c.AddOption("output", "o", "输出目录", "./dist")
	c.AddBoolOption("force", "f", "强制覆盖")
}

func (c *Demo) Execute(input *console.Input, output *console.Output) error {
	output.Writeln(input.GetArgument(0) + " -> " + input.GetOption("output"))
	return output.Err()
}
```

注册命令：

```go
if err := cli.Register(&Demo{}); err != nil {
	return err
}
```

## 注册校验

`Register` 会调用 `Configure`，检查签名、描述、参数声明并拒绝重复命令。签名由小写字母开头的冒号分段组成，分段后续可包含数字和短横线，例如 `config:dump`；描述不能为空或包含控制字符。

参数名必须是字母开头、后续为字母/数字/短横线；短选项必须是单个字母或数字。重复参数、重复选项、重复短选项和无效布尔默认值会在注册或解析时失败。相同声明重复调用 `Configure` 是幂等的。

如果命令实现 `SetApp(*framework.App)`，注册时会注入默认应用；如果命令实现 `SetApplicationManager(*framework.ApplicationManager)`，还可以通过 `--app/-a` 选择目标应用。命令业务错误、解析错误和输出错误都会由 `Console.Run` 返回，不会只打印文本后伪造成功。

## 运行与帮助

```go
if err := cli.Run("app:demo", "Alice", "--force"); err != nil {
	return err
}
```

没有参数时 `Run()` 调用 `ShowHelp()`。帮助按命令名排序，展示描述、位置参数、长短选项和默认值，输出顺序稳定，适合脚本和快照。
