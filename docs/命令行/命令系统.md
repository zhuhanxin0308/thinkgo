# 命令系统

自定义命令实现 `console.ICommand`，通常嵌入 `console.Command`：

```go
type Demo struct {
    console.Command
}

func (command *Demo) Configure() {
    command.Signature = "app:demo"
    command.Description = "执行应用命令"
    command.AddArgument("name", "目标名称", true)
    command.AddOption("output", "o", "输出目录", "./dist")
    command.AddBoolOption("force", "f", "强制覆盖")
}

func (command *Demo) Execute(input *console.Input, output *console.Output) error {
    output.Writeln(input.GetArgument(0) + " -> " + input.GetOption("output"))
    return output.Err()
}
```

将导出的命令类型放在 `app/<应用名>/command` 或其公开子包内。`make:command` 自动刷新静态发现清单，手工添加或调整类型后可以运行 `service:discover`。独立安装的 `thinkgo` 和项目入口均可直接列出、查看帮助和执行命令：

```bash
thinkgo list
thinkgo help app:demo
thinkgo app:demo Alice --force
```

发现依据是 Go 编译目标及 `console.ICommand` 接口；未实例化泛型、普通辅助结构体、`internal` 与 `testdata` 私有目录不会自动注册。签名和参数来自命令自身的 `Configure`，支持常量拼接等正常 Go 实现。生成的静态清单位于 `cmd/think/commandautoload/autoload_generated.go`，不会创建额外业务应用。

自行嵌入控制台时也可以显式注册命令：

```go
if err := cli.Register(&Demo{}); err != nil {
    return err
}
```

## 注册校验

`Register` 调用 `Configure`，检查签名、描述、参数和选项声明，并拒绝重复命令。相同声明重复调用 `Configure` 幂等；未知、重复、缺值和参数数量不匹配都会在执行前失败。

项目命令与内置命令或其他项目命令签名冲突时直接报错，不覆盖已有命令。源码或依赖编译失败时不会退回旧清单。列表、帮助和未知命令不调用业务 `Register`、初始化项目配置或启动 Provider；动态发现的首轮宿主仅导入命令包及其依赖。编译进制品的 Go 包仍会正常执行 `init`，命令的 `Configure` 也会执行，因此应将外部操作放在 `Execute` 中。

有效的自定义命令会先校验参数，再装配和初始化项目 App。默认跳过数据库连接，需要数据库的命令应明确声明：

```go
// RequiresDatabase 声明该命令需要按项目配置初始化数据库。
func (command *Demo) RequiresDatabase() bool {
    return true
}
```

通过独立 CLI 动态运行项目源码命令需要 Go 工具链。框架通过固定构建参数生成临时宿主，并在执行完成或取消后清理；不会修改已安装 CLI 或模块缓存中的框架源码。新项目以 `-tags=thinkgo_runtime` 构建的控制台入口会直接消费静态命令清单，部署后不需要 Go 工具链或命令源码；空静态清单也不会触发动态扫描。宿主集成可使用 `launcher.RunWithCommands` 传入静态命令实例，原 `launcher.Run` 接口保持兼容。

实现 `SetApp(*framework.App)` 的命令会收到项目入口 App。需要处理具体应用时，应使用框架提供的编译期清单选择逻辑，而不是通过全局变量记录“当前应用”。内置路由、配置、迁移和部署命令使用 `--app`；生成器同时支持 `--app admin` 与 `admin@Type`，两者冲突时拒绝执行。

项目入口 App 负责持有和逆序关闭子应用。命令不得单独关闭从清单取得的子 App，也不得在并发任务之间共享请求级状态。

## 运行与帮助

```go
if err := cli.Run("app:demo", "Alice", "--force"); err != nil {
    return err
}
```

没有参数时 `Run()` 显示帮助。帮助按命令名排序，展示描述、位置参数、长短选项和默认值，适合脚本与快照。业务错误、解析错误和输出错误都由 `Console.Run` 返回，不会只打印文本后伪造成功。
