# 代码生成命令

生成器都要求一个必填类型名，并支持 `--app <应用名>` 选择目标应用：

```bash
go run cmd/think/main.go make:controller Account --app admin
go run cmd/think/main.go make:model UserProfile --app admin
go run cmd/think/main.go make:validate UserProfile --app admin
```

未指定 `--app` 时使用 `default_app` 配置；没有显式默认配置时使用 `index`。未知应用、应用名越界和路径穿越都会在写文件前拒绝。

名称会去除首尾空白，把下划线、短横线和空格分隔的单词转为导出的 Go 类型名，例如 `user_profile` 变成 `UserProfile`。名称不能包含路径分隔符、点号或其它非法字符，必须最终成为导出的 Go 标识符。

## 生成位置

| 命令 | 文件位置 | 应用入口变化 |
|---|---|---|
| `make:controller` | `app/<name>/controller/<type>.go` | 更新 `RegisterController` |
| `make:model` | `app/<name>/model/<snake_name>.go` | 由应用服务显式使用 |
| `make:validate` | `app/<name>/validate/<type>.go` | 由控制器或服务显式使用 |
| `make:command` | `app/<name>/command/<type>.go` | 命令属于目标应用 |
| `make:middleware` | `app/<name>/middleware/<type>.go` | 更新 `RegisterGlobalMiddleware` |
| `make:event` | `app/<name>/event/<type>.go` | 由业务代码发布 |
| `make:listener` | `app/<name>/listener/<type>.go` | 更新当前应用事件监听注册 |
| `make:subscribe` | `app/<name>/subscribe/<type>.go` | 更新当前应用订阅注册 |
| `make:service` | `app/<name>/service/<type>.go` | 更新当前应用 Provider 注册 |

控制器、中间件、Provider、监听器和订阅者生成后，生成器使用 Go AST 更新 `app/<name>/application.go`。更新是幂等的：同一类型重复执行不会重复导入或重复注册，已有注册语句会按稳定顺序整理。

模型文件使用 `db.ToSnakeCase` 生成文件名，遵循所属应用的模型目录和表名命名约定；模型构造器返回 `(*ModelType, error)`，必须处理 `NewModelAuto` 的配置错误。

## 应用入口示例

```go
// app/admin/application.go
package admin

import (
	"thinkgo/app/admin/controller"
	"thinkgo/framework"
)

func Register(app *framework.App) error {
	return app.RegisterController("AccountController", &controller.AccountController{})
}
```

入口文件只注册 `admin` 自己的组件。不能把生成的类型导入 `app/index/application.go`，也不能通过旧的包级 `init()` 注册 API 让所有应用共享。

## 安全写入

生成器会先用 `go/format` 格式化源码，再在目标应用目录约束内创建文件。应用注册入口更新会先读取并解析完整 Go AST，只有解析、修改和格式化全部成功后才原子替换 `application.go`：

- 路径穿越、绝对路径和根目录外符号链接会失败；
- 已存在的生成源码不会覆盖；
- 注册入口解析失败时原文件保持不变；
- 生成源码和注册入口写入失败时不会留下半成品；
- 生成成功只表示源码已创建和入口已更新，不表示业务逻辑已经通过编译。

生成后应运行：

```bash
gofmt -w app/<name>
go test ./...
```

命令行应用选择见[输入解析](输入解析.md)，服务启动见[启动服务](启动服务.md)，应用目录边界见[目录结构](../基础/目录结构.md)。
