# 输出与错误

输出器可以绑定标准流或测试 writer：

```go
output := console.NewOutputWithWriters(os.Stdout, os.Stderr, false)
output.Write("raw")
output.Writeln("line")
output.Info("info")
output.Warning("warning")
output.Success("success")
output.Error("failure")
```

`Write`/`Writeln`/`Info`/`Warning`/`Success` 写 stdout；`Error` 写 stderr。`Err()` 返回第一个底层 writer 错误；后续写入不会覆盖第一个错误。

## 颜色与终端

`NewOutputWithAutoColor` 只在 stdout 是交互式终端时启用 ANSI 颜色。管道、文件、buffer 默认无颜色；设置 `NO_COLOR` 或 `TERM=dumb` 也会关闭颜色。`NewOutputWithWriters` 可以显式指定颜色开关。

状态输出会转义换行、回车、制表符和其它控制字符，防止命令输出伪造日志行或注入终端控制序列。原始 `Write` 保持调用方文本，不应把不可信数据直接作为原始终端控制流输出。

## 错误与退出码

`Console.Run` 会合并命令执行错误和输出器错误。`cmd/think` 的入口把错误写到 stderr，并以非零状态退出：

```text
ThinkGo command failed: "命令错误"
```

入口使用 `%q` 转义底层错误中的控制字符。自定义命令应把业务失败、参数失败和输出失败返回给入口，不要只调用 `output.Error` 后返回 nil。
