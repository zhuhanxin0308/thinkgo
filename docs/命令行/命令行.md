# 命令行

命令行入口在 `cmd/think/main.go`。运行方式：

```bash
go run cmd/think/main.go list
```

## 内置命令

| 命令 | 说明 |
|---|---|
| `list` | 列出命令 |
| `version` | 显示版本 |
| `clear` | 清空并重建 `runtime/cache` 目录 |
| `run` | 启动 HTTP 服务 |
| `route:list` | 列出已注册路由 |
| `config:dump` | 输出配置并脱敏敏感值 |
| `make:controller` | 创建控制器 |
| `make:model` | 创建模型 |
| `make:command` | 创建命令 |
| `make:validate` | 创建验证器 |
| `make:middleware` | 创建中间件 |
| `make:event` | 创建事件 |
| `make:listener` | 创建监听器 |
| `make:subscribe` | 创建订阅者 |
| `make:service` | 创建服务 |

除 `run` 外，默认使用 `framework.NewConsoleApp()` 跳过数据库连接。

## run

```bash
go run cmd/think/main.go run
go run cmd/think/main.go run -p 9000
go run cmd/think/main.go run --port=9000
```

`-p` / `--port` 会校验端口范围，并同时写入进程环境变量 `SERVER_PORT` 和当前应用内存配置。

命令会探测 `air`。已安装时使用热重载；未安装时以普通模式启动，并提示安装方式。热重载模式会在应用根目录准备 `bin` 目录，再把构建产物输出为 `bin/server` 或 `bin/server.exe`。

## route:list

```bash
go run cmd/think/main.go route:list
```

输出已注册路由的方法、路径和处理器。

## config:dump

```bash
go run cmd/think/main.go config:dump
go run cmd/think/main.go config:dump app.server
```

配置输出会脱敏 `password`、`token`、`secret`、`session`、`cookie`、`authorization`、`api_key` 等字段。

## 自定义命令

命令需要实现 `console.ICommand`。通常嵌入 `console.Command`：

```go
type Demo struct {
	console.Command
}

func (c *Demo) Configure() {
	c.Signature = "app:demo"
	c.Description = "执行应用命令"
	c.AddArgument("name", "目标名称", true)
	c.AddOption("output", "o", "输出目录", "./dist")
	c.AddBoolOption("force", "f", "强制覆盖")
}

func (c *Demo) Execute(input *console.Input, output *console.Output) {
	name := input.GetArgument(0)
	dir := input.GetOption("output")
	force := input.GetOption("force")
	output.Writeln(name + " -> " + dir + " force=" + force)
}
```

注册命令：

```go
cli.Register(&Demo{})
```

## 参数和选项

支持：

```text
--name value
--name=value
-n value
-n=value
--flag
-f
--
```

短选项会按命令声明映射到长选项。布尔选项出现即为 `true`，不会消费后续位置参数。声明为取值型的选项可以接收负数值，例如 `--offset -1`。

`--` 表示选项解析结束，后续 token 即使以 `-` 开头也会作为位置参数处理。

## 输出

```go
output.Write("text")
output.Writeln("line")
output.Info("info")
output.Warning("warning")
output.Error("error")
output.Success("success")
```

彩色输出使用 ANSI 转义序列。

## 注意事项

生成器命令会校验名称，拒绝路径分隔符、点号和非法 Go 标识符，避免生成文件逃逸目标目录。生成的事件、监听器、服务、中间件和验证器模板会匹配当前框架接口。

`clear` 只清理缓存目录，不删除 `runtime/log`、`runtime/session`、证书或离线数据库文件。
