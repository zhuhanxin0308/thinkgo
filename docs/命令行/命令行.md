# 命令行

命令行文档已按命令系统、输入解析、输出错误、内置命令、代码生成和服务启动拆分，请从[命令行章节索引](README.md)进入。
命令行入口在 `cmd/think/main.go`。运行方式：

```bash
go run cmd/think/main.go list
```

## 内置命令

| 命令 | 说明 |
|---|---|
| `list` | 列出命令 |
| `version` | 显示版本 |
| `clear` | 安全清理当前缓存后端和本地文件缓存 |
| `run` | 启动 HTTP 服务 |
| `route:list` | 列出已注册路由 |
| `config:dump` | 输出配置并脱敏敏感值 |
| `make:controller` | 创建控制器 |
| `make:model` | 创建模型 |
| `make:command` | 创建命令 |
| `make:validate` | 创建验证器 |
| `make:middleware` | 创建中间件 |
| `make:event` | 创建事件 |
| `make:listener` | 创建监听器 |
| `make:subscribe` | 创建订阅者 |
| `make:service` | 创建服务 |

除 `run` 外，默认使用严格的 `framework.BuildConsoleApp` 跳过数据库连接。初始化失败直接返回错误，不会返回可继续使用的半初始化应用；命令若需要数据库，必须显式解析 `framework.ServiceDB` 并处理不可用错误，或自行调用 `db.Connect` 管理连接。

## run

```bash
go run cmd/think/main.go run
go run cmd/think/main.go run -p 9000
go run cmd/think/main.go run --port=9000
```

`-p` / `--port` 会校验端口范围。应用初始化和配置依赖通过检查后，端口才会同时写入进程环境变量 `SERVER_PORT` 和当前应用内存配置；启动检查失败不会污染进程状态。

命令会探测 `air`。已安装时使用热重载；未安装时通过 `App.Run()` 以普通模式启动，并提示安装方式。初始化或 Provider 启动失败时不会继续监听端口；退出时统一调用幂等的 `App.Close()`。热重载模式会在应用根目录准备 `bin` 目录，再把构建产物输出为 `bin/server` 或 `bin/server.exe`。热重载由命令行直接传递 Air 参数，不需要 `.air.toml`；默认排除 `runtime`、`bin`、`tmp`、`framework`、`cmd`、`vendor`、`testdata` 和 `assets`。

## route:list

```bash
go run cmd/think/main.go route:list
```

输出已注册路由的方法、路径和处理器。

## config:dump

```bash
go run cmd/think/main.go config:dump
go run cmd/think/main.go config:dump app.server
```

配置输出会先按 JSON 语义归一化，再递归脱敏 `password`、`token`、`secret`、`session`、`cookie`、`authorization`、`credential`、`passphrase`、`private_key`、`api_key`、`access_key`、`connection_string`、`dsn`、`uri`、`url` 等字段。直接查询敏感点路径（例如 `config:dump database.password`）同样只输出 `[REDACTED]`，强类型映射和结构体不能绕过脱敏。

## 自定义命令

命令需要实现 `console.ICommand`。通常嵌入 `console.Command`：

```go
type Demo struct {
	console.Command
}

func (c *Demo) Configure() {
	c.Signature = "app:demo"
	c.Description = "执行应用命令"
	c.AddArgument("name", "目标名称", true)
	c.AddOption("output", "o", "输出目录", "./dist")
	c.AddBoolOption("force", "f", "强制覆盖")
}

func (c *Demo) Execute(input *console.Input, output *console.Output) error {
	name := input.GetArgument(0)
	dir := input.GetOption("output")
	force := input.GetOption("force")
	output.Writeln(name + " -> " + dir + " force=" + force)
	return output.Err()
}
```

注册命令：

```go
if err := cli.Register(&Demo{}); err != nil {
	return err
}
```

`ICommand.Execute`、`Console.Register` 和 `Console.Run` 都返回 `error`。命令业务错误、参数错误、重复注册和输出流写入错误必须向入口层传播；`cmd/think` 会输出到标准错误流并以非零状态退出。命令签名、描述及参数声明非法时注册失败，重复签名不会静默覆盖。

## 参数和选项

支持：

```text
--name value
--name=value
-n value
-n=value
--flag
-f
--
```

短选项会按命令声明映射到长选项。布尔选项出现即为 `true`，不会消费后续位置参数。声明为取值型的选项可以接收负数值，例如 `--offset -1`。

`--` 表示选项解析结束，后续 token 即使以 `-` 开头也会作为位置参数处理。

解析器会拒绝未知或重复选项、缺少选项值、非法布尔值、缺少必填参数和多余位置参数。`NewInput` 只使用显式传入的参数，不读取或修改全局 `os.Args`。

## 输出

```go
output.Write("text")
output.Writeln("line")
output.Info("info")
output.Warning("warning")
output.Error("error")
output.Success("success")
```

`Error` 写入 stderr，其余方法写入 stdout。颜色只在交互式终端启用；重定向或管道输出默认无 ANSI 序列，设置 `NO_COLOR` 或 `TERM=dumb` 也会禁用颜色。状态输出会转义换行和 ANSI 等控制字符，防止终端注入；调用方可通过 `output.Err()` 获取首个写入错误。

## 注意事项

生成器命令会校验名称，拒绝路径分隔符、点号和非法 Go 标识符。源码在应用根目录约束内经 `gofmt` 格式化后独占创建；路径穿越、根目录外符号链接、已有同名文件和并发覆盖都会失败，失败时不遗留半成品。生成的事件、监听器、服务、中间件和验证器模板会匹配当前框架接口。`make:model` 生成的构造器返回 `(*ModelType, error)`，并完整处理 `db.NewModelAuto` 的配置错误。

`clear` 先调用当前默认缓存 store 的 `Flush()`；后端失败时输出错误并停止，不会继续清理本地目录或谎报成功。后端成功后，使用文件驱动清理 `runtime/cache` 中受管的 `.cache` 与陈旧临时文件，保留活动 `.lock` 和非缓存文件；不会删除 `runtime/log`、`runtime/session`、证书或离线数据库文件。
