# 写入更新删除

## 插入

```go
database := app.DB()
id, err := database.Name("users").Insert(map[string]interface{}{
	"name": "张三",
	"age":  18,
})
```

插入 map 不能为空，字段名必须是安全标识符。框架会复制调用方传入的 map，自动时间戳和后续处理不会修改调用方持有的数据。返回值是驱动报告的插入结果；支持主键回传的方言会返回实际主键值。

## 更新

```go
affected, err := database.Name("users").
	WhereField("id", "=", userID).
	Update(map[string]interface{}{"name": "李四"})
```

更新必须包含调用方提供的业务 `WHERE`，否则返回 `ErrUnsafeFullTableMutation`。普通更新数据不能为空；字段名会校验，值作为参数绑定。模型自动追加的软删除条件不计作业务 WHERE。

## 删除

```go
affected, err := database.Name("users").
	WhereField("id", "=", userID).
	Delete()
```

删除同样禁止无 WHERE。数据库查询器的 `Delete` 始终是物理删除；模型启用软删除时，模型层的 `Delete` 会改写为更新时间字段，见[模型生命周期](模型生命周期.md)。

## Inc 与 Dec

```go
affected, err := database.Name("users").
	WhereField("id", "=", userID).
	Inc("score", 5).
	Dec("quota", 1).
	Update(nil)
```

`Inc` 和 `Dec` 生成参数化的字段算术表达式。步长必须是正整数；同一字段不能重复配置增减，也不能同时出现在普通更新 map 和增减表达式中。只配置增减表达式时，`Update(nil)` 或空 map 是允许的。

## 模型写入

模型查询器在普通写入之上增加修改器、事件、自动时间戳和软删除：

```go
id, err := userModel.Insert(map[string]interface{}{"name": "张三"})

affected, err := userModel.
	Where("id = ?", id).
	UpdateMap(map[string]interface{}{"name": "李四"})
```

模型结构体写入使用 `Create` 和 `Update`，其字段映射规则见[模型字段映射](模型字段映射.md)。

## 失败边界

- 写入字段为空、字段名非法、值不能被驱动处理时，操作在执行前返回错误。
- 更新和删除的影响行数由底层驱动返回，不把“没有匹配行”和“执行失败”混淆。
- `DB.Close` 开始后新写入会被拒绝；已经开始的操作会完成或返回上下文/连接错误。
- 跨表写入、库存扣减、写入并记录审计等原子业务应使用[事务](事务.md)。
