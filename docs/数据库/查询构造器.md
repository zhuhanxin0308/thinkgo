# 查询构造器

查询构造器由 `app.DB.Table()` 或 `app.DB.Name()` 创建。每次调用都会返回新的 `Query` 实例，不跨请求共享状态。

## Table 与 Name

```go
// 使用完整表名，不追加前缀。
app.DB.Table("tg_users")

// 使用短表名，自动追加 database.prefix。
app.DB.Name("users")
```

JOIN 表会跟随主表的前缀规则。

## 查询数据

```go
row, err := app.DB.Name("users").
	WhereField("id", "=", 1).
	Find()

rows, err := app.DB.Name("users").
	WhereLike("name", "%张%").
	Order("id DESC").
	Page(1, 20).
	Select()
```

`Find` 会在克隆查询上设置 `LIMIT 1`，不会污染原查询对象。

## Where 条件

推荐使用安全 API：

```go
q := app.DB.Name("users").
	WhereField("status", "=", 1).
	WhereIn("id", []interface{}{1, 2, 3}).
	WhereBetween("age", 18, 60).
	WhereLike("name", "%go%").
	WhereNull("deleted_at")
```

`Where` 兼容多种形式：

```go
q.Where("id = ?", 1)
q.Where("status", 1)
q.Where("age", ">=", 18)
q.Where(map[string]interface{}{"status": 1})
q.Where([][]interface{}{{"age", ">=", 18}, {"status", "=", 1}})
q.Where(func(g *db.ConditionGroup) {
	g.Where("status = ?", 1).WhereOr("status = ?", 2)
})
```

普通 `Where` 会校验字段、操作符、参数数量和谓词形式；`map` 条件按字段名排序，SQL 与参数顺序稳定。`WhereTime` 拒绝零时间、空值和 NaN/Inf。复杂表达式使用 `WhereRaw`：

```go
q.WhereRaw("JSON_EXTRACT(profile, '$.role') = ?", "admin")
```

`WhereRaw` 是显式原生 SQL 入口，调用方必须自行保证参数化和输入安全。

## 字段、排序和分组

```go
q.Field("id,name,email")
q.Order("id DESC")
q.Group("status")
q.Having("total > ?", 10)
q.HavingField("total", ">", 10)
```

字段列表、别名、排序字段、分组字段会做标识符白名单校验，并由当前 SQL 方言引用标识符。聚合函数形式的复杂 HAVING 请用 `HavingRaw`。

## JOIN

```go
rows, err := app.DB.Name("orders").
	Join("users", "orders.user_id = users.id").
	WhereField("orders.status", "=", 1).
	Field("orders.id,users.name").
	Select()
```

JOIN 条件只允许 `field op field` 形式，支持 `AND` 连接多个条件。字段支持 `table.field`。未调用 `Field` 时，框架默认投影 `主表.*`，不会把关联表的同名列写入结果 map；需要关联表字段时必须显式选择，并为所有同名列设置唯一别名。

## 写入数据

```go
id, err := app.DB.Name("users").Insert(map[string]interface{}{
	"name": "张三",
	"age":  18,
})
```

插入数据不能为空；空 `map` 会返回错误。框架先复制调用方 `map`，自动时间戳、模型修改器和主键回填不会修改调用方持有的数据。支持 `RETURNING` 的方言使用模型实际主键，不再固定为 `id`。

批量插入：

```go
affected, err := app.DB.Name("users").InsertAll([]map[string]interface{}{
	{"name": "a", "age": 1},
	{"name": "b", "age": 2},
})
```

`InsertAll` 会逐行复制输入，要求每行至少包含一个字段且字段集合一致。占位符数量超过方言上限时自动分批，多批写入会包裹事务保证原子性；任一批次执行或读取影响行数失败时回滚，并同时保留业务错误与回滚错误。

## 更新与删除

```go
affected, err := app.DB.Name("users").
	WhereField("id", "=", 1).
	Update(map[string]interface{}{"name": "李四"})

affected, err = app.DB.Name("users").
	WhereField("id", "=", 1).
	Delete()
```

无 WHERE 的 `Update` 和 `Delete` 会被拒绝，防止误更新或误删全表。普通 `Update` 的数据不能为空；仅使用 `Inc`/`Dec` 生成 SET 表达式时可传空 `map`。

自增自减：

```go
affected, err := app.DB.Name("users").
	WhereField("id", "=", 1).
	Inc("score", 5).
	Update(nil)
```

`Inc`/`Dec` 的步长必须是正整数，最多传一个；字段名、算术符和步长都会由框架生成或绑定，步长不会内联进 SQL。同一字段不能重复配置增减表达式，也不能同时出现在 `Update` 数据中。

## 聚合与字段读取

```go
total, err := app.DB.Name("orders").Count()
sum, err := app.DB.Name("orders").Sum("amount")
avg, err := app.DB.Name("orders").Avg("amount")
max, err := app.DB.Name("orders").Max("amount")
min, err := app.DB.Name("orders").Min("amount")

name, err := app.DB.Name("users").WhereField("id", "=", 1).Value("name")
names, err := app.DB.Name("users").Column("name")
nameMap, err := app.DB.Name("users").Column("name", "id")
```

`Count` 对 JOIN、GROUP、HAVING、DISTINCT 会自动包一层子查询统计真实总数。聚合值会按驱动常见整数、浮点、文本和 `json.Number` 类型精确解析；负数计数、非整数计数、溢出、NaN/Inf 或非法文本会返回 `ErrInvalidAggregateValue`，不会静默当作零。

`Value` 要求结果确实包含目标字段。`Column(field, key)` 要求每行同时包含目标字段和 key；两者都支持 `table.column` 限定字段，并兼容 SQL 驱动返回末段列名。重复 key 或字符串化后冲突会返回 `ErrInvalidDatabaseRow`，不会覆盖先前数据。

## 分页

```go
p, err := app.DB.Name("users").
	WhereField("status", "=", 1).
	Paginate(1, 20)

return context.NewResponse().Json(p.ToMap())
```

分页结果包含：

```text
list total page page_size last_page has_more
```

`Paginator.Offset()` 返回 `(int, error)`，页码与页大小相乘溢出时返回 `ErrInvalidPagination`。`Paginate` 不修改原查询对象，可安全重复执行。

## 分块遍历

```go
err := app.DB.Name("users").Chunk(100, func(rows []map[string]interface{}) bool {
	return true
})

err = app.DB.Name("users").ChunkById(1000, "id", func(rows []map[string]interface{}) bool {
	return true
})
```

回调不能为空；返回 `false` 会立即停止且不再发起下一批查询。`ChunkById` 要求游标字段存在、类型受支持并严格递增，缺失、类型漂移或不推进会返回 `ErrInvalidDatabaseRow`。框架在调用回调前保存下一游标，因此回调修改结果行不会破坏推进。大表遍历优先使用 `ChunkById`，避免 OFFSET 深分页性能下降和数据增删造成漏读。

## 悲观锁

```go
row, err := app.DB.Name("users").
	WhereField("id", "=", 1).
	Lock(true).
	Find()
```

MySQL 使用 `FOR UPDATE` 或 `LOCK IN SHARE MODE`，PostgreSQL 使用 `FOR UPDATE` 或 `FOR SHARE`，SQLite 和 SQL Server 不输出尾部锁子句。

## 上下文

```go
ctx, cancel := context.WithTimeout(req.Raw().Context(), 3*time.Second)
defer cancel()

rows, err := app.DB.Name("users").
	WithContext(ctx).
	Select()
```

内置 SQL、MongoDB 和 Neo4j 连接都支持 context 取消和有界超时。`WithContext(nil)` 会形成 `ErrInvalidQuery`，并在终端方法调用时返回。

## 原生 SQL

```go
rows, err := app.DB.Query("SELECT * FROM users WHERE id = ?", 1)
affected, err := app.DB.Execute("UPDATE users SET name = ? WHERE id = ?", "张三", 1)
```

原生 SQL 统一使用 `?` 占位符，框架按方言转换为 `$1`、`@p1`、`:1` 等形式。PostgreSQL 的单字符 JSONB 存在操作符写作 `??`，例如 `WhereRaw("payload ?? ?", "role")` 会执行为 `payload ? $1`；`?|`、`?&`、`@?` 可直接使用且不占用参数序号。占位符扫描会忽略字符串、引用标识符、行/块注释和 PostgreSQL dollar quote 中的问号，未闭合引用或参数数量不一致会返回错误。

SQL 行映射保留二进制列的 `[]byte` 类型并复制驱动缓冲区；结果出现同名列时必须使用唯一别名，否则返回 `ErrInvalidDatabaseRow`。错误日志只记录参数数量和脱敏 SQL，不记录绑定值；字符串字面量、PostgreSQL dollar quote、行注释和块注释内容都会替换为脱敏标记。

自定义 SQL 方言需要实现完整 `db.Builder`，包括 `QuoteIdentifier`、`QuoteFields`、`Rebind`、`Pagination`、`LockClause`、`SupportsLastInsertId`、`InsertReturning` 和 `MaxBindParams`。不能使用通用多行 `VALUES` 的方言还应实现可选的 `db.BatchInsertBuilder`；Oracle 已通过该接口生成 `INSERT ALL`。`MaxBindParams` 必须返回该驱动单条语句可接受的正数参数预算，否则批量写入会返回配置错误。

## 错误判断

数据库错误支持 `errors.Is`。业务通常需要区分：

```go
switch {
case errors.Is(err, db.ErrUnsafeFullTableMutation):
    // 缺少业务 WHERE 条件。
case errors.Is(err, db.ErrInvalidPagination):
    // 分页为负、越界或溢出。
case errors.Is(err, db.ErrInvalidQuery):
    // 标识符、占位符、上下文或查询状态非法。
case errors.Is(err, db.ErrDatabaseClosed):
    // 数据库已经进入关闭状态。
}
```
