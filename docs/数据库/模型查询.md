# 模型查询

模型查询器 `*db.ModelQuery` 在普通查询器之上保留模型行为：软删除过滤、获取器、修改器、事件、关联预加载和上下文。

## 创建与链式查询

```go
var rows []UserOutput
err := userModel.
	Where("status = ?", 1).
	WithContext(ctx).
	Field("id,name,status").
	Order("id DESC").
	Select(&rows)
```

模型查询器代理查询构造器的条件、字段、排序、分组、JOIN、聚合、分页、锁和写入方法。`PrepareQuery` 可在确有需要时取出已经复制并注入模型配置的底层查询对象；业务服务一般不需要直接使用它。

## 终端方法的模型行为

- `Find(&record)` 查询一行，返回 `(found bool, err error)`，应用当前模型获取器，并按 `With` 预加载关联。
- `Select(&rows)` 查询多行，返回 `error`，应用获取器，并按 `With` 预加载关联。可保存记录使用 `[]*User`，纯输出结构体可使用 `[]UserOutput`。
- 动态字段查询使用 `FindMap()` 和 `SelectMaps()`，分别返回单个 map 和 map 切片。
- `db.Paginate[T](query, page, size)` 返回类型化列表与分页元信息，应用获取器和预加载，`Count` 只负责统计。
- `db.Chunk(query, size, callback)` 与 `db.ChunkById(query, size, callback)` 都对当前批次应用获取器和显式 `With` 预加载，回调签名为 `func([]T) (bool, error)`。
- `db.SeekPage[T](query, size, after)` 按模型主键游标读取一页，不执行 `Count` 或 `OFFSET`，关联只为可见页批量加载。
- `Value` 和 `Column` 在目标字段上应用对应获取器。
- `Count`、`Sum`、`Avg`、`Max`、`Min` 不把关联预加载展开到统计中。

终端方法在查询副本上执行，软删除条件只注入副本，因此同一模型查询可以安全重复调用。

不需要精确总数的列表接口可以使用游标分页：

```go
query := userModel.
	WhereField("status", "=", 1).
	Field("id,name,status")
page, err := db.SeekPage[UserOutput](query, 20, nil)
```

`db.SeekPage` 固定按模型主键升序读取，并要求该字段存在于数据库投影中、唯一、非空且严格递增。首页之后把 `page.NextCursor` 编码后作为 `after` 传入下一次调用；文本或自定义游标列使用 `db.SeekPageWithCodec[T](query, size, field, codec, after)`。需要精确 `total`、`last_page` 时使用 `db.Paginate[T]`。无筛选条件时可通过 `userModel.Query()` 获得独立查询。需要保存的结果使用 `*User` 作为元素类型。

## 软删除范围

```go
active := userModel.Where("status = ?", 1)
all := userModel.WithTrashed().WhereField("status", "=", 1)
deleted := userModel.OnlyTrashed().WhereField("status", "=", 1)
```

`WithTrashed` 和 `OnlyTrashed` 的范围状态保存在本次 `ModelQuery`，不会污染模型本身或其它查询。软删除详情见[模型生命周期](模型生命周期.md)。

## 搜索器

搜索器把服务层的筛选字段转换为查询条件：

```go
if err := userModel.Searcher("keyword", func(q *db.Query, value interface{}, data map[string]interface{}) *db.Query {
	return q.WhereLike("name", "%"+fmt.Sprint(value)+"%")
}); err != nil {
	return err
}

query := userModel.WithSearch(
	[]string{"keyword"},
	map[string]interface{}{"keyword": "go"},
)
var rows []UserOutput
err := query.Select(&rows)
```

`WithSearch` 只应用已注册且在输入 map 中存在的搜索器；输入 map 会复制。字段非法、回调为空或重复注册会返回 `ErrInvalidModel`。搜索器内部仍应使用安全条件 API，不能把搜索值拼接到原生 SQL。

## 模型写入

```go
id, err := userModel.InsertGetId(map[string]interface{}{"name": "张三"})

affected, err := userModel.
	Where("id = ?", id).
	Update(map[string]interface{}{"name": "李四"})
```

模型单行写入会应用修改器、自动时间戳和生命周期事件；结构体写入使用 `Create`、`Update`。更新和删除仍受无 WHERE 全表写保护。

## 上下文与分层

服务方法接收 `context.Context`，并在模型查询入口绑定它：

```go
func (s *UserService) List(ctx context.Context) ([]UserOutput, error) {
	var rows []UserOutput
	err := s.users.WithContext(ctx).Order("id DESC").Select(&rows)
	return rows, err
}
```

控制器只负责验证请求并调用该服务，不把 `*db.ModelQuery` 或数据库行直接作为控制器内部的查询编排入口。
