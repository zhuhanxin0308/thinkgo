# 模型查询

模型查询器 `*db.ModelQuery` 在普通查询器之上保留模型行为：软删除过滤、获取器、修改器、事件、关联预加载和上下文。

## 创建与链式查询

```go
rows, err := userModel.
	Where("status = ?", 1).
	WithContext(ctx).
	Field("id,name,status").
	Order("id DESC").
	Select()
```

模型查询器代理查询构造器的条件、字段、排序、分组、JOIN、聚合、分页、锁和写入方法。`PrepareQuery` 可在确有需要时取出已经复制并注入模型配置的底层查询对象；业务服务一般不需要直接使用它。

## 终端方法的模型行为

- `Find` 查询一行，应用当前模型获取器，并按 `With` 预加载关联。
- `Select` 查询多行，应用获取器，并按 `With` 预加载关联。
- `Paginate` 对列表应用获取器和预加载，`Count` 只负责统计。
- `Chunk` 对每批结果应用获取器和 `With` 预加载；`ChunkById` 对每批结果应用获取器，但当前不执行关联预加载，需要关联数据时使用 `Chunk` 或在服务层单独规划批量关联读取。
- `SeekPage` 按模型主键游标读取一页，应用获取器但不执行 `Count`、`OFFSET` 或 `With` 关联预加载。
- `Value` 和 `Column` 在目标字段上应用对应获取器。
- `Count`、`Sum`、`Avg`、`Max`、`Min` 不把关联预加载展开到统计中。

终端方法在查询副本上执行，软删除条件只注入副本，因此同一模型查询可以安全重复调用。

不需要精确总数的列表接口可以使用游标分页：

```go
page, err := userModel.
	WhereField("status", "=", 1).
	Field("id,name,status").
	SeekPage(20, "id", nil)
```

`SeekPage` 固定按游标字段升序读取，并要求该字段存在于投影中、唯一、非空且严格递增。首页之后把 `page.NextCursor` 编码后作为 `after` 传入下一次调用；文本或自定义主键使用 `SeekPageWithCodec`。需要精确 `total`、`last_page` 时仍使用 `Paginate`。

## 软删除范围

```go
active := userModel.Where("status = ?", 1)
all := userModel.WithTrashed().WhereField("status", "=", 1)
deleted := userModel.OnlyTrashed().WhereField("status", "=", 1)
```

`WithTrashed` 和 `OnlyTrashed` 的范围状态保存在本次 `ModelQuery`，不会污染模型本身或其它查询。软删除详情见[模型生命周期](模型生命周期.md)。

## 搜索器

搜索器把服务层的筛选字段转换为查询条件：

```go
if err := userModel.Searcher("keyword", func(q *db.Query, value interface{}, data map[string]interface{}) {
	q.WhereLike("name", "%"+fmt.Sprint(value)+"%")
}); err != nil {
	return err
}

query := userModel.WithSearch(
	[]string{"keyword"},
	map[string]interface{}{"keyword": "go"},
)
rows, err := query.Select()
```

`WithSearch` 只应用已注册且在输入 map 中存在的搜索器；输入 map 会复制。字段非法、回调为空或重复注册会返回 `ErrInvalidModel`。搜索器内部仍应使用安全条件 API，不能把搜索值拼接到原生 SQL。

## 模型写入

```go
id, err := userModel.Insert(map[string]interface{}{"name": "张三"})

affected, err := userModel.
	Where("id = ?", id).
	UpdateMap(map[string]interface{}{"name": "李四"})
```

模型单行写入会应用修改器、自动时间戳和生命周期事件；结构体写入使用 `Create`、`Update`。更新和删除仍受无 WHERE 全表写保护。

## 上下文与分层

服务方法接收 `context.Context`，并在模型查询入口绑定它：

```go
func (s *UserService) List(ctx context.Context) ([]map[string]interface{}, error) {
	return s.users.With().WithContext(ctx).Order("id DESC").Select()
}
```

控制器只负责验证请求并调用该服务，不把 `*db.ModelQuery` 或数据库行直接作为控制器内部的查询编排入口。
