# 模型

模型封装表名、查询构造器、自动时间戳、软删除、事件、获取器、修改器、搜索器和关联关系。

## 定义模型

```go
package model

import "thinkgo/framework/db"

type User struct {
	*db.Model
}

func NewUser(database *db.DB) *User {
	m := &User{}
	m.Model = db.NewModel(database, "users")
	return m
}
```

显式表名优先。`db.NewModelAuto` 只把结构体名转为 `snake_case`，不会自动复数化。

## 基础查询

```go
userModel := model.NewUser(app.DB)

row, err := userModel.Where("id = ?", 1).Find()
rows, err := userModel.Order("id DESC").Limit(20).Select()
total, err := userModel.Count()
```

`ModelQuery` 会把软删除条件、获取器和关联预加载统一处理，并保证终端方法在克隆上执行。

## 写入与更新

```go
id, err := userModel.Insert(map[string]interface{}{
	"name": "张三",
})

affected, err := userModel.
	WhereField("id", "=", id).
	Update(map[string]interface{}{"name": "李四"})
```

结构体写入：

```go
type UserRow struct {
	ID   int64  `thinkgo:"id,omitempty"`
	Name string `thinkgo:"name"`
}

row := &UserRow{Name: "张三"}
err := userModel.Create(row)
```

结构体更新要求主键非零，并会把主键从 SET 子句中剔除：

```go
row.Name = "李四"
err = userModel.Update(row)
```

`thinkgo:"-"` 跳过字段，`thinkgo:"col,omitempty"` 零值时跳过字段。

## 主键

默认主键是 `id`：

```go
userModel.PrimaryKey("user_id")
```

非默认主键模型在关联预加载、多对多和结构体更新时应显式声明主键。

## 自动时间戳

数据库配置启用 `auto_timestamp` 后，模型会继承全局配置。也可以单独设置：

```go
userModel.
	AutoTimestamp(true).
	CreateTimeField("created_at").
	UpdateTimeField("updated_at")
```

时间值类型由 `timestamp_value_type` 控制：

```text
unix datetime timestamp date
```

## 软删除

```go
userModel.SoftDelete("delete_time")

rows, err := userModel.Select()              // 默认排除已删除
rows, err = userModel.WithTrashed().Select() // 包含已删除
rows, err = userModel.OnlyTrashed().Select() // 仅已删除

_, err = userModel.WhereField("id", "=", 1).Delete()
_, err = userModel.WhereField("id", "=", 1).Restore()
_, err = userModel.WhereField("id", "=", 1).ForceDelete()
```

`ForceDelete` 和 `Restore` 禁止无 WHERE 执行。

## 获取器与修改器

```go
userModel.Getter("status", func(value interface{}, row map[string]interface{}) interface{} {
	if fmt.Sprint(value) == "1" {
		return "启用"
	}
	return "禁用"
})

userModel.Setter("password", func(value interface{}, row map[string]interface{}) interface{} {
	return hashPassword(fmt.Sprint(value))
})
```

获取器作用于查询结果，修改器作用于插入和更新数据。

## 搜索器

```go
userModel.Searcher("keyword", func(q *db.Query, value interface{}, data map[string]interface{}) {
	q.WhereLike("name", "%"+fmt.Sprint(value)+"%")
})

rows, err := userModel.WithSearch(
	[]string{"keyword"},
	map[string]interface{}{"keyword": "go"},
).Select()
```

## 模型事件

```go
userModel.On(db.ModelBeforeInsert, func(data map[string]interface{}) bool {
	return data["name"] != ""
})
```

事件类型：

```text
before_insert after_insert before_update after_update before_delete after_delete
```

`before_*` 回调返回 `false` 会阻止操作。

## 关联定义

一对一：

```go
userModel.DefineHasOne("profile", profileModel, "user_id", "id")
```

一对多：

```go
userModel.DefineHasMany("orders", orderModel, "user_id", "id")
```

反向关联：

```go
orderModel.DefineBelongsTo("user", userModel, "user_id", "id")
```

多对多：

```go
userModel.DefineBelongsToMany("roles", roleModel, "user_role", "user_id", "role_id", "id")
```

预加载：

```go
rows, err := userModel.With("profile", "orders").Select()
```

## 分页与遍历

```go
p, err := userModel.WhereField("status", "=", 1).Paginate(1, 20)

err = userModel.ChunkById(1000, "id", func(rows []map[string]interface{}) bool {
	return true
})
```

模型分页会自动应用获取器和关联预加载。

## 上下文

```go
rows, err := userModel.
	WhereField("status", "=", 1).
	WithContext(req.Raw().Context()).
	Select()
```

HTTP 请求中建议传入请求上下文，使数据库操作随请求取消。
