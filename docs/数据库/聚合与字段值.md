# 聚合与字段值

查询构造器提供常用聚合和字段读取方法，返回值会经过严格类型校验，不会把异常结果静默转换成零值。

## 聚合方法

```go
database := app.DB()
total, err := database.Name("orders").Count()
sum, err := database.Name("orders").Sum("amount")
avg, err := database.Name("orders").Avg("amount")
max, err := database.Name("orders").Max("amount")
min, err := database.Name("orders").Min("amount")
```

`Sum`、`Avg`、`Max`、`Min` 返回 `float64`。字段名会按安全标识符规则校验；驱动返回的整数、浮点、文本和 `json.Number` 会被解析，NaN、无穷、非法文本和溢出会返回 `ErrInvalidAggregateValue`。

## Count

简单查询直接统计目标表；存在 JOIN、GROUP、HAVING 或 DISTINCT 时，框架会先构造完整 SELECT，再执行：

```sql
SELECT COUNT(*) FROM (
    -- 完整的 JOIN/GROUP/HAVING/DISTINCT 查询
) tg_count_sub
```

因此 `Count` 和 `Paginate` 的 `total` 表示最终结果行数，而不是被 JOIN 放大的底层扫描行数，也不是分组前的原始记录数。

计数结果必须是非负整数。负数、小数、NaN、无穷、超出 `int64` 范围或无法解析的文本都会返回错误。

## Value

```go
name, err := database.Name("users").
	WhereField("id", "=", 1).
	Value("name")
```

`Value(field)` 查询一行并返回指定字段。目标字段不存在时返回 `ErrInvalidDatabaseRow`，不会从其他字段猜测结果；没有记录时返回 `nil, nil`。

## Column

```go
names, err := database.Name("users").Column("name")
nameMap, err := database.Name("users").Column("name", "id")
```

不传 key 时，返回按查询顺序组织的字段切片；传入 key 时，返回 key 到目标字段值的映射。每一行必须同时包含目标字段和 key 字段；缺列、重复 key 或字符串化后发生 key 冲突会返回 `ErrInvalidDatabaseRow`，不会覆盖先写入的数据。

字段支持 `table.column` 限定，也兼容 SQL 驱动返回的末段列名。JOIN 场景应显式选择并设置唯一别名，避免驱动列名冲突。

## 模型查询

模型查询器复用这些方法：

```go
count, err := userModel.Where("status = ?", 1).Count()
names, err := userModel.Field("name").Column("name")
```

聚合和字段读取不会加载模型关联或应用获取器到聚合值；`Find`、`Select` 读取行时才由模型查询器应用获取器和预加载关联。
