# 连接管理

业务代码通过 `app.DB()` 取得默认连接，通过 `app.DBManager()` 取得命名连接管理器。默认 lazy 策略只注册连接工厂，首次访问某个连接时才真正建立连接池。

## 默认连接

```go
database := app.DB()
if database == nil {
	return db.ErrDatabaseUnavailable
}

users := database.Name("users")
archive := database.Table("archive_users")
```

`Name` 接收不带前缀的短表名，并自动追加 `database.prefix`；`Table` 接收最终完整表名，不追加前缀。每次调用都会返回独立 Query，同一个 DB 可以被并发请求安全复用。

## 命名连接

```go
manager := app.DBManager()
read, err := manager.Connection("read")
if err != nil {
	return err
}

rows, err := read.Name("users").Select()
```

并发首次访问同名 lazy 连接时只执行一次连接工厂；失败会返回给所有等待者，下一次访问允许重试。连接名称非法、未配置或管理器已经关闭时返回明确错误。

## 请求上下文

```go
rows, err := app.DB().
	Name("orders").
	WithContext(request.Raw().Context()).
	Select()
```

数据库驱动会接收请求取消和截止时间。不要把请求 Context 保存到应用级 DB 或 Manager 中。

## 手动连接

框架外脚本或测试可以显式创建连接：

```go
connector.RegisterBuiltins()

database, err := db.Connect(db.Config{
	Type:     "sqlite",
	Database: "runtime/task.db",
})
if err != nil {
	return err
}
defer database.Close()
```

普通 HTTP 业务不要在每个请求中反复 `db.Connect`，应复用 `app.DB()` 或 `app.DBManager()` 管理的连接。

## 关闭

应用退出时 `App.Close()` 统一关闭 Manager 管理的所有连接。`DB.Close` 和 `Manager.Close` 都是幂等的；关闭会阻止新租约，等待已经开始的查询或事务结束，再关闭底层连接。

只有手工创建且不交给应用管理的 DB 才由调用方负责关闭。
