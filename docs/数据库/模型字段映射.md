# 模型字段映射

模型结构体写入通过 `thinkgo` 标签把 Go 字段映射为数据库列。未指定标签时，导出的字段名自动转换为小写蛇形。

## 标签语法

```go
type UserRecord struct {
	ID          int64  `thinkgo:"id,omitempty"`
	DisplayName string `thinkgo:"display_name"`
	Password    string `thinkgo:"password,omitempty"`
	Runtime     string `thinkgo:"-"`
}
```

标签规则：

- `thinkgo:"-"`：跳过字段。
- `thinkgo:"column"`：显式指定列名。
- `thinkgo:"column,omitempty"`：字段为零值时跳过。
- 空标签：使用 Go 字段名转小写蛇形，例如 `CreatedAt` 映射为 `created_at`。

只有导出字段参与映射；未导出的字段会被跳过。列名必须是安全标识符，未知标签选项、重复列名或不可写字段会返回 `ErrInvalidModel`。

## Create

```go
user := &UserRecord{DisplayName: "张三"}
if err := userModel.Create(user); err != nil {
	return err
}
```

`Create` 要求传入非 nil 的结构体指针。主键为零值时会从 INSERT 数据中移除，交给数据库生成；如果方言支持主键回传，生成的整数主键会写回原结构体。自定义主键必须先使用 `PrimaryKey` 配置。

显式提供非零主键时，框架会保留它并按普通字段写入。结构体映射使用内部数据副本，修改器、自动时间戳和事件不会修改结构体中未参与回填的原始字段。

## Update

```go
user := &UserRecord{ID: 10, DisplayName: "李四"}
if err := userModel.Update(user); err != nil {
	return err
}
```

`Update` 要求主键存在且为非零值，并自动把主键作为 `WHERE` 条件，同时从 SET 数据中剔除主键。这样结构体更新不会退化为无条件全表更新，也不会意外改写主键。

如果更新接口需要部分字段，应使用 `omitempty`，或在服务层构造明确的 map；不要把未赋值的零值直接当作“保持不变”。

## 修改器和数据副本

模型修改器会在结构体映射完成后作用于写入数据：

```go
if err := userModel.Setter("password", func(value interface{}, row map[string]interface{}) interface{} {
	return hashPassword(fmt.Sprint(value))
}); err != nil {
	return err
}
```

map 写入和结构体写入都会使用修改器。框架会复制输入 map；修改器可以改变内部工作副本，但不能通过副作用污染调用方原始 map。

## 主键与关联

默认主键字段是 `id`。自定义主键示例：

```go
userModel.PrimaryKey("user_id")
```

主键配置会影响结构体更新、插入主键回填、`ChunkById` 的默认业务约定和多对多关联读取。关联定义中使用的本地键、外键和所有者键必须实际存在于查询投影中；否则预加载会返回关联错误。
