# 数据库 - 连接数据库

本章介绍 ThinkGo 数据库层的连接机制：支持的数据库类型、配置方式、环境变量覆盖、连接池、多连接管理、启动期连接行为，以及相关开发约束。查询构造、模型、事务等内容见同目录其它章节。

---

## 1. 架构概览

数据库层由四个角色组成：

| 角色 | 类型 | 职责 |
|---|---|---|
| 连接器注册表 | `db.RegisterConnector` / `db.GetConnector` | 按数据库类型名注册/查找连接器；注册、查找均返回错误，重复名称不会覆盖原连接器 |
| 连接器 | `db.Connector` 接口 | 把 `db.Config` 转换为一个具体 `db.Connection`（建立底层驱动连接） |
| 连接 | `db.Connection` 接口 | 封装底层驱动（`database/sql`、Mongo、Neo4j 等），向上提供统一执行能力 |
| 连接句柄 | `*db.DB` | 持有一个连接及全局配置（前缀、时间戳策略），是业务侧使用的入口 |
| 连接管理器 | `*db.Manager` | 管理多个命名 `*db.DB`，维护默认连接语义，统一关闭 |

业务侧主要面对两个对象：

- `app.DB`：默认连接（`*db.DB`）。
- `app.DBManager`：多连接管理器（`*db.Manager`）。

连接器通过各自的 `init()` 在包导入时自动注册。应用入口通过空导入 `_ "thinkgo/framework/db/connector"` 触发全部连接器注册。自定义连接器必须处理注册错误：

```go
if err := db.RegisterConnector("custom", connector); err != nil {
    return err
}
```

连接器名称必须是安全标识符；空实现、类型化 `nil` 和重复注册会分别返回可识别错误。

## 2. 支持的数据库类型

`framework/db/connector` 包内置以下连接器，注册名即配置中的 `type` 值：

| `type` | 数据库 | 底层 Go 驱动 | 说明 |
|---|---|---|---|
| `mysql` | MySQL / MariaDB | `github.com/go-sql-driver/mysql` | 默认启用 TLS、连接池调优与存活检查 |
| `pgsql` | PostgreSQL | `github.com/lib/pq` | DSN 默认 `sslmode=require`；自增主键回传用 `RETURNING <primary_key>` |
| `sqlsrv` | SQL Server | `github.com/microsoft/go-mssqldb` | 分页用 `OFFSET … FETCH` |
| `oracle` | Oracle | godror | 需使用 `-tags oracle` 构建；分页用 `OFFSET … FETCH` |
| `sqlite` | SQLite | `github.com/mattn/go-sqlite3` | `database` 是普通文件路径或 `:memory:`；需 CGO |
| `mongo` | MongoDB 4.2+ | `go.mongodb.org/mongo-driver/v2` v2.8.0 | 默认启用 TLS，URI 使用标准 URL 构造并转义凭据 |
| `neo4j` | Neo4j | neo4j-go-driver | 默认协议 `neo4j+s`；`database` 可省略以使用服务端默认库 |

> SQLite 依赖 CGO，编译环境需具备 C 工具链（gcc）。Windows + MSYS2 必须把对应的 `ucrt64/bin` 加入 `PATH`，否则 GCC 无法定位链接子工具；`build_linux.bat` 生成的 `nocgo` 产物不包含 SQLite 驱动能力。
>
> Oracle 连接器和方言仅在 `oracle` 构建标签下编译，并需要 godror 对应的 CGO/Oracle 客户端环境。
>
> `mongo`、`neo4j` 的连接已注册，但其查询模型与 SQL 连接差异较大，详见各自章节；本章聚焦 SQL 连接的建立流程。

## 3. 配置文件 `config/database.json`

配置文件名 `database` 即一级命名空间。`default` 和非空 `connections` 都是必需项，且 `default` 必须引用已声明连接；框架不会自动挑选或创建默认连接：

```json
{
    "default": "mysql",
    "connections": {
        "mysql": {
            "type": "mysql",
            "hostname": "127.0.0.1",
            "hostport": "3306",
            "database": "your_database",
            "username": "your_username",
            "password": "",
            "charset": "utf8mb4",
            "prefix": "",
            "debug": false,
            "auto_timestamp": true,
            "create_time_field": "create_time",
            "update_time_field": "update_time",
            "timestamp_value_type": "unix",
            "params": {
                "timeout": "5s"
            }
        }
    }
}
```

### 配置项参考

| JSON 键 | 类型 | 对应 `db.Config` 字段 | 默认/回退 | 说明 |
|---|---|---|---|---|
| `type` | string | `Type` | 无 | 连接器类型名（见上表），必填 |
| `hostname` | string | `Hostname` | 无 | 网络数据库主机地址，必填 |
| `hostport` | string | `Hostport` | 可空 | 十进制端口字符串；非空时范围为 `1-65535` |
| `database` | string | `Database` | 无 | 数据库名，除 Neo4j 外必填；SQLite 为文件路径 |
| `username` | string | `Username` | 空 | 用户名 |
| `password` | string | `Password` | 空 | 密码 |
| `charset` | string | `Charset` | `utf8mb4`（MySQL） | 字符集 |
| `prefix` | string | `Prefix` | 空 | 全局表前缀 |
| `debug` | bool | `Debug` | `false` | 是否开启 SQL 调试 |
| `auto_timestamp` | bool | `AutoTimestamp` | `false` | 是否自动维护时间戳字段 |
| `create_time_field` | string | `CreateTimeField` | `create_time` | 创建时间字段名 |
| `update_time_field` | string | `UpdateTimeField` | `update_time` | 更新时间字段名 |
| `timestamp_value_type` | string | `TimestampValueType` | `unix` | 时间戳落库类型：`unix`/`datetime`/`timestamp`/`date` |
| `max_open_conns` | int | `MaxOpenConns` | 25（SQL 连接） | 最大打开连接数；`0` 使用连接器默认值 |
| `max_idle_conns` | int | `MaxIdleConns` | 10（SQL 连接） | 最大空闲连接数；不能超过最大打开数 |
| `conn_max_lifetime_seconds` | int | `ConnMaxLifetimeSeconds` | 300（SQL 连接） | 连接最大生命周期（秒） |
| `conn_max_idle_time_seconds` | int | `ConnMaxIdleTimeSeconds` | 120（SQL 连接） | 连接最大空闲时长（秒） |
| `params` | object | `Params` | 空 | 额外连接参数；键和值都必须是字符串 |

配置采用严格解析：未知字段、类型错误、负数、小数、数值溢出、非法标识符或连接坐标都会形成启动错误，不会截断或静默忽略。连接池数值 `0` 表示使用连接器默认值。

`params` 支持从 JSON 读取，但不会把数字或布尔值隐式转换成字符串。Neo4j 只接受 `params.scheme`；MongoDB 会拒绝大小写不同的重复参数和同时配置 `tls`/`ssl` 的歧义写法。

## 4. 环境变量覆盖

部署时无需修改配置文件，可用环境变量覆盖**默认连接**的关键参数：

| 环境变量 | 覆盖字段 |
|---|---|
| `DB_TYPE` | `type` |
| `DB_HOST` | `hostname` |
| `DB_PORT` | `hostport` |
| `DB_USER` | `username` |
| `DB_PASS` | `password` |
| `DB_NAME` | `database` |
| `DB_MAX_OPEN_CONNS` | `max_open_conns` |
| `DB_MAX_IDLE_CONNS` | `max_idle_conns` |
| `DB_CONN_MAX_LIFETIME_SECONDS` | `conn_max_lifetime_seconds` |
| `DB_CONN_MAX_IDLE_TIME_SECONDS` | `conn_max_idle_time_seconds` |
| `DB_TIMESTAMP_VALUE_TYPE` | `timestamp_value_type` |

`.env` 示例：

```text
DB_TYPE=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASS=secret
DB_NAME=thinkgo
DB_MAX_OPEN_CONNS=25
DB_MAX_IDLE_CONNS=10
DB_CONN_MAX_LIFETIME_SECONDS=300
```

优先级（从高到低，遵循 12-factor）：

1. **系统环境变量**（真实进程环境变量）
2. `.env` 文件
3. `config/database.json`
4. 连接器自身的安全默认值

> 重要约束：
> - 环境变量覆盖**只作用于默认连接**（`default` 指向的那个）。非默认连接只能通过 `config/database.json` 配置。
> - 真实系统环境变量优先于 `.env` 文件（便于容器/CI 注入覆盖），`.env` 仅本地兜底；框架加载 `.env` 时不调用 `os.Setenv`，不会把 `DB_PASS` 等敏感值泄露进程环境。
> - 数值型环境变量必须是非负整数；非法值会阻止应用启动，`0` 表示使用连接器默认值。覆盖过程是原子的，任一字段非法时不会留下部分覆盖结果。

## 5. 连接池

MySQL、PostgreSQL、SQLite、SQL Server 和 Oracle 统一应用以下连接池默认值与配置规则：

| 参数 | 默认值 | 配置为 `0` / 负数时 |
|---|---|---|
| `MaxOpenConns` | 25 | 使用默认 / 返回配置错误 |
| `MaxIdleConns` | 10 | 使用默认 / 返回配置错误 |
| `ConnMaxLifetime` | 5 分钟 | 使用默认 / 返回配置错误 |
| `ConnMaxIdleTime` | 2 分钟 | 使用默认 / 返回配置错误 |

每个 SQL 连接在返回前都会使用 5 秒有界上下文执行 `PingContext`；失败时同时关闭连接池并保留探测与关闭错误。

MySQL DSN 默认注入 `charset=utf8mb4`、`parseTime=True`、`loc=Local`、`checkConnLiveness=true` 和 `tls=true`。如本地环境确需明文连接，必须在受信配置中显式设置 `params.tls`；`multiStatements`、`allowAllFiles`、`allowCleartextPasswords`、`allowFallbackToPlaintext` 的 `true` 值会被拒绝。

SQLite 默认启用外键、5 秒忙等待和文件库 WAL。普通数据库文件会以私有权限创建或收紧为 `0600`（Windows 除外），符号链接、特殊文件和携带 URI 参数的路径会被拒绝；新建文件若连接失败会被清理。`:memory:` 强制最多一个池连接，防止连接池产生互相隔离的多个内存库。

## 6. 获取连接

### 默认连接

```go
// 默认连接（config 中 default 指向的那个）
user, err := app.DB.Name("users").WhereField("id", "=", 1).Find()
```

### 命名连接（多库）

```go
// 取指定名称的连接；不存在时返回 error
read, err := app.DBManager.Connection("read")
if err != nil {
    return c.Error("数据库连接不存在", 500)
}
rows, err := read.Name("users").Select()

// 取默认连接（等价于 app.DB）；缺失或管理器已关闭时返回 error
def, err := app.DBManager.Default()
if err != nil {
    return c.Error("默认数据库不可用", 500)
}
```

初始化成功时，`app.DB` 与 `app.DBManager.Default()` 返回同一个默认连接实例。需要访问底层连接时使用 `connection, err := app.DB.GetConnection()`，关闭后会返回错误而不是暴露失效句柄。

## 7. 多数据库连接

在 `connections` 下声明多个连接，`default` 指定默认连接名：

```json
{
    "default": "mysql",
    "connections": {
        "mysql": {
            "type": "mysql",
            "hostname": "127.0.0.1",
            "hostport": "3306",
            "database": "app_main",
            "username": "root",
            "password": ""
        },
        "read": {
            "type": "mysql",
            "hostname": "10.0.0.21",
            "hostport": "3306",
            "database": "app_main",
            "username": "reader",
            "password": ""
        },
        "log": {
            "type": "pgsql",
            "hostname": "127.0.0.1",
            "hostport": "5432",
            "database": "app_log",
            "username": "postgres",
            "password": ""
        }
    }
}
```

启动时框架按连接名称排序后逐个建立 `connections`，并以连接名注册到 `app.DBManager`；`default` 对应的连接同时绑定到 `app.DB`。连接名称非法、重复注册或默认连接缺失都会形成启动错误，不会覆盖已有实例。

## 8. 程序内手动连接

需要在框架托管之外建立连接（如脚本、测试、临时任务）时，直接使用 `db.Connect`：

```go
import "thinkgo/framework/db"

database, err := db.Connect(db.Config{
    Type:     "mysql",
    Hostname: "127.0.0.1",
    Hostport: "3306",
    Database: "thinkgo",
    Username: "root",
    Password: "secret",
    Charset:  "utf8mb4",
    Prefix:   "tg_",
    // 手动连接同样支持注入额外 DSN 参数。
    Params: map[string]string{
        "timeout":      "5s",
        "readTimeout":  "5s",
        "writeTimeout": "5s",
    },
    MaxOpenConns: 50,
})
if err != nil {
    log.Fatal(err)
}
defer database.Close()
```

`db.Connect` 会先复制并校验配置，再按 `Type` 查连接器、建立连接、验证可达性，最后应用前缀和自动时间戳策略。未注册类型、空连接或连接器错误都会原样返回，不会产生半可用 `*db.DB`。

## 9. 启动期连接行为

应用初始化（`App.Initialize`）阶段处理数据库连接，关键行为：

1. 严格读取 `database.default` 与非空 `database.connections`，验证默认名称确实存在。
2. 按名称排序后逐个 `db.Connect`，按名注册到 `DBManager`；默认连接绑定 `app.DB`。
3. **任一连接配置、覆盖、连接或注册失败**：记录错误并设置内部 `startupErr`；不会创建隐式回退连接，也不会把非默认连接提升为默认连接。

所有内置 SQL、MongoDB 和 Neo4j 连接器都会在连接阶段执行有界可达性检查；检查失败时会关闭已创建的驱动资源并聚合关闭错误。

启动错误在不同入口的处理不同：

| 入口 | 行为 |
|---|---|
| `go run main.go`（`App.Run`） | `startupErr` 非空时**中止启动并 panic**（不启动半初始化的服务） |
| `think run`（开发用命令） | 仅**告警**，仍尝试启动，便于数据库未就绪时调试非数据库路由 |
| 其它命令行命令（`version`/`list`/`make:*` 等） | 使用 `framework.NewConsoleApp()`**跳过数据库连接**，`app.DB` 为 `nil` |

> 因此：编写控制台命令时不要假设 `app.DB` 非 `nil`，需要数据库的自定义命令应自行判断或单独建立连接。

---

## 10. 关闭连接

长期运行服务退出前应关闭连接释放连接池。`app.Run()` 会调用幂等的 `app.Close()`：在 Provider 逆序退出和缓存驱动关闭后，优先 `app.DBManager.Close()`（关闭全部命名连接并去重），否则关闭 `app.DB`，并把 Provider、缓存、数据库与日志关闭错误聚合返回。

`DB.Close()` 会先冻结新操作，再等待正在执行的查询和事务释放租约后关闭底层连接；并发或重复关闭会得到同一个稳定结果。`DBManager.Close()` 关闭后不再允许添加或获取连接。

手动建立的连接由调用方负责 `defer database.Close()`。

## 11. 开发约束规范

- **不要硬编码凭据**：账号、密码、主机等通过 `config/database.json` 或环境变量提供；敏感值（密码）优先用环境变量，不要提交进仓库的 `.env`/JSON。
- **生产连接信息用环境变量注入**：利用「系统环境变量 > `.env`」的优先级，在容器/CI 中覆盖默认配置，不改文件。
- **非默认连接不受 `DB_*` 环境变量影响**：多库场景中只有默认连接能被环境变量覆盖，其余连接的差异化配置必须写入 JSON。
- **控制台命令不得假设 `app.DB` 存在**：非 `run` 命令默认跳过连库。
- **连接类型必须是已注册类型**：`type` 取值限于 §2 列表，否则启动报 `connector not found`。
- **SQLite 的 `database` 是普通文件路径或 `:memory:`**，不得夹带 `file:`、`?`、`#` 参数，也不得指向符号链接；注意 CGO 依赖。
- **网络数据库默认使用加密连接**：MySQL、PostgreSQL、MongoDB、Neo4j 均提供安全默认值；本地显式降级只能放在受信配置中。
- **手动 `db.Connect` 必须配对 `Close`**，避免连接泄漏。
- 连接建立属于启动期一次性动作，不要在请求处理中反复 `db.Connect`；请求中复用 `app.DB` / `app.DBManager`。

## 12. 完整示例

`config/database.json`（主库 + 只读库）：

```json
{
    "default": "mysql",
    "connections": {
        "mysql": {
            "type": "mysql",
            "hostname": "127.0.0.1",
            "hostport": "3306",
            "database": "shop",
            "username": "root",
            "password": "",
            "charset": "utf8mb4",
            "prefix": "tg_",
            "auto_timestamp": true,
            "max_open_conns": 50,
            "max_idle_conns": 20,
            "conn_max_lifetime_seconds": 600
        },
        "read": {
            "type": "mysql",
            "hostname": "10.0.0.21",
            "hostport": "3306",
            "database": "shop",
            "username": "reader",
            "password": ""
        }
    }
}
```

`.env`（生产用环境变量覆盖默认连接的敏感项）：

```text
DB_HOST=db-prod.internal
DB_USER=app
DB_PASS=prod-secret
DB_NAME=shop
```

控制器中按连接使用：

```go
func (c *Order) Recent() *context.Response {
    // 写走默认连接
    id, err := c.App.DB.Name("orders").Insert(map[string]interface{}{
        "user_id": 1,
        "amount":  99,
    })
    if err != nil {
        return c.Error("下单失败", 500)
    }

    // 读走只读库
    read, err := c.App.DBManager.Connection("read")
    if err != nil {
        return c.Error("只读库不可用", 500)
    }
    rows, err := read.Name("orders").Order("id DESC").Page(1, 20).Select()
    if err != nil {
        return c.Error("查询失败", 500)
    }
    return context.NewResponse().Json(map[string]interface{}{
        "id":   id,
        "list": rows,
    })
}
```
