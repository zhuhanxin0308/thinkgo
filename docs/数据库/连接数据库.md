# 连接数据库

数据库配置使用 ThinkPHP 同名的 `config/database.json`。普通业务通过 `app.DB()` 和 `app.DBManager()` 使用连接，不需要解析容器服务名或在入口文件装配连接池。

## 默认配置结构

```json
{
    "default": "mysql",
    "time_query_rule": {},
    "auto_timestamp": true,
    "datetime_format": "Y-m-d H:i:s",
    "datetime_field": "",
    "connections": {
        "mysql": {
            "type": "mysql",
            "hostname": "127.0.0.1",
            "database": "",
            "username": "root",
            "password": "",
            "hostport": "3306",
            "params": {},
            "charset": "utf8mb4",
            "prefix": "",
            "deploy": 0,
            "rw_separate": false,
            "master_num": 1,
            "slave_no": "",
            "fields_strict": true,
            "break_reconnect": false,
            "trigger_sql": true,
            "fields_cache": false
        }
    }
}
```

`default` 必须指向 `connections` 中已声明的连接。未知字段、类型错误、非法连接名或不受支持的非默认能力会返回配置错误，不会静默忽略。

## 默认 lazy 行为

与 ThinkPHP 一样，默认启动只加载并校验连接配置，不立即访问数据库。首次调用默认连接时才建立连接：

```go
database := app.DB()
if database == nil {
	return db.ErrDatabaseUnavailable
}

user, err := database.Name("user").
	Where("id = ?", 1).
	Find()
```

同名连接并发首访只执行一次连接工厂，成功后复用连接池；失败返回给当前调用，后续访问可以重试。

## 命名连接

```go
manager := app.DBManager()
read, err := manager.Connection("read")
if err != nil {
	return err
}

rows, err := read.Name("user").Select()
```

`manager.Default()` 与 `app.DB()` 指向同一个默认连接。

## 启动策略扩展

Go 长期运行服务可以在 `config/app.json` 额外声明 `database_startup_policy`：

| 值 | 行为 |
|---|---|
| `lazy` | 默认行为；首次使用时连接 |
| `required` | 启动期连接默认数据库，失败阻止监听 |
| `degraded` | 启动期连接，失败允许启动但 readiness 失败 |
| `disabled` | 不注册数据库连接 |

未声明时固定使用 `lazy`，这与 ThinkPHP 默认连接时机一致。该字段是 Go 服务部署扩展，不改变 `config/database.json` 的字段名称。

## 环境变量

系统环境变量优先于 `.env`，`.env` 优先于 JSON。完整点路径转成大写下划线：

```text
DATABASE_DEFAULT
DATABASE_CONNECTIONS_MYSQL_HOSTNAME
DATABASE_CONNECTIONS_MYSQL_HOSTPORT
DATABASE_CONNECTIONS_MYSQL_DATABASE
DATABASE_CONNECTIONS_MYSQL_USERNAME
DATABASE_CONNECTIONS_MYSQL_PASSWORD
```

`.env` 可以使用 ThinkPHP 风格分组：

```ini
[DATABASE]
CONNECTIONS_MYSQL_HOSTNAME = 127.0.0.1
CONNECTIONS_MYSQL_DATABASE = thinkgo
CONNECTIONS_MYSQL_USERNAME = root
CONNECTIONS_MYSQL_PASSWORD = secret
```

## 支持的连接器

| `type` | 数据库 | 主要边界 |
|---|---|---|
| `mysql` | MySQL / MariaDB | 默认 TLS、utf8mb4、UTC 时间参数 |
| `pgsql` | PostgreSQL | 默认 `sslmode=verify-full` |
| `sqlsrv` | SQL Server | 默认加密连接 |
| `oracle` | Oracle | 需要 Oracle 构建环境 |
| `sqlite` | SQLite | 需要 CGO；支持普通文件或 `:memory:` |
| `mongo` | MongoDB | 不提供 SQL JOIN、GROUP 或原生 SQL |
| `neo4j` | Neo4j | 使用 Label 和参数化 Cypher |

宿主入口会调用 `connector.RegisterBuiltins()` 注册内置连接器。只有框架外脚本、自定义宿主或独立测试需要自行调用。

## 连接池

SQL 连接默认值：

| 参数 | 默认值 |
|---|---:|
| 最大打开连接数 | 25 |
| 最大空闲连接数 | 10 |
| 最大生命周期 | 5 分钟 |
| 最大空闲时长 | 2 分钟 |
| Ping 超时 | 5 秒 |

可以在连接配置中使用：

```json
{
    "max_open_conns": 50,
    "max_idle_conns": 20,
    "conn_max_lifetime_seconds": 300,
    "conn_max_idle_time_seconds": 120
}
```

## 安全默认值

- MySQL 默认启用 TLS、`utf8mb4`、连接存活检查和 UTC；生产环境不得使用 `skip-verify`。
- PostgreSQL 默认 `sslmode=verify-full`，同时校验证书链与主机名；SQL Server 默认加密。
- SQLite 启用外键、忙等待和文件库 WAL；拒绝符号链接与 URI 参数路径。
- MongoDB 默认 TLS，Neo4j 默认加密协议。
- 所有原生 SQL 必须参数化，连接错误文本会脱敏后写入日志。

## 手动连接

框架外脚本或测试可以直接连接，并由调用方关闭：

```go
connector.RegisterBuiltins()

database, err := db.Connect(db.Config{
	Type:     "sqlite",
	Database: "runtime/task.db",
})
if err != nil {
	return err
}
defer database.Close()
```

HTTP 业务应复用 `app.DB()`，不要在请求处理中反复创建连接。

## 关闭

应用退出时 `App.Close()` 统一关闭 DBManager 中的连接。正在执行的查询和事务会先释放租约；重复关闭返回稳定结果。连接管理细节见[连接管理](连接管理.md)。
