# 事件

事件入口是 `app.Event`，底层为 `event.Dispatcher`。事件用于解耦生命周期回调和业务扩展。

## 基础事件

```go
app.Event.Dispatch(event.NewEvent("user.created", userID))
```

监听事件：

```go
type UserCreatedListener struct{}

func (l *UserCreatedListener) Handle(e event.Event) {
	if simple, ok := e.(*event.SimpleEvent); ok {
		_ = simple.Data
	}
}

app.Event.Listen("user.created", &UserCreatedListener{})
```

也可以用函数监听器：

```go
app.Event.Listen("user.created", &event.SimpleListener{
	Handler: func(e event.Event) {
		// 处理事件。
	},
})
```

## 优先级

```go
app.Event.Listen("user.created", listenerA, 10)
app.Event.Listen("user.created", listenerB, 1)
```

数值越大越先执行。优先级相同时按注册顺序执行。

## 通配监听

事件名支持通配匹配：

```go
app.Event.Listen("user.*", listener)
```

通配规则使用 Go `path.Match` 语义。

## 停止传播

`event.SimpleEvent` 支持停止传播：

```go
e := event.NewEvent("user.created", userID)
e.StopPropagation()
```

调度器发现事件实现 `IsPropagationStopped() bool` 且返回 `true` 时，会停止继续调用后续监听器。

## 订阅者

订阅者可以一次注册多个监听器：

```go
type UserSubscriber struct{}

func (s *UserSubscriber) Subscribe(dispatcher *event.Dispatcher) {
	dispatcher.Listen("user.created", &UserCreatedListener{})
	dispatcher.Listen("user.deleted", &UserDeletedListener{})
}

app.Event.Subscribe(&UserSubscriber{})
```

## 框架生命周期事件

框架会触发以下生命周期事件：

| 事件 | 触发时机 |
|---|---|
| `AppInit` | 应用初始化完成 |
| `RouteLoaded` | 路由加载完成 |
| `HttpRun` | 每个 HTTP 请求开始 |
| `HttpEnd` | 每个 HTTP 请求结束 |

事件类型由 `framework/event` 包提供。业务代码可以监听这些事件实现扩展逻辑。

## 自定义事件类型

只要实现 `Name() string` 即可作为事件：

```go
type OrderPaid struct {
	ID int64
}

func (e OrderPaid) Name() string {
	return "order.paid"
}
```
