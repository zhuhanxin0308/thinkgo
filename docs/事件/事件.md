# 事件

事件服务通过 `framework.ServiceEvent` 解析为 `*event.Dispatcher`。事件用于解耦生命周期回调和业务扩展。以下示例假定已完成：

```go
dispatcher, err := framework.ResolveServiceAs[*event.Dispatcher](app, framework.ServiceEvent)
if err != nil {
	return err
}
```

## 基础事件

```go
if err := dispatcher.Dispatch(event.NewEvent("user.created", userID)); err != nil {
	return err
}
```

监听事件：

```go
type UserCreatedListener struct{}

func (l *UserCreatedListener) Handle(e event.Event) error {
	if simple, ok := e.(*event.SimpleEvent); ok {
		_ = simple.Data
	}
	return nil
}

if err := dispatcher.Listen("user.created", &UserCreatedListener{}); err != nil {
	return err
}
```

也可以用函数监听器：

```go
if err := dispatcher.Listen("user.created", &event.SimpleListener{
	Handler: func(e event.Event) error {
		// 处理事件。
		return nil
	},
}); err != nil {
	return err
}
```

`Listen`、`Subscribe` 和 `Dispatch` 都返回错误。空名称、类型化 nil、畸形通配符、监听器业务错误以及事件/监听器/订阅者 panic 都可由调用方处理；单个事件名最多 256 字节。

动态模块卸载时调用 `Forget("事件名或通配模式")` 移除对应监听器。精确事件通过直接索引解析，分发成本只随匹配的通配模式和监听器数量增长。

## 优先级

```go
if err := dispatcher.Listen("user.created", listenerA, 10); err != nil {
	return err
}
if err := dispatcher.Listen("user.created", listenerB, 1); err != nil {
	return err
}
```

数值越大越先执行。优先级相同时按注册顺序执行。

## 通配监听

事件名支持通配匹配：

```go
if err := dispatcher.Listen("user.*", listener); err != nil {
	return err
}
```

通配规则使用 Go `path.Match` 语义。

## 停止传播

`event.SimpleEvent` 支持停止传播：

```go
e := event.NewEvent("user.created", userID)
e.StopPropagation()
```

调度器发现事件实现 `IsPropagationStopped() bool` 且返回 `true` 时，会停止继续调用后续监听器。

## 订阅者

订阅者可以一次注册多个监听器：

```go
type UserSubscriber struct{}

func (s *UserSubscriber) Subscribe(dispatcher *event.Dispatcher) error {
	if err := dispatcher.Listen("user.created", &UserCreatedListener{}); err != nil {
		return err
	}
	return dispatcher.Listen("user.deleted", &UserDeletedListener{})
}

if err := dispatcher.Subscribe(&UserSubscriber{}); err != nil {
	return err
}
```

## 框架生命周期事件

框架会触发以下生命周期事件：

| 事件 | 触发时机 |
|---|---|
| `AppInit` | 全部 Provider 完成 `Register` 后、执行 `Boot` 前 |
| `RouteLoaded` | 全部 Provider 完成 `Boot` 后 |
| `HttpRun` | 每个 HTTP 请求开始 |
| `HttpEnd` | 每个 HTTP 请求结束 |

事件类型由 `framework/event` 包提供。业务代码可以监听这些事件实现扩展逻辑。

## 自定义事件类型

只要实现 `Name() string` 即可作为事件：

```go
type OrderPaid struct {
	ID int64
}

func (e OrderPaid) Name() string {
	return "order.paid"
}
```
