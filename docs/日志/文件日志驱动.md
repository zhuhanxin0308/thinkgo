# 文件日志驱动

```go
driver, err := logDriver.NewFileWithOptions("./runtime/log", logDriver.FileOptions{
	MaxFileSize:   10 * 1024 * 1024,
	RetentionDays: 30,
	MaxFiles:      100,
	MaxTotalSize:  1024 * 1024 * 1024,
})
if err != nil {
	return err
}
```

`FileOptions` 零值使用以下默认值：

| 选项 | 默认值 | 语义 |
|---|---:|---|
| `MaxFileSize` | 10 MiB | 单个日志文件上限 |
| `RetentionDays` | 30 | 按日期清理的保留天数 |
| `MaxFiles` | 100 | 受管日志文件数量上限 |
| `MaxTotalSize` | 1 GiB | 受管日志总容量上限 |

负数配置在构造阶段拒绝。推荐 `NewFileWithOptions`，它会立即创建目录并返回权限或路径错误；兼容构造器 `NewFile` 返回对象，初始化错误会在首次写入时暴露。

## 文件命名与轮转

基础文件按日期命名：

```text
2026-07-15.log
2026-07-15_1.log
2026-07-15_2.log
```

单条或批量写入都会检查写入后的大小；当前文件无法容纳整条日志时选择第一个可用的轮转文件。批量日志会按日期分组，并在同一批次内继续执行大小轮转，不会写出超过限制的半行。

清理只识别严格的 `YYYY-MM-DD.log` 和 `YYYY-MM-DD_N.log`（N 从 1 开始）。过期、超数量或超总容量时优先删除更旧且不是当前打开的文件；当前文件无法清理时返回错误，不删除当前打开文件来伪造容量达标。

目录和日志文件在类 Unix 系统分别使用 `0700`、`0600`；Windows 使用受保护 DACL，仅授权当前进程用户。驱动不会删除不属于上述命名规则的文件。
