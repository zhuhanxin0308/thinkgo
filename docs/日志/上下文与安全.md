# 上下文与安全

带上下文记录：

```go
logger := app.Log()
logger.ErrorCtx("创建用户失败", map[string]interface{}{
	"user_id": userID,
	"error":   frameworkLog.SanitizeErrorText(err.Error()),
})
```

可用方法为 `ErrorCtx`、`WarningCtx`、`InfoCtx` 和 `DebugCtx`。日志入队前会深度复制 map、slice、array、结构体和指针，因此调用返回后修改原对象不会改变已入队日志。

## 脱敏

框架按 map 键、HTTP Header 名和结构体 JSON 字段名递归识别敏感字段，覆盖 `password`、`passwd`、`token`、`secret`、`cookie`、`authorization`、`session`、`api_key`、`refresh_token` 等，敏感值输出为 `[REDACTED]`。

脱敏不会修改调用方对象。循环引用输出 `[CIRCULAR]`；不能安全表示的 map 键或值使用受限占位符，不调用任意 map key 的 `String()` 来取得内容。

消息正文不会按关键字自动替换秘密，业务代码仍不能把密码、Token、Cookie、Authorization 或个人隐私直接拼入消息。需要把第三方错误放入上下文时，先调用 `log.SanitizeErrorText`；驱动失败的兜底文本会使用单行格式并对常见凭据模式脱敏。

## 控制字符

日志消息、级别、调用位置和驱动错误中的 CR/LF/TAB 会被转义。控制台和文件驱动都基于 `FormatEntry` 输出，因此日志注入防护不依赖具体驱动。
