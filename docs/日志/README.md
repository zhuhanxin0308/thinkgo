# 日志

`framework.ServiceLog` 是应用日志入口，解析结果为 `*log.Log`。`framework/log` 提供级别过滤、上下文快照、多驱动、命名通道、调用位置、异步批量刷盘和关闭错误聚合；文件和控制台驱动位于 `framework/log/driver`。

本目录按能力拆分：

- [日志基础](日志基础.md)：级别、格式和同步/异步记录 API。
- [上下文与安全](上下文与安全.md)：深拷贝、敏感字段脱敏、循环引用和控制字符。
- [日志通道与配置](日志通道与配置.md)：默认通道、命名通道、驱动注册和应用配置。
- [文件日志驱动](文件日志驱动.md)：日期/大小轮转、保留策略和权限。
- [控制台日志驱动](控制台日志驱动.md)：颜色、写入器和输出边界。
- [刷盘、关闭与错误](刷盘、关闭与错误.md)：Flush、Close、兜底输出和错误聚合。

日志写入可能是异步的；需要在响应结束、任务提交或进程退出前确认日志已交给驱动时，调用 `Flush(ctx)` 或 `Close()` 并处理错误。
