# 刷盘、关闭与错误

## 异步记录

普通级别方法通过懒启动的异步队列记录。`NewLog` 默认缓冲区为 200 条、刷盘间隔为 5 秒；实际异步 channel 容量为缓冲区的两倍。批次达到缓冲区大小或定时器触发时调用驱动的 `SaveEntries`。

```go
logger := app.Log()
if err := logger.SetBufferSize(500); err != nil {
	return err
}
if err := logger.SetFlushInterval(2 * time.Second); err != nil {
	return err
}
```

缓冲区大小和刷盘间隔必须大于 0，并且只能在异步队列启动前设置。首次记录或调用 `Flush` 后再修改会返回 `ErrLogAlreadyStarted`。队列满时单条日志降级为同步写入，不会因为瞬时高峰直接丢弃。

需要立即同步写一条日志时可以使用 `Write(msg, level)`；它不会进入异步批次，但仍受级别过滤和关闭状态限制。

## Flush

```go
if err := logger.Flush(ctx); err != nil {
	return err
}
```

`Flush` 会等待调用前已经入队的日志交给全部驱动，再返回此前尚未消费的驱动错误。nil context 按 `context.Background()` 处理；context 取消只结束调用方等待，不会破坏后台刷盘协议，后续仍可以再次 Flush。关闭后的日志器返回 `ErrLogClosed`。

## Close

```go
if err := logger.Close(); err != nil {
	return err
}
```

`Close` 幂等执行以下步骤：

1. 标记日志器关闭，拒绝新的记录和通道注册。
2. 关闭异步输入并等待剩余批次刷盘。
3. 等待队列满时产生的在途同步写入。
4. 关闭当前日志器的所有驱动。
5. 递归关闭命名通道并聚合错误。

旧名称 `Shutdown()` 是返回错误的兼容别名。应用生命周期会调用 `app.Close()`，绕过 `App.Run()` 的调用方必须自己关闭并处理错误。

## 驱动错误

驱动的 `WriteEntry`、`SaveEntries` 或 `Close` 返回错误时，日志器会：

- 增加 `DriverErrorCount()`；
- 把已包装错误保留到下一次 `Flush`/`Close` 返回；
- 向兜底 writer 写入脱敏的单行错误；
- 把驱动 panic 转成错误，不让 panic 穿透业务 goroutine。

待返回的驱动错误最多保存 64 条，超出部分以省略数量汇总。兜底 writer 默认是 `os.Stderr`，可以通过 `SetFallbackWriter` 替换；兜底输出自身失败也会进入聚合错误。
