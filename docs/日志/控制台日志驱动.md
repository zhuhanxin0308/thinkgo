# 控制台日志驱动

```go
console, err := logDriver.NewConsoleWithWriter(os.Stdout)
if err != nil {
	return err
}
```

`NewConsole` 默认写入标准输出；`NewConsoleWithWriter` 用于注入 writer 或测试，拒绝 nil 和类型化 nil。驱动不会关闭调用方传入的 writer，`Close` 只释放自身状态并返回 nil。

控制台输出使用 `LogEntry.FormatEntry` 的统一格式、脱敏和控制字符转义。不同日志级别使用 ANSI 颜色：错误级别红色，warning/notice 黄色，info 绿色，debug 青色，sql 蓝色，未知级别只使用重置标记。

单条写入和批量写入都在同一个互斥区内执行，确保并发日志不会交错破坏单行边界。底层 writer 的错误和短写会原样返回。
