# 模板路径安全

模板名应是应用内部的逻辑名，例如 `user/index`。驱动会统一斜线并把配置的后缀补到模板名后，但会在清理前拒绝危险输入：

- 空模板名、绝对路径、盘符和包含冒号的路径；
- `..`、`.`、空段和重复斜线；
- 反斜线、空字节、回车、换行；
- 超过 2048 字节或超过 64 个路径段的名称。

驱动会把候选路径解析到根目录下，并在打开前后分别复核真实路径。根目录和目标文件的符号链接都不能把读取目标带出根目录；目标必须是普通文件，目录、替换后的其它文件和符号链接逃逸都会返回错误。

单个模板文件最大 4 MiB。读取使用有界 reader，超过上限返回 `ErrTemplateTooLarge`，不会无界加载到内存。`Exists` 同样执行路径和普通文件安全检查，不能用来绕过模板边界。

模板名如果来自 URL、查询参数、数据库或用户配置，应先映射到固定逻辑名白名单。路径安全校验不是业务授权机制，也不应允许用户通过模板内容选择任意文件。
