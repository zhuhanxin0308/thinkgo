## 请求级调试记录

视图管理器可以接收显式请求 collector：

```go
collector := debug.FromRequest(req)
viewManager, err := framework.ResolveServiceAs[*view.View](app, framework.ServiceView)
if err != nil {
	return err
}
if err := viewManager.RenderWithDebug(collector, writer, "user/index", data); err != nil {
	return err
}
```

`RenderWithDebug` 和 `FetchWithDebug` 只把本次成功渲染的模板写入传入 collector，不会修改后续请求的采集目标。旧的 `Render`、`Fetch` 入口仍保留构造时 Debug 兼容行为；新代码不要把 Debug 或请求对象保存到全局变量。模板路径仍按[模板路径安全](模板路径安全.md)校验。
