# 视图

ThinkGo 默认使用 Go 标准库 `html/template` 作为视图驱动。模板会自动转义 HTML 输出。

## 配置

`config/view.json`：

```json
{
    "view_path": "./app/view",
    "view_suffix": "html",
    "cache": true
}
```

`view_path` 是模板根目录，应用初始化时相对路径会转换为基于项目根目录的路径。配置仅接受 `view_path`、`view_suffix` 和 `cache`；未知字段、非法后缀或错误类型会使应用启动失败。

## 控制器渲染

```go
func (c *User) Page() string {
	c.Assign("title", "用户列表")
	return c.Fetch("user/index")
}
```

传入局部数据：

```go
return c.Fetch("user/detail", map[string]interface{}{
	"name": "张三",
})
```

局部数据优先于 `Assign` 的控制器数据。

## 应用级视图

```go
app.View.Assign("site_name", "ThinkGo")

var builder strings.Builder
err := app.View.Render(&builder, "user/index", map[string]interface{}{
	"title": "用户列表",
})
```

也可以直接返回字符串：

```go
html, err := app.View.Fetch("user/index", data)
```

## 模板路径安全

模板名会被限制在 `view_path` 内。驱动会统一路径分隔符，并直接拒绝包含 `..`、绝对路径、盘符或空字节的模板名。打开文件前后都会复核真实路径和文件句柄，只允许读取根目录内不超过 4 MiB 的普通文件。

不要把未经业务授权的用户输入直接作为模板名。

## 模板函数

框架默认注入 `lang` 函数：

```html
<h1>{{ lang "auth.login_success" }}</h1>
```

新增函数：

```go
if err := app.View.SetFuncMap(map[string]interface{}{
	"upper": strings.ToUpper,
}); err != nil {
	return err
}
```

函数值必须是非空函数。注册成功后旧模板缓存立即失效；同一模板的并发冷加载只解析一次，缓存最多保留 1024 个模板。

## 模板存在性

```go
exists, err := app.View.Exists("user/index")
if err != nil {
	return err
}
if exists {
	// 模板存在。
}
```

## 自定义驱动

```go
type Driver interface {
	Config(config map[string]interface{}) error
	Fetch(template string, data map[string]interface{}) (string, error)
	Display(writer io.Writer, template string, data map[string]interface{}) error
	Exists(template string) (bool, error)
	SetFuncMap(funcMap map[string]interface{}) error
}

if err := app.View.SetDriver(customDriver); err != nil {
	return err
}
```

## 错误处理

控制器的 `View` / `Fetch` 在渲染失败时会记录详细日志，并返回通用错误文本。直接使用 `SetDriver`、`SetFuncMap`、`Render`、`Fetch` 或 `Exists` 时，必须处理返回的 `error`。
