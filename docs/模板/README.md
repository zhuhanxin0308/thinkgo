# 模板

ThinkGo 的视图层由 `framework/view` 管理，默认驱动是 Go 标准库 `html/template`。控制器可以使用便捷方法渲染，应用或服务也可以直接使用视图管理器。

本目录按能力拆分：

- [视图管理器](视图管理器.md)：驱动安装、全局数据、局部数据、渲染和存在性检查。
- [控制器模板集成](控制器模板集成.md)：`Assign`、`View`/`Fetch` 和渲染错误边界。
- [Go 模板驱动](Go模板驱动.md)：配置、自动转义、函数映射和模板缓存。
- [模板路径安全](模板路径安全.md)：路径隔离、符号链接复核和文件大小限制。
- [自定义视图驱动](自定义视图驱动.md)：驱动接口和替换规则。

模板名来自业务代码时应使用固定白名单映射，不要把未经授权的请求参数直接传入 `Fetch`、`Render` 或 `Exists`。
