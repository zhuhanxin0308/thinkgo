# 自定义视图驱动

自定义驱动必须实现 `view.Driver`：

```go
type Driver interface {
	Config(config map[string]interface{}) error
	Fetch(template string, data map[string]interface{}) (string, error)
	Display(w io.Writer, template string, data map[string]interface{}) error
	Exists(template string) (bool, error)
	SetFuncMap(funcMap map[string]interface{}) error
}
```

安装驱动：

```go
viewManager, err := framework.ResolveServiceAs[*view.View](app, framework.ServiceView)
if err != nil {
	return err
}
if err := viewManager.SetDriver(customDriver); err != nil {
	return err
}
```

`SetDriver` 会复制视图配置后调用 `Config`，配置失败时旧驱动保持不变。`SetFuncMap` 只有在驱动已安装后才会转发；驱动缺失返回 `ErrViewDriverNotConfigured`。

驱动应自行保证并发安全、模板名边界、输出错误传播和资源生命周期。框架的 `View` 管理器不会替自定义驱动提供 HTML 自动转义、文件路径隔离或缓存语义；这些责任属于驱动实现。
