# 控制器模板集成

控制器通过 `Assign` 保存当前控制器实例的模板数据，通过 `View` 或 `Fetch` 渲染：

```go
func (c *User) Page() string {
	c.Assign("title", "用户列表")
	return c.Fetch("user/index", map[string]interface{}{
		"count": 10,
	})
}
```

`Fetch` 是 `View` 的别名。控制器初始化时会为每个控制器实例创建独立的数据 map；控制器数据不会跨请求共享。传入的局部 map 在渲染时覆盖 `Assign` 的同名值。

控制器便捷方法返回字符串而不是 `error`。模板驱动未配置、模板不存在、路径非法或执行失败时，方法会把详细错误写入 `c.App.Log()`，对调用方返回固定的“页面渲染出错，请稍后再试”文本，避免把模板路径和内部错误暴露给客户端。

需要区分错误、返回 JSON 或自行决定状态码时，通过 `c.App.View()` 直接调用 `Render`/`Fetch` 并处理 `error`，不要依赖控制器便捷方法的通用错误文本。

## `lang` 函数

应用初始化默认 Go 模板驱动后会注册：

```html
<h1>{{ lang "auth.login_success" }}</h1>
```

该函数调用 `c.App.Lang().Get(key, nil, "")`。需要严格使用当前请求语言时，应在控制器中调用 `c.Lang`，或把已经按请求语言解析的文本放入模板数据。
