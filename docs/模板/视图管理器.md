# 视图管理器

`view.NewView` 创建视图管理器；应用初始化时把 `config/view.json` 复制给它，再安装默认驱动：

```go
debugger := app.DebugManager()
viewManager := view.NewView(debugger, map[string]interface{}{
	"view_path": app.ApplicationViewPath(),
	"view_suffix": "html",
	"cache": true,
})
if err := viewManager.SetDriver(driver.NewGoTemplate()); err != nil {
	return err
}
```

`ApplicationViewPath` 始终指向当前编译应用的 `app/<应用名>/view`，不会让多个应用共享同一个模板目录。

`SetDriver` 会先调用驱动的 `Config`，只有配置成功才安装驱动。配置 map 会复制，驱动修改收到的 map 不会污染应用配置。

## 全局与局部数据

```go
viewManager := app.View()
viewManager.Assign("site_name", "ThinkGo")

html, err := viewManager.Fetch("user/index", map[string]interface{}{
	"title": "用户列表",
})
```

`Assign` 写入视图管理器的全局数据，`Get` 读取单个值。渲染时先复制全局 map，再覆盖局部数据；同名局部值优先。每次渲染都会创建合并 map，不会修改调用方传入的 map。

## 三种操作

```go
var builder strings.Builder
if err := viewManager.Render(&builder, "user/index", data); err != nil {
	return err
}

content, err := viewManager.Fetch("user/index", data)
if err != nil {
	return err
}

exists, err := viewManager.Exists("user/index")
```

`Render` 写入 `io.Writer`；空 writer 或类型化 nil writer 返回 `ErrInvalidViewWriter`。`Fetch` 返回完整字符串。`Exists` 只检查模板是否为根目录内可读取的普通文件，不执行模板。

视图没有可用驱动时，三种操作返回 `ErrViewDriverNotConfigured`。成功的 `Render`/`Fetch` 才会向 Debug 记录模板文件；失败渲染不会记录为已成功使用的文件。
