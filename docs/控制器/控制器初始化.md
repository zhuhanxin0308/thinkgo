# 控制器初始化

控制器实例创建后，框架会先注入当前 `App` 和 `Request`，再调用 `Initialize`，随后注册控制器中间件并执行动作。这个顺序对应 ThinkPHP `BaseController::__construct` 调用受保护 `initialize()` 的生命周期。

## Initialize

需要准备当前控制器状态时实现无参数、无返回值的 `Initialize`：

```go
func (controller *User) Initialize() {
	controller.SetMiddleware(framework.ControllerMiddleware{
		Name:   "auth",
		Except: []string{"Login"},
	})
}
```

`Initialize` 执行时可以直接使用：

```go
controller.App
controller.Request
```

业务控制器不接收也不调用底层注入方法。Go 没有 `protected` 方法，因此使用导出的 `Initialize` 对应 ThinkPHP 的受保护 `initialize()`；签名只能是：

```go
func (controller *User) Initialize()
```

带参数、可变参数或返回值的签名会在动作执行前被拒绝。

## 请求级状态

控制器实例按请求创建，`Initialize` 中保存的字段只属于当前请求。服务依赖可以作为实例字段保存，但请求参数、当前语言、权限结果等状态不能写入包级变量或共享单例字段。

请求结束后控制器实例不再复用。需要跨中间件传递请求级值时，使用 `Request.Set`/`Request.GetData`；需要跨请求共享的配置或服务，使用应用容器和线程安全组件。
