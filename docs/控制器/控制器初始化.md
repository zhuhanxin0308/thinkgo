# 控制器初始化

初始化发生在控制器实例创建之后、控制器级中间件和动作执行之前。基础控制器的 `Init` 会保存应用和请求，并创建控制器级视图数据 map。

## 重写 Init

需要准备控制器级状态时重写 `Init`，并先调用嵌入的基础实现：

```go
func (c *User) Init(app *framework.App, req *context.Request) {
	c.Controller.Init(app, req)
	c.SetMiddleware(framework.ControllerMiddleware{
		Name:   "auth",
		Except: []string{"Login"},
	})
}
```

基础初始化完成后可以使用：

```go
c.App
c.Request
```

如果不调用 `c.Controller.Init`，`App`、`Request` 和视图数据不会由基础控制器设置。

## 签名

HTTP 内核在反射调用前验证 `Init`：

- 除接收者外必须有两个参数，且参数类型必须能接收 `*framework.App` 和 `*context.Request`。
- 不允许可变参数。
- 可以无返回值，也可以只返回一个实现 `error` 的值。

常用签名是：

```go
func (c *User) Init(app *framework.App, req *context.Request) error {
	c.Controller.Init(app, req)
	return nil
}
```

签名不符合约束时不会等到 `reflect.Call` 才触发 panic，而是在动作前返回内部错误。`Init` 返回非 `nil` 错误时动作不会执行；生产环境响应为通用 500，详细错误只写入日志。

## 请求级状态

控制器实例按请求创建，`Init` 中保存的字段只属于当前请求。例如服务依赖可以作为实例字段保存，但请求参数、当前语言、权限结果等状态不能写入包级变量或共享单例字段。

请求结束后控制器实例不再复用。需要跨中间件传递请求级值时，使用 `Request.Set`/`Request.GetData`；需要跨请求共享的配置或服务，使用应用容器和线程安全的组件。
