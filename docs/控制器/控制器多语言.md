# 控制器多语言

控制器通过 `Lang` 和 `GetLang` 读取请求级语言。请求级语言由多语言中间件写入 `Request` 数据，不修改 `framework.ServiceLang` 对应语言服务的全局当前语言。

## 翻译消息

```go
func (c *User) Index() *context.Response {
	return c.Success(nil, c.Lang("auth.login_success"))
}
```

带变量时传入一个 map：

```go
message := c.Lang("validate.default.required", map[string]interface{}{
	"field": "邮箱",
})
```

`Lang` 从 `Request.GetData(framework.LangRequestKey)` 读取语言，并把它传给通过 `ServiceLang` 解析的语言管理器。没有请求语言时传空字符串，由语言管理器使用当前语言；语言包缺失时继续按默认语言和原 key 回退。翻译键、变量和回退规则见[翻译读取](../多语言/翻译读取.md)。

## 读取语言标识

```go
locale := c.GetLang()
```

`GetLang` 只返回请求上下文中的语言标识；请求没有经过语言中间件或上下文没有该值时返回空字符串。它适合传给服务层，让服务层在不依赖控制器的情况下调用解析得到的语言管理器 `Get(key, vars, locale)`。

## 并发边界

多个请求可以同时调用 `c.Lang`。因为语言值保存在各自的 `Request` 中，控制器代码不应通过共享语言服务的 `SetLang` 代替请求语言切换；`SetLang` 修改的是应用级状态，详见[语言生命周期](../多语言/语言生命周期.md)。
