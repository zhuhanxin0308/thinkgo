# 控制器中间件

控制器可以在初始化阶段声明已经注册的中间件别名。HTTP 内核会在 `Initialize` 完成后、动作执行前，把匹配当前动作的中间件插入请求链。本章保留控制器侧的使用说明；中间件管道、路由层级和完整安全边界见[中间件章节中的控制器中间件](../中间件/控制器中间件.md)。

## 声明

```go
func (controller *User) Initialize() {
	controller.SetMiddleware(
		framework.ControllerMiddleware{
			Name:   "auth",
			Except: []string{"Login"},
		},
		framework.ControllerMiddleware{
			Name: "csrf",
			Only: []string{"Create", "Update"},
		},
	)
}
```

`Name` 是通过 `framework.ServiceMiddleware` 对应管道的 `Alias` 注册的别名。声明顺序就是控制器级中间件进入管道的顺序。

## 动作过滤

每一项声明只能使用一种过滤方式：

| 配置 | 行为 |
|---|---|
| `Only` 非空 | 只对列表中的动作生效 |
| `Except` 非空 | 对除列表外的动作生效 |
| 两者都为空 | 对全部动作生效 |

动作名匹配不区分大小写，列表中的首尾空白会被去除。`Only` 和 `Except` 不能同时配置；空动作名、非法标识符和忽略大小写后的重复动作都会被拒绝。

## 过滤项约束

动作过滤列表只允许 Go 标识符风格的名称：首字符为 ASCII 字母或 `_`，后续字符为 ASCII 字母、数字或 `_`。

控制器中间件解析时会校验所有声明，包括当前动作不会命中的声明。名称为空、别名未注册或配置冲突时，请求直接返回内部错误，不会跳过保护中间件继续执行动作。

## API

```go
middlewares := c.GetMiddleware()
c.SetMiddleware(middlewares...)
```

`SetMiddleware` 直接替换当前实例的声明切片；`GetMiddleware` 返回当前声明。它们不是全局注册 API，控制器实例仍按请求创建。不要在多个请求之间复用或并发修改同一声明切片。
