# 控制器概览

ThinkGo 控制器与 ThinkPHP 多应用一样放在 `app/<应用名>/controller`。创建控制器时不需要维护注册表、入口文件或框架内部目录：

```bash
go run ./cmd/think make:controller User
```

生成命令会同时刷新 Go 静态编译需要的应用装配文件，路由直接使用 `user/index` 调用。

## 普通控制器

控制器不强制继承基础控制器：

```go
package controller

type User struct{}

func (*User) Index() string {
	return "User List"
}
```

动作可以直接声明路由参数，也可以声明当前 `*framework.App`、`*framework.Request` 或容器中可解析的服务。每次请求都会创建新的控制器实例。

## 基础控制器

需要请求、视图、验证、响应辅助或控制器中间件时，可以嵌入应用提供的 `BaseController`：

```go
package controller

type User struct {
	BaseController
}

func (controller *User) Initialize() {
	// 当前请求的控制器初始化逻辑
}

func (controller *User) Index() *framework.Response {
	return controller.Success([]string{})
}
```

`Initialize` 对应 ThinkPHP `BaseController::initialize`，在框架注入当前 App 和 Request 后、控制器动作前执行。控制器只负责读取请求、选择验证场景、调用服务和生成响应；业务规则与持久化应放在当前 `app/<name>/service` 和 `app/<name>/model`。

## 请求顺序

```text
路由匹配
  -> 创建请求级控制器实例
  -> 注入 App 与 Request
  -> Initialize
  -> 控制器中间件
  -> 动作参数绑定
  -> 控制器动作
  -> 返回值转换为 Response
```

控制器不应把请求数据写入包级变量或应用单例字段。
