# 控制器概览

ThinkGo 控制器通常放在 `app/<应用名>/controller`，在所属应用的 `application.go` 中通过 `app.RegisterController` 注册，再由该应用的路由使用 `Controller@Action` 调度。控制器只负责读取请求、选择验证场景、调用服务和返回响应；业务规则和持久化应放在服务、模型或仓储层。

一次控制器请求的关键顺序是：

```text
路由匹配 -> 容器创建控制器实例 -> 校验 Init/动作签名 -> Init
-> 解析控制器中间件 -> 控制器动作 -> 返回值转换为 Response
```

最小控制器由嵌入基础控制器、注册名和动作组成：

```go
package controller

import "thinkgo/framework"

type User struct {
	framework.Controller
}

func (c *User) Index() string {
	return "User List"
}
```

应用入口中注册：

```go
if err := app.RegisterController("User", &controller.User{}); err != nil {
	return err
}
```

控制器实例按请求创建，`App`、`Request`、视图数据和中间件声明都属于该实例。控制器不应把请求数据写入包级变量或应用单例字段。
