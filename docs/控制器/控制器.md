# 控制器

控制器放在 `app/controller`，包名为 `controller`。每个控制器必须注册到框架，路由才能通过 `"Controller@Action"` 调度。

## 定义控制器

```go
package controller

import "thinkgo/framework"

type User struct {
	framework.Controller
}

func init() {
	// 注册名必须和路由中的 User@Index 保持一致。
	framework.MustRegisterController("User", &User{})
}

func (c *User) Index() string {
	return "User List"
}
```

`MustRegisterController` 会拒绝空名称、非结构体原型和重复名称；注册表不暴露可变 map。控制器每个请求都会创建新实例。不要把请求级状态写入包级变量或应用单例字段。

## 初始化

需要在动作前准备状态时重写 `Init`，并先调用基础控制器初始化：

```go
func (c *User) Init(app *framework.App, req *context.Request) {
	c.Controller.Init(app, req)
}
```

`Init` 必须接收能容纳 `*framework.App`、`*context.Request` 的两个参数，可无返回值或返回一个 `error`。签名不符会在动作调用前转换为 500，不会等到反射 `Call` 时 panic。

初始化后可通过：

```go
c.App
c.Request
```

访问应用实例和当前请求。

## 返回值

动作方法可以返回：

| 返回值 | 响应 |
|---|---|
| `*context.Response` | 原样发送 |
| `string` | 文本响应 |
| 其它结构 | JSON 响应 |
| 无返回值 | 空 200 响应 |
| `error` | nil 为空 200，非 nil 为 500 |
| `(value, error)` | error 为空时转换 value，非空时返回 500 |

```go
func (c *User) Detail(req *context.Request) *context.Response {
	id := req.ParamInt("id", 0)
	return c.Success(map[string]interface{}{"id": id})
}
```

动作可以不接收参数，也可以接收 `*context.Request`；最多返回两个值，双返回值的第二项必须实现 `error`。生产环境只向客户端返回通用 500，详细错误写入日志。

## 响应辅助

```go
c.Success(data, "操作成功")
c.Error("参数错误", 400)
c.Result(data, 0, "success")
c.Redirect("/login")
```

`Success` 和 `Error` 返回统一 JSON：

```json
{
    "code": 0,
    "msg": "success",
    "data": {}
}
```

## 视图

```go
func (c *User) Page() string {
	c.Assign("title", "用户列表")
	return c.Fetch("user/index")
}
```

`Assign` 设置控制器级模板变量，`Fetch` 和 `View` 会合并已赋值数据与传入数据。模板渲染失败时会记录详细日志，对用户返回通用错误信息。

## 验证

```go
result, err := c.Validate(req.All(), map[string]string{
	"name": "required|max:20",
})
if err != nil {
	return c.Error("验证配置错误", 500)
}
if !result.Valid() {
	return c.Error(result.FirstError(), 422)
}
```

复杂验证推荐创建 `app/validate` 下的验证器。

## 多语言

```go
message := c.Lang("auth.login_success")
lang := c.GetLang()
```

语言标识从当前请求上下文读取，不修改全局语言状态，适合并发请求。

## 控制器中间件

控制器级中间件通过别名声明：

```go
func (c *User) Init(app *framework.App, req *context.Request) {
	c.Controller.Init(app, req)
	c.SetMiddleware(framework.ControllerMiddleware{
		Name:   "auth",
		Except: []string{"Login"},
	})
}
```

`Only` 非空时只对指定动作生效；`Except` 非空时排除指定动作；二者都为空时对全部动作生效。
`Only` 与 `Except` 不能同时配置；别名缺失或动作名非法时请求失败关闭，不会跳过中间件后继续执行动作。
