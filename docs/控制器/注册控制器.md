# 注册控制器

控制器注册表只保存控制器的 `reflect.Type`，不保存控制器实例。路由中的控制器名称必须与注册名称完全一致。

## 注册 API

应用代码通常在 `app/<应用名>/application.go` 中注册：

```go
	if err := app.RegisterController("User", &controller.User{}); err != nil {
	return err
}
```

`App.RegisterController` 接受结构体或结构体指针原型，内部只保留结构体类型。注册错误必须返回给应用管理器；包初始化阶段只登记 `ApplicationDefinition`，不把控制器写入共享注册表。

## 名称与原型约束

注册名必须满足：

- 非空，且首尾不能有空白。
- 长度不超过 256 字节。
- 不包含控制字符。
- 同一应用注册表中不能重复注册。

原型不能为 `nil`，也不能是数字、函数或其它非结构体类型。非法输入返回 `ErrInvalidRegistration`；重复名称返回 `ErrDuplicateRegistration`。注册不会静默覆盖已有绑定。

```go
// 下面的名称和原型都会被拒绝。
framework.RegisterController("", &User{})
framework.RegisterController("User", nil)
framework.RegisterController("User", 1)
```

## 应用初始化绑定

应用初始化时读取注册表快照，并把每个控制器通过 `BindFactory` 放入容器。HTTP 内核每次解析路由控制器时都会创建新的指针实例，因此下面两次解析不会得到同一个对象：

```go
first, _ := app.Make("User")
second, _ := app.Make("User")
```

显式把控制器绑定成单例会改变这一生命周期，应避免这样做。需要控制器请求级状态时，应使用[控制器初始化](控制器初始化.md)和当前请求对象。

## 注册名与路由

注册名是路由处理器字符串 `Controller@Action` 的左半部分：

```go
_, err := router.Get("/api/users", "User@Index")
```

控制器未注册、容器无法解析或路由字符串格式不是恰好一个 `@` 分隔的两段时，请求会进入统一的内部错误处理。
