# 配置

ThinkGo 使用 `config/*.json` 作为配置文件。文件名就是一级命名空间，例如 `config/app.json` 对应 `app`，`config/database.json` 对应 `database`。

## 读取配置

配置支持点路径读取：

```go
debug := app.Config.GetBool("app.app_debug", false)
port := app.Config.GetInt("app.server.port", 8080)
name := app.Config.GetString("app.app_name", "ThinkGo")
server := app.Config.GetMap("app.server")
```

优先使用 `GetBool`、`GetInt`、`GetString`、`GetMap` 这类类型安全方法。裸 `Get` 只在确知类型时使用，避免配置缺失或类型不符时 panic。

`Get` 和 `GetMap` 对 map、slice 返回递归隔离的快照，调用方修改返回值不会污染共享配置。需要修改共享配置时仍必须使用 `Set`：

```go
// 使用点路径写入嵌套配置。
app.Config.Set("app.server.port", 9000)
```

`Set` 会复制传入的 map 和常见切片，后续修改原变量不会污染配置。

`GetMapCopy` 是兼容名称，与 `GetMap` 具有相同的快照语义。

## 配置加载顺序

应用初始化时按以下顺序处理配置：

1. 加载 `.env` 到框架内部环境存储。
2. 加载 `config/*.json`。
3. 用框架显式支持的环境变量覆盖配置。
4. 初始化日志、语言、缓存、视图、Cookie、Session、数据库、中间件和路由。

环境变量优先级为：

```text
真实系统环境变量 > .env 文件 > config/*.json > 框架默认值
```

`.env` 不会被写入进程环境，避免 `DB_PASS` 等敏感值被子进程继承。
通过 `Env.Get` 读取时，真实系统环境变量只要存在就优先，即使值为空字符串。
缺失的 `.env` 被视为未提供可选配置；其他读取错误或不符合 `KEY=VALUE` 的行会返回带文件和行号的错误，且不会加载部分数据。

布尔环境变量使用显式错误返回：

```go
enabled, err := app.Env.GetBool("SERVER_TLS_ENABLE", false)
```

解析规则与 `strconv.ParseBool` 一致。变量存在但值非法时返回错误，不会回退默认值。

## 应用配置

常用 `config/app.json` 配置：

| 配置项 | 说明 |
|---|---|
| `app_debug` | 是否开启调试模式 |
| `app_trace` | 是否启用 Trace 调试条 |
| `session_enable` | 是否启用 Session 中间件 |
| `csrf_enable` | 是否全局启用 CSRF 中间件 |
| `server.host` | HTTP 监听地址 |
| `server.port` | HTTP 监听端口 |
| `server.tls.enable` | 是否启用 TLS |
| `server.http3` | 是否启用 HTTP/3 |
| `server.allowed_hosts` | Host 白名单 |
| `server.trusted_proxies` | 可信代理网段 |
| `server.read_header_timeout_ms` | 请求头读取超时，必须为正整数 |
| `server.read_timeout_ms` | 请求读取超时，不得短于请求头超时 |
| `server.write_timeout_ms` | 响应写入超时 |
| `server.idle_timeout_ms` | Keep-Alive 空闲超时，同时应用于 HTTP/1.x、HTTP/2 和 HTTP/3 |
| `server.shutdown_timeout_ms` | 优雅关闭超时 |
| `server.max_header_bytes` | 请求头字节上限，同时应用于 TCP HTTP 和 HTTP/3 |
| `server.max_body_bytes` | 请求体硬上限，范围 1 字节到 1GiB |
| `server.multipart_max_memory_mb` | multipart 内存阈值，范围 1MB 到 1024MB |
| `compression.enable` | 是否启用响应压缩 |
| `compression.min_size` | 启用压缩的最小响应字节数，最大 8MiB |
| `compression.levels` | `gzip`、`deflate`、`br`、`zstd` 的独立等级 |

当前默认端口是 `8081`，TLS、HTTP/3、压缩默认开启。

`http.NewHttp(app)` 返回 `(*http.Http, error)`，会一次性严格校验上述配置。整数不得用小数截断，未知键、非法 Host/代理网段、越界压缩等级都会阻止启动；HTTP/3 必须与 TLS 同时启用。`allowed_hosts` 为空表示接受任意语法合法的 Host，生产环境应显式配置白名单。Host 端口必须是 `1-65535` 的十进制数字，IPv6 Host 必须使用方括号；压缩算法名称不区分大小写，同一算法不得重复配置。

## Cookie、Session 与 CSRF 配置

三个配置文件都采用未知字段即失败的严格解析：

| 文件 | 支持字段 |
|---|---|
| `cookie.json` | `prefix`、`secret`、`path`、`domain`、`secure`、`httponly`、`samesite`、`expire`、`sign_max_age` |
| `session.json` | `name`、`type`、`storage_path`、`cookie_path`、`expire`、`domain`、`secure`、`httponly`、`samesite`、`max_data_bytes` |
| `csrf.json` | `cookie_name`、`header_name`、`field_name`、`cookie_path`、`cookie_domain`、`secure`、`samesite`、`max_age`、`secret`、`safe_methods` |

Session 的 `type` 只支持 `file`、`memory`。`storage_path` 是文件存储目录，相对路径必须位于应用根目录；`cookie_path` 是浏览器 Cookie Path，旧 `path` 字段不再支持。Session Cookie 强制启用 HttpOnly，单个持久化信封受 `max_data_bytes` 限制。

Cookie/CSRF 的非空密钥至少 32 字节。CSRF `safe_methods` 只允许 `GET`、`HEAD`、`OPTIONS`，`SameSite=None` 自动强制 Secure。

## 数据库配置

`config/database.json` 只接受 `default` 和 `connections`。两者都必须存在，`connections` 必须是非空对象，`default` 必须是合法连接名称并引用其中一个连接；框架不会自动创建或提升默认连接。连接配置中的未知字段、类型错误、负数、溢出和非法坐标都会形成启动错误，`params` 的键和值必须显式使用字符串。

`DB_*` 只覆盖默认连接。数值覆盖必须是非负整数，非法值会阻止启动且不会留下部分覆盖结果。完整字段和连接器安全默认值见[连接数据库](../数据库/连接数据库.md)。

## 缓存配置

`config/cache.json` 只接受 `default` 和 `stores`。`default` 必须是合法且已定义的 store 名称，`stores` 支持 `file`、`memory`、`redis`；任何未知字段、错误类型、非法范围或不支持的驱动都会形成启动错误，不会隐式回退。

文件 store 只接受 `type`、`path`；相对路径必须位于应用根目录内。Memory store 只接受 `type`。Redis store 可使用 `host`、`port`、`password`、`select`、`timeout_ms`、`prefix`、`allow_flush_db`。旧 `expire` 字段不再受支持，TTL 由缓存写入 API 指定。

Redis 空前缀默认禁止清空。只有所选 DB 完全独占时才可设置 `allow_flush_db=true`；否则必须使用非空 `prefix`。

## 环境变量

框架显式支持的常用环境变量：

```text
APP_DEBUG=true
APP_TRACE=true
SERVER_HOST=0.0.0.0
SERVER_PORT=8081
SERVER_HTTP3=false
SERVER_TLS_ENABLE=false
SERVER_TLS_CERT=./runtime/cert.pem
SERVER_TLS_KEY=./runtime/key.pem
SERVER_ALLOWED_HOSTS=example.com,api.example.com
SERVER_TRUSTED_PROXIES=127.0.0.1,10.0.0.0/8
DB_TYPE=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASS=secret
DB_NAME=thinkgo
```

`DB_*` 只覆盖默认数据库连接。非默认连接必须写在 `config/database.json`。

## 配置转储

命令行可以查看当前配置：

```bash
go run cmd/think/main.go config:dump
go run cmd/think/main.go config:dump app.server
```

`config:dump` 会先按 JSON 语义归一化配置，再递归脱敏密码、token、secret、cookie、authorization、credential、passphrase、私钥、访问密钥、连接字符串、DSN 和 URI/URL 等敏感字段。直接查询敏感点路径（例如 `database.password`）以及强类型映射、结构体中的敏感字段同样只输出 `[REDACTED]`；无法安全序列化时命令失败且不输出部分数据。
