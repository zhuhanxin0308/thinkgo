# 配置

ThinkGo 使用根 `config/*.json` 作为项目配置，并允许 `app/<name>/config/*.json` 为单个编译应用覆盖同名命名空间。文件名就是一级命名空间，例如 `config/app.json` 对应 `app`。Go 宿主监听和应用解析规则始终取项目配置快照，业务应用不能改写进程监听边界。

## 读取配置

```go
cfg := app.Config()

withRoute := cfg.GetBool("app.with_route", true)
timezone := cfg.GetString("app.default_timezone", "Asia/Shanghai")
suffix := cfg.GetString("route.url_html_suffix", "html")
```

优先使用 `GetBool`、`GetInt`、`GetString` 和 `GetMap`。`GetMap` 与 `GetMapCopy` 返回递归隔离快照；共享配置只能通过 `Set` 修改：

```go
if err := cfg.Set("app.server.port", 9000); err != nil {
	return err
}
```

`Set` 会复制输入的 map 和常见切片，并拒绝非法点路径或大小写冲突，不会提交半次修改。

## 加载顺序

应用初始化顺序为：

1. 加载公共环境文件和当前环境文件；
2. 加载根 `config/*.json`，按完整点路径应用环境覆盖；
3. 装配根 `app` 的项目级定义并触发项目 `AppInit`；
4. 捕获不可被业务应用污染的项目配置快照；
5. 加载目标 `app/<name>/config/*.json`，随后再次原子应用环境覆盖；
6. 装配目标应用的服务、事件、中间件、Provider、控制器、模型、验证器和路由；
7. 初始化并启动当前应用自己的 Provider 与服务。

配置来源优先级为：

```text
真实系统环境变量 > .env > app/<name>/config/*.json > config/*.json > 框架默认值
```

兼容期遗留的 `app/config` 不会被读取，只有命名业务应用的 `app/<name>/config` 是有效覆盖层。应用覆盖层新增的配置叶子也会参与第二次环境映射；类型不一致时应用初始化失败，不会降级为文件值。`.env` 进入框架自己的环境存储，不写回进程环境；真实系统变量只要存在就优先，即使值为空。数组和对象的环境值使用 JSON 文本。

## 默认配置文件

| 文件 | 主要职责 |
|---|---|
| `app.json` | 命名空间、路由开关、默认时区和错误显示默认值 |
| `cache.json` | 默认 store 与文件缓存配置 |
| `console.json` | 自定义命令声明 |
| `cookie.json` | Cookie 过期、路径、域、安全属性和 SameSite |
| `database.json` | 默认连接、时间字段行为与数据库连接 |
| `filesystem.json` | 默认磁盘与本地/公共磁盘配置 |
| `lang.json` | 默认语言、浏览器检测、语言变量和允许列表 |
| `log.json` | 默认日志通道、等级、分流和关闭策略 |
| `route.json` | 路由匹配、HTML 后缀、控制器与动作默认值 |
| `session.json` | Session 名称、ID 变量、驱动、store、过期和前缀 |
| `trace.json` | Trace 输出类型与日志通道 |
| `view.json` | 模板类型、目录名、后缀与标签分隔符 |

默认时区是 `Asia/Shanghai`，默认加载根路由，路由并非强制模式，默认 HTML 后缀为 `html`。数据库、缓存、文件系统、Session、Trace 和视图配置保持 ThinkPHP 的字段名称；驱动类型在 Go 中不区分常见大小写写法。

## Go HTTP 宿主扩展

Go 进程需要自行监听端口，因此 `app.server` 可以声明监听地址、端口、TLS、HTTP/3、可信代理、Host 白名单、请求体上限和超时；`app.compression` 可以声明响应压缩。这些字段由 `http.NewHttp` 严格校验，非法端口、Host、代理网段、超时或压缩等级会阻止监听。

```bash
go run ./cmd/think config:dump
go run ./cmd/think config:dump app
go run ./cmd/think config:dump --app admin app
```

`config:dump` 会递归隐藏密码、令牌、密钥、授权信息、连接串和 URL 等敏感值；无法安全序列化时直接失败，不输出部分结果。
