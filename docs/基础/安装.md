# 安装

ThinkGo 使用 Go Modules 管理依赖。开始前先确认本机 Go 版本满足 `go.mod` 中的 `go` 指令；当前项目要求 `go 1.25.7`。

## 获取依赖

```bash
go mod download
go mod verify
```

如果依赖发生变化，使用：

```bash
go mod tidy
```

## 运行服务

HTTP 服务入口是项目根目录的 `main.go`：

```bash
go run main.go
```

命令行入口在 `cmd/think/main.go`：

```bash
go run cmd/think/main.go list
go run cmd/think/main.go run
go run cmd/think/main.go run -p 9000
```

`run -p` 会覆盖 `config/app.json` 和 `.env` 中的端口配置。除 `run` 外，`version`、`list`、`make:*` 等命令默认跳过数据库连接。

## TLS 与 HTTP/3

当前 `config/app.json` 默认启用 TLS 与 HTTP/3，证书路径为：

```text
runtime/cert.pem
runtime/key.pem
```

本地没有证书时，可运行开发证书工具：

```bash
go run cmd/cert/main.go
```

生产环境应使用正式证书，并保护私钥文件权限。

## 数据库准备

默认数据库配置在 `config/database.json`，默认连接名为 `mysql`。启动完整 Web 应用前需要保证默认连接可用；开发时也可以通过环境变量覆盖默认连接：

```text
DB_TYPE=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASS=secret
DB_NAME=thinkgo
```

## 验证安装

```bash
go build ./...
go test ./...
```

SQLite 相关能力依赖 CGO；如果当前机器没有 C 工具链，相关测试或构建可能需要先安装 gcc。
