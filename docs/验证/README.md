# 验证器

本目录按框架 `validate` 包的公共 API、规则解析器和规则实现拆分章节。验证器把配置错误和用户数据违规分成两条返回路径，适合在服务层或控制器中明确处理。

应用层验证器放在 `app/<应用名>/validate` 目录。规则配置不保存请求状态；需要按业务域拆分时使用目标应用 `validate` 目录内部的 Go 包边界。

简单无场景验证可使用 `validate.ValidateRules` 或控制器的 `Controller.Validate`；带自定义消息、场景和多语言时应创建应用内专用 `validate.Validator`，避免把请求状态放入共享配置。
