# 验证器概览

框架的 `validate` 包提供基于规则字符串的无状态验证器。规则、消息和场景通过 setter 配置；每次 `Validate` 都返回独立的 `Result`，不会把请求数据或上一次错误写入验证器实例。

## 最小用法

```go
validator := validate.NewValidator().SetRules(map[string]string{
	"email|邮箱": "required|email",
	"age|年龄":   "integer|min:18",
})

result, err := validator.Validate(data)
if err != nil {
	return err
}
if !result.Valid() {
	return errors.New(result.FirstError())
}
```

字段定义可以使用 `实际字段|显示别名`。规则通过 `|` 连接，带参数的规则写成 `rule:param`。正则、引号、场景和错误返回的完整语法分别见子章节。

## 执行模型

验证调用按以下顺序处理：

1. 应用本次调用的 `Option`。
2. 按规则和场景配置生成或读取验证计划。
3. 按稳定字段顺序执行规则。
4. 把数据违规写入 `Result`；配置错误直接返回 `error`。

默认第一条数据违规就停止；传入 `CollectAllErrors()` 才收集当前计划的全部违规。缺失字段会跳过普通可选规则，但 `required`、`requireIf` 和 `requireWith` 会按规则语义检查字段存在性。
