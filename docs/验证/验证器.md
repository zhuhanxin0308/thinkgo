# 验证器

验证器位于 `framework/validate`。配置通过 setter 复制保存，`Validate` 不写入共享调用状态，同一实例可并发验证。

## 快速验证

```go
validator := validate.NewValidator().SetRules(map[string]string{
	"email|邮箱": "required|email",
	"age|年龄":   "integer|min:1",
})

result, err := validator.Validate(req.All())
if err != nil {
	// 规则或场景配置错误属于服务端错误，不应作为用户输入错误返回。
	return c.Error("服务配置错误", 500)
}
if !result.Valid() {
	return c.Error(result.FirstError(), 422)
}
```

`Result` 提供：

- `Valid() bool`
- `FirstError() string`
- `Errors() []string`
- `Violations() []validate.Violation`

切片访问器返回副本。`Violation` 包含实际字段名、别名、规则、参数和消息。

## 定义验证器

```go
package validate

import "thinkgo/framework/validate"

type UserValidate struct {
	validate.Validator
}

func NewUserValidate() *UserValidate {
	v := &UserValidate{}
	v.SetRules(map[string]string{
		"email|邮箱": "required|email",
		"name|姓名":  "required|length:2,20",
	})
	v.SetMessages(map[string]string{
		"email.required": "validate.email_required",
		"email.email":    "validate.email_format",
	})
	v.SetScenes(map[string][]string{
		"create": {"email", "name"},
		"update": {"name"},
	})
	return v
}
```

使用场景和多语言：

```go
validator := NewUserValidate()
validator.SetLang(c.App.Lang)
result, err := validator.Validate(req.All(), validate.WithScene("create"))
```

每次编译规则时会校验所有已注册场景。场景名须去除首尾空白且不超过 256 字节；不存在、为空、字段重复或引用无规则字段的场景会返回配置错误，不会回退为全量验证。

## 批量验证

默认遇到第一条数据错误即返回。收集全部规则错误：

```go
result, err := validator.Validate(data, validate.CollectAllErrors())
if err == nil && !result.Valid() {
	errors := result.Errors()
}
```

场景和批量选项只影响当前调用，不修改验证器实例。

## 字段别名与消息

规则字段使用 `实际字段|用户可见别名`：

```go
validator.SetRules(map[string]string{
	"password|密码": "required|length:8,32",
})
```

错误消息查找顺序：

1. `field.rule`
2. `field`
3. `rule`
4. 多语言默认键 `validate.default.rule`
5. 框架内置默认消息

直接消息和多语言消息都支持 `{:field}`、`{:rule}`、`{:param}`。`{:field}` 使用别名，`Violation.Field` 保留实际字段名。

## 常用规则

| 规则 | 说明 |
|---|---|
| `required` | 必填；空字符串及空 array/slice/map 无效，`0` 和 `false` 有效 |
| `number` / `float` | 有限十进制数；拒绝 NaN、Inf、十六进制和分数写法 |
| `integer` | 整数类型、整数值浮点数或十进制整数字符串 |
| `boolean` | 布尔类型或 `strconv.ParseBool` 可解析字符串 |
| `email` | 完整邮箱地址 |
| `array` | 任意类型的 array、slice 或 map |
| `accepted` | true、yes、on 或数值/字符串 1 |
| `date` | 合法日期、日期时间或 RFC3339 时间 |
| `alpha` / `alphaNum` / `alphaDash` | 字母、字母数字、字母数字下划线横线 |
| `chs` / `chsAlpha` / `chsAlphaNum` / `chsDash` | 中文及对应组合 |
| `ip` | 合法 IPv4 地址 |
| `url` | 带 host 的 http、https、ftp、rtsp 或 mms URL |
| `mobile` | 中国大陆手机号格式 |
| `idCard` | 18 位身份证格式、出生日期、顺序码和校验码 |

字符串长度按 Unicode 字符计数；array、slice 和 map 按元素数量计数。数值比较使用任意精度十进制数，避免大整数转 `float64` 后丢失精度。

## 参数规则

```text
in:1,2,3
notIn:1,2,3
between:1,10
notBetween:1,10
length:6
length:6,20
max:20
min:2
eq:active
gt:10
lt:100
egt:10
elt:100
regex:"^(foo|bar):\d+$"
confirm:password_confirm
different:old_password
dateFormat:2006-01-02
after:start_at
before:end_at
requireIf:type,email
requireWith:email,phone
```

含规则分隔符 `|` 的正则参数必须使用单引号、双引号或斜杠包裹，例如 `regex:"^(foo|bar)$"` 或 `regex:/^(foo|bar)$/`。正则编译缓存最多保留 256 项，单个模式最多 4096 字节。

## 配置错误

未知规则、无效参数、重复字段、错误场景和无效调用选项通过 `error` 返回，可用 `errors.Is` 判断：

```go
validate.ErrUnknownRule
validate.ErrInvalidRule
validate.ErrUnknownScene
validate.ErrInvalidScene
validate.ErrInvalidOption
```

配置错误与 `Result` 中的用户数据违规严格分离。
