# 集合与长度规则

集合和长度规则对字符串、array、slice 和 map 使用统一的尺寸语义，并按值类型决定是比较数值还是比较长度。

## length

```text
length:6
length:2,20
```

- 一个参数表示必须精确等于该长度。
- 两个参数表示闭区间 `[min,max]`。
- 字符串按 Unicode code point 数量计算，不按字节计算。
- array、slice 和 map 按元素数量计算。
- 布尔值、数值和其它不可测量标量不通过。

```go
"name": "length:2,20",
"tags": "array|length:1,5",
```

长度边界必须是非负整数，且上界不能小于下界。

## max 与 min

```text
max:100
min:2
```

如果值是可解析数值：

- `max` 要求值小于或等于参数。
- `min` 要求值大于或等于参数。

如果值是字符串或集合，则比较尺寸：字符串按 Unicode 字符计数，array/slice/map 按元素数计数。尺寸比较的参数必须是整数；例如字符串 `"中文"` 通过 `max:2`。

这两个规则都要求提供可解析的十进制数参数，参数非法时属于配置错误而不是数据违规。

## required 与集合

`array` 只判断值是否为集合类型；空集合仍然满足 `array`。需要同时要求非空时组合：

```go
"items": "required|array|length:1,20",
```

`required` 会把空集合视为为空值，`length` 则继续对具体尺寸做精确或范围校验。
