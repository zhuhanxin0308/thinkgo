# 基础类型规则

基础类型规则不接受参数。规则对字段值执行类型或存在性判断；非必填字段缺失时，普通规则会被跳过，只有字段存在时才校验其值。

| 规则 | 通过条件 |
|---|---|
| `required` | 字段存在且不是 `nil`、空白字符串、空 array/slice/map；`0` 和 `false` 有效 |
| `number` | 可以解析为有限十进制数的整数、浮点数、字符串或 `json.Number` |
| `float` | 与 `number` 使用相同的有限十进制数判断 |
| `integer` | 整数类型、没有小数部分的有限浮点数，或十进制整数字符串 |
| `boolean` | `bool`，或 `strconv.ParseBool` 能解析的字符串 |
| `array` | Go array、slice 或 map，包括类型化集合 |
| `accepted` | `true`、整数/无符号整数 `1`，或字符串 `yes`、`on`、`1`、`true`（忽略大小写；不去除首尾空白） |

## 数值边界

数值规则使用任意精度有理数比较，避免把大整数先转成 `float64`。十进制语法支持正负号、小数和科学计数法，例如 `-1.25e2`；拒绝空白包裹、十六进制、分数写法以及 `NaN`/`Inf`。

`integer` 的字符串必须匹配十进制整数，例如 `-12`；浮点值 `12.0` 可以通过，但 `12.5` 不通过。

## 空值语义

这些规则本身不会把空字符串自动视为必填错误。需要禁止空值时组合 `required`：

```go
"age": "required|integer",
"enabled": "required|boolean",
```

空 map、slice 和 array 同时满足 `array`，但不满足 `required`。
