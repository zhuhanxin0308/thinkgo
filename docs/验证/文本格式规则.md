# 文本格式规则

文本格式规则只接受可安全转换为标量文本的值。普通结构体不会调用其 `String` 方法；非法或不支持的值直接失败。

## 字符集规则

| 规则 | 允许内容 |
|---|---|
| `alpha` | ASCII 字母 `A-Z`、`a-z` |
| `alphaNum` | ASCII 字母和数字 |
| `alphaDash` | ASCII 字母、数字、下划线和横线 |
| `chs` | 一个或多个中文 Han 字符 |
| `chsAlpha` | 中文 Han 字符和 ASCII 字母 |
| `chsAlphaNum` | 中文 Han 字符、ASCII 字母和数字 |
| `chsDash` | 中文 Han 字符、ASCII 字母、数字、下划线和横线 |

这些规则使用完整匹配，空字符串不通过。中文组合规则不接受空格、标点和其它 Unicode 字母。

## email

`email` 使用标准库邮件地址解析器，并要求输入就是完整地址：

- 不允许前后空白、换行或显示名形式。
- `user@example.com` 可以通过。
- `User <user@example.com>`、`user@` 和带控制字符的值不通过。

## url

`url` 要求 URL 解析成功且包含 host，只允许以下 scheme：

```text
http https ftp rtsp mms
```

空白、控制字符、缺少 host 或 `javascript:` 等 scheme 都不通过。

## date

`date` 按以下格式依次解析，并校验真实日历值：

```text
2006-01-02 15:04:05
2006-01-02
RFC3339Nano
```

例如 `2024-02-29` 可以通过，`2023-02-29` 和带尾随文本的日期不通过。

## mobile

`mobile` 只接受中国大陆手机号正则 `^1[3-9]\d{9}$`，必须是 11 位数字，号段首位为 1、第二位为 3 到 9。

## ip

`ip` 实现为 IPv4 校验，要求 `net.ParseIP` 能解析且存在 IPv4 表示。IPv6 地址不通过。

## idCard

`idCard` 校验 18 位中国居民身份证：

- 前 17 位为数字，末位为数字或 `X/x`。
- 出生日期必须是合法日期且不能晚于当前时间。
- 地址码不能全为 `000000`，顺序码不能为 `000`。
- 按身份证权重校验最后一位校验码。

该规则不额外校验行政区划字典，规则名不接受参数。

## regex

`regex` 使用 Go 正则表达式，必须提供非空参数：

```go
"code": `required|regex:"^(foo|bar):\d+$"`,
```

参数可以使用引号或 `/pattern/` 包裹。正则是否完整匹配由表达式本身的 `^` 和 `$` 决定；框架只调用 `MatchString`。
