# 比较规则

比较规则分为字符串等值、数值比较和数值区间。规则参数在计划编译阶段校验，运行时不会把非法参数当作数据失败。

## in 与 notIn

```text
in:red,green,blue
notIn:disabled,deleted
```

值先转换为标量文本，再与逗号列表中的项做精确匹配：`in` 必须命中，`notIn` 必须不命中。候选值不能为空，列表不能包含空项；规则不做大小写折叠。

## between 与 notBetween

```text
between:1,10
notBetween:1,10
```

两个边界使用任意精度数值解析：

- `between` 包含上下界，即 `1` 和 `10` 都通过。
- `notBetween` 要求值位于闭区间之外；边界值不通过。

边界必须是有效十进制数，且下界不能大于上界。

## eq

```text
eq:active
```

`eq` 比较标量文本的精确值。参数可以是空字符串，也可以是其它已解析文本；布尔和数值会按框架的标量文本形式比较。需要比较两个字段的值时使用[字段关系与条件规则](字段关系与条件规则.md)中的 `confirm` 或 `different`。

## gt、lt、egt、elt

这些规则只做数值比较，不把字符串长度当成数值边界：

| 规则 | 条件 |
|---|---|
| `gt:n` | 值大于 `n` |
| `lt:n` | 值小于 `n` |
| `egt:n` | 值大于或等于 `n` |
| `elt:n` | 值小于或等于 `n` |

它们使用任意精度十进制数，拒绝非数值、NaN、Inf、十六进制和分数参数。
