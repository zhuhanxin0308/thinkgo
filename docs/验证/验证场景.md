# 验证场景

场景是规则字段的命名子集，用于把同一个验证器复用于创建、更新、登录等不同输入。

## 定义

```go
validator.SetScenes(map[string][]string{
	"create": {"name", "email", "password"},
	"update": {"name", "email"},
})
```

也可以单独添加或替换：

```go
validator.AddScene("login", []string{"email", "password"})
```

场景名必须非空、首尾无空白，长度不超过 256 字节。场景字段可以写成带别名的字段定义，但执行时按实际字段名定位规则。

## 完整性检查

每次编译验证计划时，框架会检查全部已注册场景，即使本次没有选择某个场景。以下配置都会返回 `ErrInvalidScene`：

- 场景字段列表为空。
- 同一场景重复引用字段，重复判断不区分字段定义别名。
- 引用了没有规则定义的字段。
- 场景名首尾有空白、为空或超长。
- 场景字段定义本身非法。

场景错误通过 `error` 返回，不能被当作用户输入错误处理。

## 执行

```go
result, err := validator.Validate(
	data,
	validate.WithScene("update"),
	validate.CollectAllErrors(),
)
```

场景保留定义时的字段顺序；未指定场景时，规则字段按实际字段名排序后执行，以保证第一条错误稳定。`WithScene` 只对当前调用生效。
