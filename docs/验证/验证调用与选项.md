# 验证调用与选项

`Validate` 的选项只影响当前调用，不修改验证器共享配置。

## Validate

```go
result, err := validator.Validate(data)
```

`data` 是字段名到值的 map，可以是 `nil`。规则按编译计划执行；字段数据不符合规则时返回 `Result`，配置或选项错误返回 `error`。

## WithScene

```go
result, err := validator.Validate(
	data,
	validate.WithScene("create"),
)
```

`WithScene` 会把本次验证限制到指定场景的字段。场景名会去首尾空白，但必须非空且不超过 256 字节。同一次调用不能指定两个不同场景；空场景、超长场景或重复场景选项返回 `ErrInvalidOption`。

未指定场景时执行全部规则字段。指定了不存在的场景返回 `ErrUnknownScene`，不会静默退回全量验证。

## CollectAllErrors

```go
result, err := validator.Validate(data, validate.CollectAllErrors())
```

默认模式在第一条违规后返回；批量模式继续执行当前计划的其余字段和规则。批量模式仍然只返回一条结果对象，不会修改验证器配置。

## WithLang

```go
result, err := validator.Validate(
    data,
    validate.WithLang(languageManager),
)
```

`WithLang` 只为当前验证调用指定语言管理器，不替换验证器的共享语言配置。它适合控制器把应用级语言管理器显式传到验证边界。

## WithLocale

```go
result, err := validator.Validate(
    data,
    validate.WithLang(languageManager),
    validate.WithLocale("en-us"),
)
```

`WithLocale` 只为当前调用指定语言标识。请求并发时应使用它传递请求语言，不要反复调用共享 `Lang.SetLang`。同一次调用指定两个不同语言标识会返回 `ErrInvalidOption`。

## Option 错误

选项函数不能是 `nil`。`WithScene` 的非法参数、同一调用指定多个不同场景、同一调用指定多个不同语言等情况通过 `ErrInvalidOption` 返回。选项错误和数据违规一样不会被转成验证违规，调用方应先检查 `err`。
