# 控制器中间件

控制器中间件不是直接保存处理器，而是保存已经注册到 `framework.ServiceMiddleware` 对应管道的别名声明。HTTP 内核在控制器 `Init` 完成后、动作执行前解析声明并创建控制器管道。

## 声明

```go
func (controller *User) Init(app *framework.App, request *context.Request) {
    controller.Controller.Init(app, request)
    controller.SetMiddleware(
        framework.ControllerMiddleware{
            Name:   "auth",
            Except: []string{"Login"},
        },
        framework.ControllerMiddleware{
            Name: "csrf",
            Only: []string{"Create", "Update"},
        },
    )
}
```

别名必须先注册：

```go
pipeline, err := framework.ResolveServiceAs[*middleware.Pipeline](app, framework.ServiceMiddleware)
if err != nil {
    return err
}
pipeline.Alias("auth", Auth)
```

声明顺序就是控制器管道顺序。控制器实例由容器按请求创建，`SetMiddleware` 的结果属于该实例，不应在请求之间共享。

## 动作过滤

每一项声明只能使用一种过滤方式：

| 配置 | 行为 |
|---|---|
| `Only` 非空 | 只对列表中的动作生效 |
| `Except` 非空 | 对除列表外的动作生效 |
| 两者为空 | 对全部动作生效 |

动作名比较不区分大小写，匹配前会去除每个列表项首尾空白。过滤项要求使用 Go 标识符风格：首字符是 ASCII 字母或 `_`，后续字符是 ASCII 字母、数字或 `_`。空名称、非法名称和忽略大小写后的重复名称都会失败。

框架会校验全部声明，包括当前动作不会命中的声明。名称为空、`Only` 与 `Except` 同时存在、别名不存在时，HTTP 内核返回内部错误并且不调用控制器动作，不会跳过保护中间件继续执行。

## API 和顺序

```go
declarations := controller.GetMiddleware()
controller.SetMiddleware(declarations...)
```

`GetMiddleware` 返回当前声明，`SetMiddleware` 直接替换声明切片。控制器中间件在路由中间件之后执行，最后才进入动作；在控制器中间件中短路时，动作和后续声明都不会执行。

控制器中间件可以使用 `middleware.Lifecycle` 注册终结回调。终结回调由 HTTP 内核在响应发送后统一执行。
