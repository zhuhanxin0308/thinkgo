# 路由中间件

路由中间件作为路由注册方法的可变参数传入。只有路由匹配成功后，HTTP 内核才会创建路由管道并执行它们。

## 注册方式

```go
auth := func(request *context.Request, next func(*context.Request) *context.Response) *context.Response {
    return next(request)
}

Route.Get("api/profile", "user/profile", auth)
```

所有 HTTP 方法快捷方法都接受中间件：`Get`、`Post`、`Put`、`Patch`、`Delete`、`Options`、`Head` 和 `Any`。也可以使用 `Add`、`Rule`、`Resource` 或重定向路由的注册 API。

## 分组继承

```go
Route.Group("admin", func() {
    Route.Get("dashboard", "admin/dashboard", auth)
}, auth)
```

分组中间件会复制到子作用域，执行顺序是外层分组到内层分组，再到路由自身：

```text
外层分组 -> 内层分组 -> 路由中间件 -> 控制器中间件 -> 动作
```

`Group`、`Domain` 和 `DomainGroup` 会创建新的注册作用域，不会修改父分组；空中间件在注册时返回 `ErrInvalidRouteMiddleware`。

## 注册期约束

路由注册、分组组合和 `WithoutMiddleware` 都必须在路由冻结前完成。HTTP 内核在首次路由分发时冻结，成功后不再重复构建索引。冻结后再次增加、删除或修改路由中间件会返回 `ErrRouterFrozen`。

业务链式 `RuleItem.WithoutMiddleware` 按函数指针识别目标；同一个函数指针出现多次时会因身份歧义失败，目标不存在也会失败关闭。不要依赖匿名闭包的文本内容判断中间件身份。

## 执行边界

404、MISS 和自动 OPTIONS 没有命中业务路由，因此不会执行业务路由中间件。与 ThinkPHP 一样，自动 OPTIONS 是独立的 204 响应，不读取目标方法路由，也不继承其参数或中间件。全局 CORS 可以在进入路由前完成预检；需要路由级 CORS 时应显式注册对应的 OPTIONS 路由。静态资源始终只经过全局管道。

路由中间件可以通过 `middleware.Lifecycle` 注册终结回调。路由管道虽然调用 `Then`，但回调已经写入请求上下文，外层 HTTP 全局管道返回后会统一收集并执行。
