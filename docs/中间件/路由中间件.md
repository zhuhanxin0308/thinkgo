# 路由中间件

路由中间件作为路由注册方法的可变参数传入。只有路由匹配成功后，HTTP 内核才会创建路由管道并执行它们。

## 注册方式

```go
auth := func(request *context.Request, next func(*context.Request) *context.Response) *context.Response {
    return next(request)
}

router, err := framework.ResolveServiceAs[*route.Router](app, framework.ServiceRoute)
if err != nil {
    return err
}
_, err = router.Get("/api/profile", "User@Profile", auth)
if err != nil {
    return err
}
```

所有 HTTP 方法快捷方法都接受中间件：`Get`、`Post`、`Put`、`Patch`、`Delete`、`Options`、`Head` 和 `Any`。也可以使用 `Add`、`Rule`、`Resource` 或重定向路由的注册 API。

## 分组继承

```go
err := router.Group("/admin", func(group *route.Group) error {
    _, err := group.Get("/dashboard", "Admin@Dashboard", auth)
    return err
}, auth)
```

分组中间件会复制到子作用域，执行顺序是外层分组到内层分组，再到路由自身：

```text
外层分组 -> 内层分组 -> 路由中间件 -> 控制器中间件 -> 动作
```

`Group`、`Domain` 和 `DomainGroup` 会创建新的注册作用域，不会修改父分组；空中间件在注册时返回 `ErrInvalidRouteMiddleware`。

## 注册期约束

路由注册、分组组合和 `WithoutMiddleware` 都必须在路由冻结前完成。HTTP 服务启动时调用 `Router.Freeze`；直接调用 `ServeHTTP` 时仅在首个请求中兜底冻结，成功后不再重复构建索引。冻结后再次增加、删除或修改路由中间件会返回 `ErrRouterFrozen`。

`Route.Middlewares()` 返回防御性副本。`Route.WithoutMiddleware` 按函数指针识别目标；同一个函数指针出现多次时会因身份歧义失败，目标不存在也会失败关闭。不要依赖匿名闭包的文本内容判断中间件身份。

## 执行边界

404、405、自动 OPTIONS 和 MISS 处理没有成功匹配的业务路由，因此不会执行该业务路由的中间件。自动路由生成的临时路由也没有路由中间件。需要保护自动 OPTIONS 或静态资源时，应在更早的全局管道或专用显式路由上实现。

路由中间件可以通过 `middleware.Lifecycle` 注册终结回调。路由管道虽然调用 `Then`，但回调已经写入请求上下文，外层 HTTP 全局管道返回后会统一收集并执行。
