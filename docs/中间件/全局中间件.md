# 全局中间件

应用全局中间件放在所属应用的 `app/<应用名>/middleware` 目录，文件不应跨应用共享。所有文件使用该目录的 `middleware` 包，在应用入口中显式装配。

## 注册

在应用入口注册：

```go
package middleware

import (
    "net/http"

    "thinkgo/framework/context"
)

func Auth(request *context.Request, next func(*context.Request) *context.Response) *context.Response {
    if request.Header("Authorization") == "" {
        return context.NewResponse().Code(http.StatusUnauthorized)
    }
    return next(request)
}
```

`app.RegisterGlobalMiddleware` 接受非空处理器并返回错误。应用初始化时按当前应用的注册顺序追加到自己的管道，不会把其它应用的中间件暴露给当前请求。

应用入口必须导入自己的中间件包并注册：

```go
import "thinkgo/app/index/middleware"

if err := app.RegisterGlobalMiddleware(middleware.Auth); err != nil {
	return err
}
```

否则 `RequestID` 和应用自定义的 `init` 注册都不会发生。注册顺序由包初始化顺序决定；有依赖关系的安全中间件应显式放在路由链或用已验证的管道装配代码组织，不要依赖不同包之间的偶然初始化顺序。

## 请求边界

全局动态管道只处理已经通过 Host 校验、请求对象创建和 `Request.Parse` 的请求。GET/HEAD 命中的 `public` 文件会在全局管道之前直接返回，不经过鉴权、Session、CSRF 或应用全局中间件。

全局中间件可以使用 `Request.Set` 写入请求级数据，供后续中间件、路由和控制器读取；不要把请求对象、用户身份或请求级 Session 写入包级变量。

## 内置应用中间件

当前应用包提供：

| 文件 | 导出能力 |
|---|---|
| `request_id.go` | `RequestID`、`EnsureRequestID`、`ValidRequestID` |
| `admin_cors.go` | 管理员严格 CORS |
| `admin_locale.go` | 管理员语言限制 |
| `admin_authentication.go` | 管理员 Bearer 认证 |
| `admin_authorization.go` | 管理员路由和权限授权 |
| `admin_audit.go` | 管理员操作审计 |
| `admin_route_metadata.go`、`admin_runtime.go` | 管理员中间件内部运行时辅助 |

管理员链应放在管理员应用的 `app/admin/middleware` 和 `app/admin/route` 下，具体职责见[管理员中间件](管理员中间件.md)。
