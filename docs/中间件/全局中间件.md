# 全局中间件

业务应用中间件放在 `app/<name>/middleware`，并在 `app/<name>/middleware.go` 中按执行顺序声明。根 `app/middleware.go` 只放确实需要作用于全部业务应用的项目级中间件。

## 编写中间件

```go
package middleware

import (
	"net/http"

	"github.com/zhuhanxin0308/thinkgo/framework"
)

func Auth(request *framework.Request, next func(*framework.Request) *framework.Response) *framework.Response {
	if request.Header("Authorization") == "" {
		return framework.NewResponse().Code(http.StatusUnauthorized)
	}
	return next(request)
}
```

也可以先生成标准文件：

```bash
go run ./cmd/think make:middleware --app index Auth
```

## 声明全局顺序

在 `app/index/middleware.go` 中加入处理器：

```go
package index

import (
	frameworkMiddleware "github.com/zhuhanxin0308/thinkgo/framework/middleware"
	applicationMiddleware "example.com/project/app/index/middleware"
)

func Middleware() []frameworkMiddleware.Handler {
	return []frameworkMiddleware.Handler{
		applicationMiddleware.Auth,
	}
}
```

项目全局列表包裹应用全局列表；每层列表顺序就是进入请求时的执行顺序，响应阶段按调用栈逆序返回。开发者不需要调用 `RegisterGlobalMiddleware`，也不要依赖包级 `init` 隐式装配。

## 请求边界

全局中间件可以使用 `Request.Set` 写入请求级数据，供后续中间件、路由和控制器读取。不要把 Request、用户身份或 Session 写入包级变量或应用单例。

需要为单组路由添加能力时使用路由中间件；只保护特定控制器动作时使用控制器中间件。
