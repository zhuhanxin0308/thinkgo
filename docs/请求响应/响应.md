# 响应

`context.Response` 负责状态码、响应头、响应体、文件下载、流式输出和分块输出。

## 创建响应

```go
return context.NewResponse().Content("ok")
```

设置状态码与响应头：

```go
return context.NewResponse().
	Code(201).
	Header("X-Request-ID", requestID).
	Json(data)
```

`Header` 会整体拒绝非法响应头名或包含控制字符的值。`Connection`、`Content-Length`、`Transfer-Encoding` 等分帧与逐跳响应头由 HTTP 内核管理，不能通过此 API 手工设置。需要重复字段时使用 `AddHeader`：

```go
response.AddHeader("Set-Cookie", firstCookie)
response.AddHeader("Set-Cookie", secondCookie)
```

直接发送响应时必须处理写入错误：

```go
if err := response.Send(writer); err != nil {
	return err
}
```

`Error()` 返回构建阶段累计的配置或序列化错误。

## JSON

```go
return context.NewResponse().Json(map[string]interface{}{
	"code": 0,
	"msg":  "success",
	"data": data,
})
```

JSON 序列化失败时会返回 500，并输出通用错误消息。该失败状态不能被后续链式 `Content`、`Stream` 或文件响应覆盖。

## JSONP

```go
return context.NewResponse().Jsonp("callback", data)
```

回调名会做白名单校验，只允许合法 JavaScript 函数路径。非法回调返回 400，避免脚本注入。
JSONP 序列化失败时同样返回 500 和通用错误消息。

## XML

```go
return context.NewResponse().Xml(data)
```

XML 序列化失败时返回 500 和通用错误消息。

## 重定向

```go
return context.NewResponse().Redirect("/login")
return context.NewResponse().Redirect("/login", 301)
```

只允许 `301`、`302`、`303`、`307` 和 `308`。空目标、控制字符、非法状态码或多个状态码参数会使响应安全降级为 500，且不会写出 `Location`。跳转目标如果来自用户输入，业务仍需自行防范开放重定向。

## 文件下载

受信任路径使用：

```go
return context.NewResponse().Download(filePath, "report.xlsx")
```

用户可控路径使用：

```go
return context.NewResponse().DownloadSafe("./storage/files", req.Param("path"), "")
```

`DownloadSafe` 会拒绝绝对路径和 `..` 逃逸，并在发送前后复核符号链接、真实路径和已打开文件句柄。只允许下载普通文件；越界返回 403，不存在或非普通文件返回 404。成功响应写入准确的 `Content-Length`，默认使用 `private, no-store`。

## 流式响应

```go
return context.NewResponse().Stream(func(w io.Writer) error {
	_, err := w.Write([]byte("stream data"))
	return err
})
```

未设置 `Content-Type` 时默认 `application/octet-stream`。回调必须返回每次写入错误。

流在响应提交前失败时，HTTP 内核会丢弃缓冲内容并返回通用 500。调用 `Flush` 或写出足够数据后响应已经提交，后续错误只能返回给调用方并写入日志，不能再替换已发送的状态码和实体。

## 分块响应

```go
return context.NewResponse().Chunk([][]byte{
	[]byte("part1\n"),
	[]byte("part2\n"),
})
```

每个分块写出后会刷新底层写入器；应用不会手工设置 `Transfer-Encoding`。

## 空响应与终止响应

```go
return context.NewResponse().NoContent()

return context.NewResponse().Abort(403, map[string]interface{}{
	"message": "forbidden",
})
```

`Abort` 支持字符串和结构化 JSON。

## Cookie 响应头

```go
return context.NewResponse().Cookie(
	"token",
	"value",
	3600,
	"/",
	"",
	true,
	true,
)
```

应用级 Cookie 推荐使用 `framework/cookie` 的请求级实例，以复用严格配置、签名、SameSite 和 Secure 策略。构造、读写与删除都会返回错误：

```go
cookieManager, err := framework.ResolveServiceAs[*cookie.Cookie](app, framework.ServiceCookie)
if err != nil {
    return err
}
requestCookie, err := cookieManager.ForRequest(req.Raw(), nil)
if err != nil {
    return err
}
header, err := requestCookie.BuildHeader("token", value, cookie.CookieOptions{
    Path: "/",
    HttpOnly: true,
    SameSite: "Strict",
    Expire: 3600,
})
if err != nil {
    return err
}
response.AddHeader("Set-Cookie", header)
value, found, err := requestCookie.Get("token")
```

`found=true, value=""` 表示命中显式空值；重复同名 Cookie、非法签名和过期签名通过 `error` 返回，不会被静默当成缺失。
