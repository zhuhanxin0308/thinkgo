# 请求

`context.Request` 封装原生 `*http.Request`，提供参数、头部、Cookie、文件、客户端 IP 和请求上下文数据访问能力。

框架外独立构造请求时，`NewRequest` 会校验全部选项并返回错误：

```go
req, err := context.NewRequest(raw,
	context.WithMaxBodyBytes(10<<20),
	context.WithMultipartMemoryLimit(32<<20),
	context.WithTrustedProxies([]string{"127.0.0.1/32"}),
)
```

固定且已知合法的内部配置可使用 `MustNewRequest`。请求体和 multipart 内存上限必须在 1 字节到 1GiB 之间；任一受信代理项非法时整组配置失败。

## 基础信息

```go
method := req.Method()
host := req.Host()
path := req.Path()
ext := req.Ext()
url := req.Url(true)
scheme := req.Scheme()
ip := req.Ip()
```

`Ip()` 和 `IsSsl()` 只有在请求来源命中 `server.trusted_proxies` 或 `SERVER_TRUSTED_PROXIES` 时才信任代理头。
`X-Forwarded-For` 存在多级代理时，会从右向左剥离受信代理并返回最近的非受信客户端 IP。
多值 `X-Forwarded-Proto` 使用受信链最右侧值，客户端预置的左侧值不能覆盖最近代理写入的协议。

## 参数读取

参数优先级：

```text
请求体参数 > 查询参数 > 路由参数
```

这对应 ThinkPHP `param()` 依次合并 route、get、当前请求方法 body 数据的行为；中间件透传数据通过 `Middleware()` 单独读取，不会混入业务输入。

```go
id := req.Param("id", "0")
page := req.ParamInt("page", 1)
enabled := req.ParamBool("enabled", false)
price := req.ParamFloat("price", 0)
```

整数转换不会截断小数或接受溢出值；浮点转换拒绝 `NaN`/`Inf`；数字布尔值只接受 `0` 和 `1`。显式空字符串与字段缺失不同，不会被默认值覆盖。

单独读取：

```go
query := req.Get("q", "")
post := req.Post("name", "")
routeID := req.Route("id", "")
```

`All()` 会合并查询、表单、JSON 和路由透传数据，后面的来源覆盖前面的来源：

```go
data := req.All()
only := req.Only("name", "email")
except := req.Except("password")
```

## JSON 请求体

```go
var payload CreateUserRequest
if err := req.Json(&payload); err != nil {
	return context.NewResponse().Abort(400, "invalid json")
}
```

`Body()` 会按硬上限读取并缓存原始请求体，每次返回防御性副本。请求体读取失败时，`Body()` 和 `Json()` 返回原始错误；JSON 参数解析不会把失败伪装成空 body 再回落到查询参数。

HTTP 内核在进入事件、中间件和业务处理前调用 `Parse()`：JSON 必须是单一对象，语法错误、尾随文档、重复键、超过 100 层嵌套都会返回 400；请求体超限返回 413。独立使用 Request 时也应先处理 `Parse()` 错误。`ParseError()` 可读取已经发现的解析错误。

## 表单与文件

```go
name := req.Post("name")

file, err := req.File("avatar")
if err != nil {
	return context.NewResponse().Abort(400, "missing file")
}
```

multipart 表单的内存上限由 `app.server.multipart_max_memory_mb` 控制，默认 32MB。请求结束时框架会调用 `Cleanup() error` 清理临时文件；独立使用时必须处理其错误。multipart 以流式方式解析时，之后调用 `Body()` 会返回 `ErrRequestBodyUnavailable`，不会伪装成空请求体。

## 头部与 Cookie

```go
token := req.Header("Authorization")
lang := req.Cookie("lang")
contentType := req.ContentType()
mediaType, err := req.MediaType()
```

`Server(key)` 当前是 `Header(key)` 的兼容别名。

## 请求判断

```go
req.IsGet()
req.IsPost()
req.IsPut()
req.IsDelete()
req.IsAjax()
req.IsSsl()
```

## 请求上下文数据

中间件、路由和控制器之间传递请求级数据：

```go
req.Set("request_id", requestID)
value := req.GetData("request_id")
```

`Set` 和 `GetData` 内部有锁保护，可在并发读取场景下使用。不要把请求级数据写到包级变量或应用级单例字段。

## 原始请求

```go
raw := req.Raw()
ctx := raw.Context()
```

数据库查询和事务建议传入 `raw.Context()`，使慢查询随请求取消。
`Raw()` 暴露的是同一个原生请求对象，调用方不得并发修改它。`Root`、`BaseUrl`、`Url(true)` 和 `Port` 遇到非法 Host 时返回空字符串，避免把伪造 Host 写入绝对链接；端口必须是 `1-65535` 的十进制数字，IPv6 Host 必须使用方括号。
