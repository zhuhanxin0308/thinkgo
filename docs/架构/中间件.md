# 中间件

中间件是 ThinkGo 的请求横切层，用于在控制器动作前后处理请求编号、语言、Session、CSRF、Trace、认证、审计和响应收尾。中间件可以调用 `next` 继续执行，也可以直接返回响应短路请求。

本章说明中间件在整体架构中的位置；具体中间件 API、配置和安全边界见[中间件章节](../中间件/README.md)。

## 处理器接口

框架统一使用以下处理器签名：

```go
type Handler func(
	request *context.Request,
	next func(*context.Request) *context.Response,
) *context.Response
```

中间件必须返回 `*context.Response`。不调用 `next` 就会阻止后续中间件、路由和控制器动作；短路响应必须设置明确的状态码。下游返回 `nil` 时，调用方不能把它误认为成功响应。

## 请求中的位置

项目级静态资源和业务路由共用应用全局管道。架构顺序为：

```text
Host 校验、路由冻结、请求对象创建
        ↓
Recovery
        ↓
CORS（可选）
        ↓
Security Headers（可选）
        ↓
Rate Limit（可选）
        ↓
Session（可选）
        ↓
Trace（可选）
        ↓
CSRF（可选）
        ↓
语言检测
        ↓
请求解析
        ↓
项目级静态资源，或选择目标应用上下文
        ↓
目标应用全局中间件
        ↓
路由匹配
        ↓
路由请求：路由中间件 -> 控制器中间件 -> 控制器动作
```

每个业务应用在独立 `framework.App` 初始化阶段装配两层管道：Recovery 始终存在；可选安全、Session 和 Trace 能力由该应用配置决定；语言检测和根 `app/middleware.go` 进入项目全局管道，`app/<name>/middleware.go` 进入应用管道。项目全局管道先处理请求解析和共享静态资源，只有进入业务路由时才执行目标应用管道。已注册别名可以单独被路由或控制器引用，显式优先级在装配末尾排序。

## 三种作用域

| 作用域 | 注册方式 | 生效位置 |
|---|---|---|
| 全局中间件 | 当前 `App.RegisterGlobalMiddleware` 或 `Pipeline.Pipe` | 请求解析、静态资源或路由处理前 |
| 路由中间件 | 路由、分组或路由选项 | 路由匹配成功后 |
| 控制器中间件 | 控制器声明别名 | `Init` 后、动作执行前 |

全局中间件适合请求编号、语言和统一异常处理；路由中间件适合一组路由共享的权限或业务前置条件；控制器中间件适合单个控制器或动作的声明式保护。

## 注册和生命周期

单个业务应用的全局中间件在 `app/<name>/middleware.go` 返回；跨应用中间件使用相同接口在根 `app/middleware.go` 返回：

```go
func Middleware() []middleware.Handler {
	return []middleware.Handler{func(
		request *context.Request,
		next func(*context.Request) *context.Response,
	) *context.Response {
		request.Set("middleware_seen", true)
		return next(request)
	}}
}
```

应用中间件包只声明实现，不通过包初始化修改全局中间件表。需要别名或优先级时，通过当前 App 的 Pipeline API 显式装配。

中间件拿到下游响应后，如果需要设置响应头，必须先判断响应是否为空。终结逻辑使用 `Lifecycle` 或 `PipeLifecycle`，不要在持有共享锁时回调业务代码。

## 安全边界

- Recovery 负责请求管道中的 panic 转换，业务代码不要依赖 panic 控制正常流程。
- CSRF、认证和授权失败时必须短路，不能继续调用 `next`。
- `public/` 静态资源会经过全局中间件，但不会经过路由、分组或控制器中间件；需要路由级鉴权的资源不能直接放入该目录。
- 中间件读取外部输入时必须遵守请求、路径、Cookie、Session 和响应头的安全校验。
- 中间件写入请求上下文使用 `req.Set`，不能把当前请求状态写入单例字段。
