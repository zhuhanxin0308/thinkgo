# 架构

本目录按 ThinkPHP 手册的主题方式组织 ThinkGo 的应用架构文档。每篇文档只负责一个架构主题，内容以当前 ThinkGo 源码和实际运行边界为准。

## 架构基础

- [请求流程](请求流程.md)：从应用启动、HTTP 请求进入到响应收尾的完整流程。
- [架构总览](架构总览.md)：应用对象、组件组合、启动生命周期和层次边界。
- [入口文件](入口文件.md)：HTTP、命令行和开发证书入口的装配职责。
- [多模块和多应用](多模块和多应用.md)：应用目录、应用选择、同进程多应用和宿主边界。

## 应用能力

- [URL访问](URL访问.md)：请求 URL 的进入路径、路由分发和 URL 生成。
- [容器和依赖注入](容器和依赖注入.md)：绑定生命周期、工厂解析、显式实例和依赖解析。
- [服务](服务.md)：服务提供者生命周期与应用服务层的职责划分。
- [门面](门面.md)：ThinkGo 的显式应用能力访问方式，以及与 ThinkPHP Facade 的边界。

## 横切能力

- [中间件](中间件.md)：全局、路由、控制器中间件的架构位置和执行顺序。
- [事件](事件.md)：生命周期事件、业务事件和事件分发边界。
- [可观测性](可观测性.md)：低基数 HTTP 指标、导出边界和生产安全要求。
