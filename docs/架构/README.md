# 架构

本目录描述当前原生多应用架构，以实际代码和发布模块边界为准。

## 架构基础

- [请求流程](请求流程.md)：项目启动、应用选择、请求处理和响应收尾。
- [架构总览](架构总览.md)：项目 App、应用 App、HTTP 宿主和隔离边界。
- [入口文件](入口文件.md)：HTTP 与开发 CLI 的组合职责。
- [Module 与多应用边界](多模块和多应用.md)：唯一发布模块、开发宿主与业务应用。

## 应用能力

- [URL访问](URL访问.md)：域名/路径应用解析、请求 URL 和应用 URL 生成。
- [容器和依赖注入](容器和依赖注入.md)：应用容器、请求作用域和依赖解析。
- [服务](服务.md)：项目级服务与应用级服务职责。
- [门面](门面.md)：通过当前应用访问配置、路由、日志、缓存和数据库。

## 横切能力

- [中间件](中间件.md)：项目级、应用级、路由和控制器中间件顺序。
- [事件](事件.md)：项目生命周期、应用生命周期与请求事件。
- [可观测性](可观测性.md)：指标、Trace 和生产安全要求。
